# CL1-4T 이미지 폴더

사장님 보유 사진 7장 (사선 메인 1 + 전면 가로 1 + 날부 2 + 모델명 1 + 볼트부 1 + 핸들부 1)을
아래 파일명으로 저장해주세요.

## 파일명 가이드 (v8_trendy 매핑)

| 파일명 | 사장님 사진 | 위치 (HTML) | 비율 |
|--------|-----------|------------|------|
| `hero.png` | **사선 메인** (3/4 각도) | Hero 메인 1 — 첫 인상 | 4:5 |
| `front.png` | **전면 가로** | Hero 메인 2 — 두 번째 임팩트 | 3:2 |
| `blade1.png` | **날부 1** | 디테일 그리드 ① | 1:1 |
| `blade2.png` | **날부 2** | 디테일 그리드 ② | 1:1 |
| `model.png` | **모델명** | 디테일 그리드 ③ | 1:1 |
| `bolt.png` | **볼트부** (베어링/조정 나사) | 디테일 그리드 ④ | 1:1 |
| `handle.png` | **핸들부** (좌하→우상 사선) | About 섹션 큰 사진 | 3:2 |
| `cut.gif` (추후) | 실제 커트 영상 | "IN ACTION" 섹션 | 16:9 |

## 핵심 의도

- **Hero 메인 1 (사선) + 메인 2 (전면 가로)** = 두 메인 컷이 첫 인상을 함께 만듦
  - 사선 = 입체감 / 전면 = 정면 임팩트 → 다른 각도로 시너지
- **디테일 그리드 4장**은 1:1 정방형으로 통일 → 카탈로그 톤
- **About 섹션 핸들부 사진**은 사선 흐름 (좌하→우상)이라 가로형 3:2 잘 어울림

## 추가 권장 사양

- **포맷**: 누끼면 PNG, 흰 배경 단색이면 JPG (페이지 배경 #EDEBE8 회색이라 PNG 권장)
- **해상도**: 사장님 보유 원본 그대로 OK (3000~3700px)
- **용량 한도**:
  - 단일 사진 1MB 이하 권장 ([TinyPNG](https://tinypng.com)로 압축 — PNG도 50~70% 감소)
  - GIF 3MB 이하 / MP4 5MB 이하

## 진행 순서

1. Windows 탐색기에서 이 폴더(`projects/products/product_detail/CL1-4T/images/`) 열기
2. 사장님 사진 7장을 위 파일명으로 복사 (TinyPNG 압축 권장)
3. 클로드에게 "넣었어" 알리기
4. 클로드가 v8_trendy.html의 placeholder를 `<img src="...">`로 교체 + push
5. GitHub Pages 배포 완료 후 미리보기에서 실제 사진 확인

## 압축 도구

- **TinyPNG**: https://tinypng.com — PNG/JPG 드래그 → 자동 압축 → 다운로드
- **Squoosh**: https://squoosh.app — 더 정밀 조정 (품질 80~85% 권장)
- **ezgif.com**: https://ezgif.com — GIF/MP4 압축 + 변환

압축 시 화질 거의 유지 + 용량 50~70% 감소.
