# 가위 변수 시트 (사장님 채우기 양식)

> v10 코드의 **더미 데이터 → 실 데이터 갱신용**.
> 사장님이 아래 양식 채우셔서 클로드에게 보내주시면 → v10 코드 일괄 갱신.

---

## 1. 분류 체계 (모든 가위 공통 — 한 번만 정의)

### 등급 (현재 더미: R/A/E/S)
```
R: Regular (입문 / 표준)
A: Ace (중견 / 일반 정밀)
E: Elite (전문가 / 고급 정밀)
S: Signature (마스터 / 특수)
```
→ 사장님 의견: [ 그대로 OK / 변경 — 변경 명세 ]

### 핸들 분류 (현재 더미: A/B/C 핸들)
```
A 핸들 = ?
B 핸들 = ?
C 핸들 = ?
(또는 다른 명칭으로 변경?)
```
→ 사장님 정확한 명칭:

### 날 부분 형태 — 블런트/장가위 (현재 더미: F/A/G)
```
F (Force): 직선형 — 거친 컷, 모발 밀림 적음
A (All-round): 밸런스형 — F+G 중간
G (Glide): 둥근형 — 부드러운 컷, 모발 밀림 빠름
```
→ 사장님 의견: [ 그대로 OK / 변경 ]

### 날 부분 형태 — 드라이/슬라이싱 (사장님 명세)
```
멀티슬라이싱 = ?
정통슬라이싱 = ?
스트록 = ?
```

### 날 부분 형태 — 틴닝 (사장님 명세)
```
빗살 형태 = ?
홈 형태 = ?
감모량 분류 = ?% / ?% / ?% (단계별)
```

### 날등 형태 (현재 더미: S/K/B)
```
S (Straight): 직선형 날등
K (Ken-form): 검형 날등
B (Byeol-form): 별형 날등
```
→ 사장님 정확한 명칭:

## 2. 본 모델 정보 (CL1-4T → 정식 모델로 갈아끼우기)

### 기본
- 정식 모델명: ____________ (CL1-4T 대신)
- 가위 종류: 블런트 / 장가위 / 틴닝 / 슬라이싱 (선택)
- 길이: ____ inch
- 무게: ____ g
- 소재: ____________
- 베어링: ____________
- 가격: ____________ 원 (참고용, 페이지에는 X)

### 분류
- 등급: R / A / E / S (선택)
- 핸들: A / B / C (선택)
- 날 부분 형태: F / A / G (블런트의 경우)
- 날등 형태: S / K / B
- 권장 작업 비중: 블런트 ___% / 장가위 ___% / 틴닝 ___% / 슬라이싱 ___%

## 작성 방법

1. 이 파일을 VS Code에서 직접 편집 (밑줄 자리에 입력)
2. 또는 답변에 위 항목 채워서 보내주시면 클로드가 v10 일괄 갱신
3. 모든 항목 한 번에 채울 필요 X — 단계별 가능 (예: 1번 분류만 먼저 / 2번 본 모델만 / 등)
