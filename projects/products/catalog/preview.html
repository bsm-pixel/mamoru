Phase 1A — 블런트 카드·카피 풀·spec 첫 샘플

📋 사장님 검토 방법

  1. 1번 BLADE EDGE 카드 — F·A·G 3개 카드가 사장님 의도대로 보이는지. SVG 그림·이름·설명·선택된 상태(검은 카드)가 직관적인지
  2. 2번 Hero subtitle 카피 풀 — 5개 카피 중 어떤 게 마음에 들고 어떤 건 별로인지. 추가하고 싶은 톤·뉘앙스가 있는지
  3. 3번 A2-55FS spec 미리보기 — 빌더가 만들어낼 데이터 구조가 사장님 모델 카탈로그로 보관하기 적당한지

검토 OK면 → 나머지 카드(BLADE DESIGN · HANDLE GRIP · CAMEL · GRADE) + 카피 풀 일괄 추출

— 01 / 카드 카탈로그 (블런트)

BLADE EDGE — 날 선 형태

블런트 모델에서 사용자가 클릭으로 선택할 3개 옵션. 선택된 옵션이 검은 카드 (예시: A2-55FS의 F)

읽는 법: 빌더 페이지에서 사장님이 이 3개 카드 중 하나를 클릭 = 그 모델의 BLADE EDGE 결정. 현재 보이는 화면은 v10 실제 디자인 그대로. 사장님이 직관적으로 어떤 가위인지 알 수 있어야 함.
