MAMORU 상담 안내 페이지(page_guide.html) 이미지 폴더
========================================================

여기에 사진 파일을 넣으면 페이지에 자동 반영됩니다 (GitHub Pages 자동 배포).

[필요한 파일]
- 상담현장.jpg   ← 상담 현장 이미지 (about 탭 ③ 위치)
- 복원수리.jpg   ← 복원수리/상담 이미지 (about 탭 ⑦ 위치)

[권장 사이즈 / 비율]
- 가로:세로 = 3 : 2  (가로형)
- 권장 해상도: 1200 x 800 px (또는 1500 x 1000)
- 형식: JPG 또는 WebP (용량 최적화 권장: 200~400KB)

[참고]
- 다른 비율의 사진을 넣어도 틀(3:2)에 맞춰 자동으로 가운데 크롭됩니다.
  단, 인물/핵심이 사진 가장자리에 있으면 잘릴 수 있으니 가운데 배치 권장.
- 파일명을 위와 똑같이 맞춰야 합니다 (한글 파일명 그대로 사용).
- 다른 파일명을 쓰려면 page_guide.html 의 <img src="images/..."> 경로를 함께 수정.
