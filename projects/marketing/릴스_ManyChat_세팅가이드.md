# 🛠 ManyChat 릴스 자동 DM 세팅 가이드

> 인스타그램 릴스 → 댓글 키워드 → 자동 DM 발송 세팅 완전 가이드
> (최초 1회 세팅 후 릴스 올릴 때마다 3분이면 새 키워드 등록)

---

## 📋 사전 준비

### 필수 조건
- [ ] 인스타그램 계정이 **비즈니스 또는 크리에이터** 계정일 것
- [ ] 페이스북 페이지와 인스타그램이 **연결**되어 있을 것
- [ ] 페이스북 개인 계정이 페이지의 **관리자**일 것

### 계정 전환 방법 (일반 → 비즈니스)
인스타 앱 → 프로필 → 오른쪽 위 메뉴(☰) → **설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환** → 비즈니스 선택

---

## 1단계: ManyChat 가입 & 연결 (15분)

### 1-1. ManyChat 가입
1. https://manychat.com 접속
2. 우측 상단 **"Get Started Free"** 클릭
3. **Facebook 계정으로 로그인** (Apple/Google/이메일도 가능)

### 1-2. 인스타그램 연결
1. 가입 후 첫 화면에서 **"Connect Instagram"** 클릭
2. 페이스북 로그인 → 인스타그램 계정 선택
3. 권한 허용:
   - 메시지 관리
   - 댓글 관리
   - DM 전송
4. 연결 완료되면 대시보드 진입

### 1-3. 언어/타임존 설정
- Settings → General
- Time Zone: **Asia/Seoul (GMT+9)**
- Language: Korean (한국어 UI) 또는 English 유지

---

## 2단계: 첫 자동화 만들기 (20분)

### 2-1. 새 Automation 생성
1. 좌측 메뉴 **Automation → New Automation** 클릭
2. **"From Scratch"** 선택 (빈 캔버스)
3. 이름 입력: `릴스_신제품_안내_20260419`
   - ⚠ 날짜/내용을 이름에 넣으면 나중에 관리 쉬움

### 2-2. 트리거(시작점) 설정
1. 캔버스에서 **"Trigger"** 클릭 → **"Instagram"** 선택
2. 트리거 종류 선택:
   - **"User comments on my post"** → 댓글에 반응 ⭐ 권장
   - "User sends message" → DM 직접 받았을 때
   - "Story mention" → 스토리 멘션 시

### 2-3. 타겟 포스트 연결
1. **"Select Post"** 클릭
2. 인스타 포스트 목록에서 **릴스 선택**
   - 아직 릴스 미업로드면 → "Any post" 선택 후 나중에 변경
3. **Keyword** 입력:
   ```
   구매, 구매하고싶어요, 구매정보
   ```
   - 쉼표로 여러 키워드 등록 가능
   - 대소문자 구분 없음
   - 완전 일치 vs 포함: **"Contains"** 권장 (댓글에 키워드가 포함되기만 하면 됨)

### 2-4. DM 메시지 작성
1. 트리거 아래 **"+"** 버튼 → **"Send Message"** 추가
2. 메시지 종류 선택:
   - **Text** — 기본 텍스트
   - **Image** — 이미지 첨부
   - **Gallery** — 카드형 상품 진열 ⭐ (여러 상품 보여줄 때)
   - **Buttons** — 버튼 클릭으로 분기
3. MAMORU 톤 예시 메시지:
   ```
   안녕하세요, MAMORU입니다 😊

   관심 가져주셔서 감사합니다.
   아래에서 상세한 정보 확인하실 수 있습니다.

   👇 제품 상세
   ```
4. **Button 추가**:
   - 버튼 텍스트: `제품 보기`
   - URL: `https://mamoru.kr/44?utm_source=instagram&utm_medium=reels&utm_campaign=블런트신제품`
   - (UTM 파라미터 꼭 붙이기 → 전환 추적용)

### 2-5. 추가 흐름 (선택)
- Delay(지연) 2초 → 두 번째 메시지로 진단 페이지 안내
  ```
  어떤 가위가 맞을지 고민이시면
  👇 1분 진단으로 확인해보세요
  ```
  + 버튼: `진단 시작하기` → `/58` 링크

### 2-6. 활성화
우측 상단 **"Publish"** 또는 **"Set Live"** 클릭

---

## 3단계: 테스트 (5분)

### 3-1. 본인 계정으로 댓글 달기
1. 해당 릴스에 본인 다른 계정으로 **"구매"** 댓글
2. 5~30초 내 DM 도착 확인
3. 버튼 클릭 → 링크 정상 이동 확인

### 3-2. 댓글 공개 응답 (보너스)
ManyChat은 댓글에도 자동 답글 가능:
```
안녕하세요! DM으로 정보 보내드렸습니다 💌
```
→ 다른 시청자에게도 "자동 DM 시스템 있구나" 알릴 수 있음

### 3-3. 문제 발생 시 체크
- **DM 안 옴?**
  - ManyChat에서 Post 연결 확인
  - 키워드 오타 확인
  - 인스타 비즈니스 계정 맞는지 확인
- **링크 안 열림?**
  - `https://` 포함 여부 확인
  - 모바일에서 테스트

---

## 4단계: 운영 루틴 (릴스 올릴 때마다)

### 매번 반복 (3분)
1. 릴스 업로드
2. ManyChat → Automation → **기존 자동화 복제(Duplicate)**
3. 복제본에서:
   - 이름 변경 (날짜+주제)
   - 타겟 포스트 → 새 릴스로 변경
   - 키워드 수정
   - DM 메시지 수정 (링크/내용)
4. Publish

### 한 달에 한 번 (30분)
- ManyChat **Analytics** 확인:
  - 어떤 릴스 키워드가 가장 반응 좋았나
  - DM 클릭률이 높은 메시지 형식은?
- 효과 없는 자동화 → 비활성화
- 효과 좋은 패턴 → 템플릿화

## 🎯 MAMORU 운영 전략

### 키워드 고정화 (반복 노출 → 학습 효과)
```
- 정보 → 제품/서비스 상세
- 진단 → /58 진단 페이지
- 복원 → /53 복원수리 안내
- 구매 → 제품 상세 + 쇼핑몰 직행
- 가이드 → 관리 팁 PDF/블로그
- 상담 → 컨설팅 예약
```

→ 고객이 **"아, MAMORU 릴스에는 '진단' 댓글 달면 맞춤 가이드 준다"** 인식

### 릴스 캡션 표준 포맷
```
[본문 요약 1~2줄]

💬 댓글에 "[키워드]" 남겨주시면
   [무엇]을 DM으로 보내드립니다

#마모루 #미용가위 #[관련태그]
```

### DM 메시지 표준 포맷 (MAMORU 톤)
```
안녕하세요, MAMORU입니다 😊

[간결한 소개 1줄]
[정보 링크 버튼]

[관련 보조 링크 1개]
[버튼]

판매하지 않습니다. 안내할 뿐입니다.
```

## ⚠️ 인스타 정책 주의사항

### 금지 행동
- ❌ **24시간 이후 DM 규칙** — 사용자와 마지막 상호작용 후 24시간 지나면 **홍보성 DM 금지**
  - 해결: 댓글 달린 직후 24시간 이내에만 DM 자동 발송
- ❌ **스팸성 반복 DM** — 같은 사람에게 여러 번 자동화 발송 금지
- ❌ **외부 URL 과다** — DM에 링크만 여러 개 나열 시 페널티 가능성

### ManyChat이 자동으로 처리해주는 것
- 24시간 창 준수
- 메시지 발송 속도 제한
- 인스타 API 제한 대응
