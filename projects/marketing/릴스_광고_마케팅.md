# 📱 릴스 댓글 자동 DM 마케팅

> 인스타그램 릴스에서 댓글 키워드 → 자동 DM 발송으로 쇼핑몰 유입 극대화

---

## 🎯 핵심 아이디어

**"XX 입력해주시면 DM으로 정보를 보내드립니다"**

1. 릴스 영상 게시 (획기적 상품, 복원수리 Before/After 등)
2. 영상 끝 or 캡션에 **키워드 안내** (예: "구매" "정보" "복원")
3. 시청자가 댓글에 해당 키워드 입력
4. **자동으로 DM 발송** — 쇼핑몰 링크 / 상담 페이지 / 상세 정보

---

## 🛠 구현 도구

### 1. ManyChat (추천) ⭐
- 인스타그램 공식 파트너
- **무료 플랜**: 기본 기능 가능 (1,000명 구독자까지)
- 유료: 월 $15~ (무제한)
- 세팅: 포스트 연결 → 키워드 지정 → DM 플로우 작성 (드래그&드롭)

### 2. Meta Business Suite (무료, 공식)
- 인스타 자체 자동 응답 기능
- 단순한 키워드 → DM 가능
- 플로우/조건 분기는 제한적

### 3. 대안
- MobileMonkey
- Chatfuel
- Respond.io

## 💡 MAMORU 적용 시나리오

### 시나리오 A: 신제품 출시 릴스
**영상**: "새로 나온 틴닝가위, 뭐가 다를까?"

**캡션**:
> 댓글에 **"틴닝"** 남겨주시면
> 제품 상세 정보를 DM으로 보내드립니다

**자동 DM 내용**:
```
안녕하세요, MAMORU입니다 😊

틴닝가위 상세 정보입니다:
👉 [제품 페이지 링크]

어떤 커트 스타일에 맞는지 궁금하시면
👉 [1분 진단 페이지] 에서 확인해보세요

판매하지 않습니다. 안내할 뿐입니다.
```

### 시나리오 B: 복원수리 Before/After
**영상**: 낡은 가위가 새 것처럼 복원되는 과정

**캡션**: 
> 댓글에 **"복원"** 남겨주시면
> 복원수리 안내와 비용 정보를 보내드립니다

**자동 DM**: 복원수리 안내 페이지 + 접수 방법 + 비용

### 시나리오 C: 교육 콘텐츠 (볼트 조절 등)
**영상**: "틴닝가위 찝힘 문제, 볼트 조절 한 번이면 해결"

**캡션**:
> 댓글에 **"가이드"** 남겨주시면
> 가위 관리 가이드 PDF를 보내드립니다

**자동 DM**: PDF 링크 + 관련 블로그 링크

### 시나리오 D: 진단 유입
**영상**: "당신에게 맞는 가위 찾기"

**캡션**:
> 댓글에 **"진단"** 남겨주시면
> 1분 맞춤 진단 링크를 보내드립니다

**자동 DM**: `/58` 진단 페이지 링크

## 📊 예상 효율

### 일반 통계
| 지표 | 일반 업계 | MAMORU 예상 |
|------|---------|------------|
| 릴스 노출 수 | 베이스 | - |
| 댓글 반응률 | 1-3% | 높을 가능성 (관여도 큰 상품) |
| DM 열람률 | 80%+ | 80%+ |
| 링크 클릭률 | 40-60% | 40-60% |
| 전환율 (상담/구매) | 5-15% | 10-20% (브랜드 신뢰도) |

### 왜 효율이 높은가?
1. **Warm Lead** — 댓글 남긴 사람은 이미 관심 있음
2. **알고리즘 부스트** — 댓글 많을수록 인스타가 더 많이 노출시킴
3. **DB 확보** — DM 받은 사람 = 잠재 고객 리스트
4. **대화형 전환** — DM은 문자보다 반응률 높음

## ⚠️ 주의사항 (MAMORU 브랜드 톤)

### ❌ 하지 말 것
- "지금 바로 구매!" / "놓치지 마세요!"
- 과한 이모지 남발
- 즉각적 구매 압박
- 할인/특가 강조 (브랜드 원칙 위반)

### ✅ 해야 할 것
- "관심 가져주셔서 감사합니다" 등 차분한 인사
- 정보 제공 위주 (판매 < 안내)
- **"판매하지 않는다. 안내할 뿐이다."** 톤 유지
- 진단/컨설팅으로 자연스러운 유입

## 🚀 시작 가이드

### 1단계: 무료로 테스트 (1-2주)
1. ManyChat 계정 생성 (manychat.com)
2. 인스타그램 비즈니스 계정 연결
3. 기존 릴스 1-2개에 키워드 트리거 설정
4. 반응 측정

### 2단계: 스케일업
- 반응 좋으면 ManyChat 유료 전환
- 릴스 업로드마다 키워드 전략 포함
- DM 발송 고객 → TMS 고객 DB 연동 검토 (수동 또는 API)

### 3단계: 장기 운영
- **키워드 일관성** — "정보" "진단" "복원" "구매" 몇 개 고정
- **DM 플로우 개선** — 클릭률/전환율 측정 후 A/B 테스트
- **UTM 파라미터** — `?utm_source=instagram&utm_campaign=reels_XX` 링크에 붙여서 전환 추적

## 🎬 키워드 & DM 템플릿 모음 (사용 준비)

| 키워드 | 릴스 주제 | DM 주요 내용 |

| **상담** | 컨설팅 후기 | 컨설팅 예약 링크 |
| **구매** | 획기적 상품 | 제품 상세 + 구매 CTA |

## 📌 결론

릴스 댓글 자동 DM은 **MAMORU에 매우 적합한 마케팅 방식**:

✅ **관심 있는 사람만 필터링** → 효율 높음
✅ **인스타 알고리즘 유리** → 자연 노출 증가
✅ **브랜드 톤 유지 가능** → 압박 없는 정보 제공
✅ **TMS 고객 DB 연동** 가능성 (DM 받은 사람 = 잠재고객)

**시작 비용**: $0 (ManyChat 무료 플랜)
**예상 ROI**: 높음 (관여도 큰 상품군 + 브랜드 신뢰도)

> 유튜브(교육) → 인스타(브랜드) → 쇼핑몰(구매) 동선에서
> **인스타 → 쇼핑몰 전환**을 극대화하는 강력한 도구.
