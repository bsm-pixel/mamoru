# 🖋 일관된 아이콘 생성 프롬프트 가이드

> MAMORU 페이지에 들어가는 모든 아이콘을 **하나의 통일된 핸드드로잉 doodle 스타일**로 만들기 위한 가이드.
> 사장님이 직접 그린 스케치 → AI 변환 → 깔끔한 아이콘 산출.

---

## 🎯 적용 스타일

**Streamline Hand Drawn 스타일**:
- 약간 흔들리는 핸드드로잉 느낌
- 검정 단일 선 + 흰 배경
- 아웃라인 위주 (큰 채움 없음)
- 친근하고 따뜻한 톤
- MAMORU 모노크롬 팔레트와 자연스럽게 어울림

**참고 적용처**:
- `projects/consulting/icons/` — 진단 페이지 아이콘
- 향후 다른 페이지의 모든 SVG 아이콘 통일

---

## 📋 사용 흐름

```
1. 사장님이 종이/태블릿에 러프 스케치
   ↓
2. 사진 찍거나 스캔
   ↓
3. ChatGPT 4o에 사진 첨부 + 아래 프롬프트 입력
   ↓
4. 결과물 받기 → 마음에 들 때까지 "다시 그려줘" 반복
   ↓
5. PNG 다운로드 (1024x1024px)
   ↓
6. (선택) vectorizer.io로 SVG 변환
   ↓
7. /icons/ 폴더에 저장 → 페이지에 적용
```

## 📝 프롬프트 (영어 — 권장, 더 정확)

```
Transform this sketch into a clean hand-drawn doodle icon in the style of Streamline Hand Drawn icons.

**Style requirements:**
- Hand-drawn doodle style with slightly imperfect, wobbly lines
- Pure black ink (#1A1A1A) on pure white background
- Single consistent line weight (around 2-3px, looks hand-sketched with marker)
- Outline-only design — NO solid fills (except tiny details like eyes, dots, small accents)
- Minimal, charming, friendly, approachable feeling
- Authentic hand-drawn feel (not vector-perfect)

**Composition:**
- Centered in a perfect square frame
- Icon fills 70-80% of frame with equal padding on all sides
- Subject simplified to essential silhouette only
- Single subject, no decorative background elements

**Technical specs:**
- 1024 x 1024 pixels, square aspect ratio
- Pure white background (#FFFFFF) — for easy transparency removal later
- High contrast, crisp clean lines
- No text, no labels, no watermarks, no signatures
- No grid lines or alignment marks

**Preserve from input:**
- The original concept, shape, and pose from the provided sketch
- The general subject matter and key recognizable elements

**Strictly avoid:**
- Color (only pure black on white)
- Gradients or shadows
- 3D rendering or perspective effects
- Photo-realistic style
- Solid filled areas larger than small details
- Multiple line weights
- Watermarks or signatures
```

## 📝 프롬프트 (한국어)

```
이 스케치를 Streamline Hand Drawn 스타일의 깔끔한 손그림 아이콘으로 변환해줘.

**스타일 요구사항:**
- 약간 불완전하고 흔들리는 선의 손그림 doodle 스타일
- 순수 검정 잉크 (#1A1A1A) + 순수 흰 배경
- 일관된 선 굵기 (2-3px, 마커펜으로 그린 듯한 느낌)
- 아웃라인만 — 큰 면 채우기 금지 (눈, 점 같은 작은 디테일은 채워도 OK)
- 미니멀하고 친근하고 따뜻한 느낌
- 손그림의 자연스러움 (벡터처럼 완벽하지 않게)

**구성:**
- 정사각형 프레임 정중앙에 배치
- 아이콘이 프레임의 70-80% 차지, 사방 동일한 여백
- 핵심 실루엣만 단순화
- 배경 장식 없음, 단일 피사체

**기술 사양:**
- 1024 x 1024 픽셀, 정사각형
- 순수 흰색 배경 (#FFFFFF) — 투명화 처리하기 쉽게
- 높은 대비, 선명한 선
- 텍스트, 라벨, 워터마크, 서명 없음

**입력 스케치에서 유지:**
- 원본 컨셉, 모양, 포즈
- 핵심 알아볼 수 있는 요소

**절대 금지:**
- 컬러 (검정만)
- 그라데이션, 그림자
- 3D 효과, 원근감
- 사진풍 표현
- 작은 디테일보다 큰 면적의 채움
- 다양한 선 굵기
```

## 🛠 후처리 도구

| 도구 | 용도 |
|------|------|
| [remove.bg](https://remove.bg) | 흰 배경 → 투명 PNG |
| [vectorizer.io](https://vectorizer.io) | PNG → SVG 변환 (벡터 = 항상 깔끔) |
| [Photopea](https://photopea.com) | 무료 포토샵 (수동 보정) |

### 권장 최종 흐름
```
스케치 → ChatGPT 4o → PNG 1024px → vectorizer.io → SVG → /icons/ 폴더
```

**왜 SVG로 만들면 좋은가:**
- 어떤 사이즈로 표시해도 깨지지 않음
- 색상 변경도 CSS로 가능 (예: hover 시 색상 변경)
- 파일 크기 작음

## 📐 페이지 적용 사이즈 참고

### 진단 페이지 (page_diag.html)
- **컨테이너**: PC 52×52px / 모바일 44×44px
- **viewBox**: 자유 (`0 0 24 24` 또는 `0 0 32 32` 모두 OK)
- **선 굵기**: `stroke-width: 1.5~2`

### 메인 페이지 (page_main_*.html)
- **카테고리 칩 아이콘**: 18-24px
- **퀵 네비 아이콘**: 16-20px

### 일반 가이드
- **표시 크기 ÷ 4 = 최소 생성 사이즈**
- 즉, 50px 표시면 200px 이상으로 생성 → 선명함 유지
- 1024px로 만들면 모든 사이즈 안전

## 🎨 일관성 유지 팁

### 시리즈로 만들기
여러 아이콘을 한 시리즈로 뽑을 때:
1. **첫 번째 아이콘** 만들고 마음에 들 때까지 다듬기
2. 같은 ChatGPT 대화 안에서 **"이 스타일로 [다른 주제] 아이콘"** 으로 추가 생성
3. 같은 대화 흐름이라 톤이 자동으로 통일됨

### 프롬프트 고정
- "Style requirements" 부분은 **매번 동일하게** 사용
- "Preserve from input"의 주제만 그때그때 다르게

### 시각 검증 체크리스트
새로 만든 아이콘이 기존과 어울리는지 체크:
- [ ] 선 굵기가 비슷한가
- [ ] 손그림 흔들림 정도가 비슷한가
- [ ] 검정 정도가 같은가 (`#1A1A1A` Void)
- [ ] 주변 여백 비율이 비슷한가
- [ ] 채움 면적 비율이 비슷한가
