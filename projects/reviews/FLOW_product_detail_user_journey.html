🎯 사용자 시각 — 본 흐름 (사장님 제안 반영 ⭐)

  1. 진입: 메뉴 → 상품 클릭 → 상품 상세 페이지 진입
  2. 탐색: 메인 이미지 + 가격 확인 → 옵션·수량 선택
  3. ⭐ 신뢰 확보 (먼저): 자체 후기 — 별점 + 사진 + 태그로 다른 미용사 경험 확인 (구매 결정 직전)
  4. 학습 (관심 생긴 사용자만): 상세 설명 본문 (v10) — 마모루 톤 풀 디자인
  5. 문의 확인: Q&A 탭 클릭 → 다른 고객 질문 + 본인 문의 등록 가능 (아임웹 네이티브)
  6. 브랜드 가치 인식: PROMISE — 동일 가격 / 판매 X 안내 O
  7. 재방문 유도: 카카오 채널 친추 (할인 X, 알림 수신 목적)
  8. 의문 해소: FAQ — 배송 / 결제 / 환불 / 문의
  9. 브랜드 잔상: 슬로건 — CUT THE FAKE, KEEP THE REAL
  10. 법적 정보: 푸터 — 사업자 정보 + 약관 + 연락처

🔧 기존 흐름 → 새 흐름 변경점

  1. 구매평 탭 자체 숨김 — 사용자가 "구매평 (0)" 클릭해서 빈 화면 보는 사고 방지
    CSS: [class*="review-tab"] { display: none !important; }
  2. 자체 후기 위젯 자동 매칭 — URL ?idx=123 으로 해당 상품 후기만 표시
    후기 0건 → 위젯 자체 숨김 (빈 영역 노출 X)
  3. Q&A는 아임웹 네이티브 유지 — 디자인 통일성보다 기능 안정성 우선
    향후 별도 사이클로 자체 Q&A 시스템 구축 검토 가능
  4. 공통 영역(PROMISE+카카오+FAQ+슬로건) 한 번 paste = 모든 상품 자동 적용
