# D2. 스플릿 프로모 배너

## 기능 / 가치
좌우 반반 — 한쪽 이미지, 한쪽 태그·제목·설명·버튼. 신제품·이벤트를 알리는 정석 프로모 배너.

## 고객 경험
이미지와 카피가 나란히. 모바일에선 위(이미지)–아래(카피)로 자동 스택.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 이미지·문구·버튼 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 이미지 | image | — | |
| 이미지 위치 | outlined-textfield | 왼쪽 | **왼쪽** 또는 **오른쪽** (글·사진 좌우 바꿈) |
| 테마 | outlined-textfield | 라이트 | **라이트** 또는 **다크** |
| 높이 | outlined-textfield | (빈값) | `360px` 등, 비우면 자동(내용 높이) |
| 태그칩 | outlined-textfield | (빈값) | 비우면 숨김 |
| 제목 | outlined-textfield | 제목… | |
| 설명 | text-editor | 설명 | |
| 버튼 문구/링크 | outlined-textfield | 자세히 보기 | 비우면 버튼 숨김 |

## 주의사항
- fetch·iframe 미사용 / 탭당 1만 자 이내.
