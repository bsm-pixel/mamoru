# 📋 아임웹 커스텀 위젯 — 가이드 정밀 질문지

## A. 코드 검증 — "유효하지 않은 코드"로 차단되는 기준 (가장 중요)
1. **HTML 인라인 이벤트 핸들러**(`onerror`, `onclick`, `onload`, `onmouseover` 등 `on*=` 속성)는 금지인가? (우리는 `onerror` 때문에 저장 차단됨을 실측)
2. HTML에 `<script>`, `<style>`, `<iframe>`, `<object>`, `<embed>`, `<form>` 태그를 직접 쓰면 차단되나?
3. **JavaScript에서 금지되는 것** 목록: `eval`, `new Function`, `fetch`, `XMLHttpRequest`, `WebSocket`, `localStorage`, `sessionStorage`, `document.cookie`, `window.open`, `location` 변경 — 각각 허용/금지?
4. **정규식(RegExp 리터럴/`new RegExp`)**은 허용되나? (복잡한 정규식이 ReDoS로 차단되는지)
5. `setTimeout`/`setInterval`/`requestAnimationFrame`/`MutationObserver`/`IntersectionObserver`/`ResizeObserver` 허용되나?
6. `addEventListener`로 `scroll`/`resize`/`pointer*`/`touch*`/`keydown`/`error` 이벤트 바인딩 허용되나?
7. `document.createElement`, `innerHTML`로 마크업·**인라인 SVG 주입** 허용되나?
8. `window` 전역(예: `window.scrollY`, `window.innerWidth`, `window.matchMedia`, `window.devicePixelRatio`) 접근 허용되나?
9. **외부 이미지 URL**(`<img src="https://...">`, 예: `img.youtube.com`, CDN)은 허용되나? (네트워크 요청 금지와 별개로 이미지 로드는 되는지)
10. `data:` URL, `blob:` 허용? CSS `url()`로 외부 폰트/이미지 허용?
11. "서비스 안정성을 해치는 코드"의 **구체적 차단 예시 목록**이 있나? 차단 시 **어떤 에러 메시지/줄번호/디버깅 정보**를 주나?
12. **탭당 코드 글자수 제한**의 정확한 값은? (가이드엔 1만, 에디터엔 15,000 표시 — 어느 쪽이 맞나)

## B. 패널(설정값) — 정확한 토큰과 동작
13. 각 패널 컴포넌트의 **annotation `@type` 토큰 정확한 문자열**:
    - 텍스트 한 줄 / 줄글 에디터 / 드롭다운 / **옵션버튼(탭)** / ON·OFF / 색상 / **이미지** / 날짜 / 시간 / 반복(item) — 각각의 정확한 `@type` 값.
    - (실측: 이미지는 `image`, "image-uploader" 아님. **옵션버튼은 `segmented-control`로 쓰면 텍스트칸으로 떨어짐** — 진짜 토큰이 뭔지?)
14. `select`/옵션버튼은 **annotation(주석)만으로 자동 생성**되나, 아니면 **"패널 만들기" UI에서 수동 추가해야**만 버튼/드롭다운으로 뜨나?
15. `color-picker`의 `@default` **형식**(예: `#000000`, `rgba(...)`, `#RRGGBBAA` 중 무엇)과 **코드로 받는 반환값 형식**은?
16. `date-picker`/`time-picker`가 **코드로 받는 문자열 형식**(예: `2026-07-01`, `오후 6:00`, `18:00`)은 정확히?
17. `switch`의 반환값은 `true`/`false`인가, 다른 형식인가?
18. `@values`/`@valueNames`에 **공백·슬래시(`/`)·한글** 포함 가능한가? 구분자는 쉼표만?
19. **`{{변수}}` 치환이 HTML·CSS·JS 3탭 모두** 실제로 되나? (CSS/JS 탭에서도 치환되는지 확정)
20. **item(반복)** 한도(부모 1·자식 20·속성 20) 정확? **item 중첩**(item 안에 item) 가능? 자식 변수에 `{{@index}}`/`{{../부모변수}}` 같은 Handlebars 헬퍼 쓸 수 있나? `{{#if}}`/`{{else}}` 지원?
21. 패널에 **정적 안내문/설명 텍스트/구분선/그룹 제목**을 넣는 방법이 정말 없나? (`@description`, divider, note 등)
22. 패널 항목 **최대 개수**(1depth 50개?)와 깊이 제한?

## C. 삽입 위치 / 배치 / 렌더
23. 커스텀 위젯을 **삽입할 수 있는 영역 전체 목록**(메인, 일반 페이지 본문, **상품 상세**, 게시판/공지, 헤더/푸터, 모바일 전용 섹션 등) — 되는 곳/안 되는 곳?
24. **상품 상세 페이지**에 삽입 가능한가? 가능하면 **공통(전 상품 동일)**인가, **상품별 개별** 적용이 되나?
25. 위젯 **가로 폭/그리드**(12컬럼) 제어 가능? **전체 너비(풀블리드/100vw)** 배치 가능?
26. 위젯 **높이**는 콘텐츠 자동인가, 고정 지정 가능한가? (CSS `min-height`/`height` 적용되나)
27. 같은 위젯을 **한 페이지에 여러 개** 넣어도 되나(인스턴스별 패널값 독립)?
28. 위젯이 **PC/모바일용 DOM으로 복제 렌더**되나(코드위젯처럼)? 한쪽 `display:none`?
29. **격리 수준**: CSS가 위젯 내부로 격리되나, 페이지 전역에 샘? JS `window`는 페이지와 공유인가 샌드박스인가? 위젯 간 변수/상태 공유 정말 불가?
