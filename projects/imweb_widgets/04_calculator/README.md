# 04. 등급별 견적 계산기

## 기능 / 가치
모델·수량·등급(소비자/딜러/아카데미)을 고르면 예상 금액을 즉시 계산. B2B 대량구매 문의 전 자가 견적 → 리드 질↑.

## 고객 경험
드롭다운으로 모델 선택 → 수량 입력 → 등급 버튼 클릭 → 하단에 예상 금액(콤마·원)이 실시간 갱신.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 **등급 이름·할인%** 3개 + **모델·단가** 항목 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | 예상 견적 계산 | |
| 등급1~3 이름/할인% | outlined-textfield | 소비자0·딜러15·아카데미20 | 할인은 숫자만 |
| 하단 안내 | outlined-textfield | 실제 가격은… | 비우면 숨김 |
| 모델·단가(반복) | item | — | 모델별로 ↓ |
| └ 모델명 | outlined-textfield | | |
| └ 단가 | outlined-textfield | 0 | 숫자만(콤마 X) |

## 사용 예제
- 모델 "A2-55" 단가 180000 · 등급 "딜러" 15% · 수량 10 → 1,530,000원

## 주의사항
- 단가·할인은 **숫자만** 입력(콤마·% 기호 빼고). 표시에 콤마·원 자동.
- 등급은 3개 고정(이름/할인만 수정). fetch·iframe 미사용.
