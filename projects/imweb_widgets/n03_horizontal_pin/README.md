# N3. 가로 스크롤 핀 갤러리

## 기능 / 가치
PC에서 화면이 잠깐 고정된 채 세로 스크롤로 콘텐츠가 가로로 흐르는 트렌디한 쇼케이스. 라인업·사례를 임팩트 있게.

## 고객 경험
- PC: 섹션에 들어오면 화면 고정 + 스크롤에 따라 슬라이드가 옆으로 흐름.
- 모바일/축소모션: 손가락 가로 스와이프(네이티브)로 폴백.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **슬라이드**에서 이미지·캡션 추가 → **위젯을 전체 너비**로 배치 → 게시

## 패널 설정 항목
| 항목 | @type | 설명 |
|---|---|---|
| 슬라이드(반복) | item | 슬라이드별로 ↓ |
| └ 이미지 | image | |
| └ 캡션 | outlined-textfield | 비우면 숨김 |

## 주의사항
- **전체 너비(풀블리드)** 배치에서 효과 최대. 슬라이드 3~6개 권장.
- 핀이 어색한 환경에선 자동으로 가로 스크롤로 폴백. fetch·iframe 미사용.
