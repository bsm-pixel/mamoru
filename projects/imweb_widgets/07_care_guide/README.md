# 07. 가위 관리법 가이드 (아코디언)

## 기능 / 가치
소독·보관·텐션·오일링 등 관리법을 접었다 펴는 아코디언으로. 전문성을 보이고 체류시간을 늘림.

## 고객 경험
항목 제목 클릭 → 부드럽게 펼쳐지며 설명·이미지 표시(한 번에 하나만 열림).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **항목**에서 [+]로 항목 추가 → 제목·내용·이미지 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | (빈값) | 비우면 숨김 |
| 항목(반복) | item | — | 항목별로 ↓ |
| └ 제목 | outlined-textfield | 항목 제목 | |
| └ 내용 | text-editor | 내용 | 서식 가능 |
| └ 이미지 | image | — | 비우면 숨김 |

## 사용 예제
- "사용 후 소독" / "건조·보관" / "텐션 조절" / "정기 오일링"

## 주의사항
- 한 번에 하나만 펼쳐짐(아코디언). fetch·iframe 미사용.
