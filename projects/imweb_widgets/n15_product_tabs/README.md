# N15. 상품 카테고리 탭 (상품진열 전환)

탭 클릭 → 해당 아임웹 **네이티브 상품진열 위젯만 표시**, 나머지는 숨김. 페이지 이동 없이 제자리 전환.

## 설치 순서

1. **상품진열 위젯을 카테고리 수만큼 배치**
   미용가위 페이지에 아임웹 네이티브 상품진열 위젯을 3개 놓고, 각각 카테고리를 **틴닝 / 장가위 / 블런트**로 지정.

2. **각 상품진열 위젯의 ID(WID) 확인**
   `w20250908c6ee5f1272760` 형태. 확인 경로 = 아임웹 어드민 → 환경설정 → Header Code 의 `IDS` 배열
   (`projects/common_code/header_product_style.txt` 참고. ⚠️ 이 파일은 **읽기만** — 상품진열 스타일은 다른 페이지와 공유)

3. **n15 위젯을 상품진열들 위에 배치**하고, 탭 항목을 카테고리 수만큼 추가
   - 탭 이름: `틴닝`
   - 상품진열 위젯 ID: `w20250908c6ee5f1272760`

4. **진단 스위치 켜기** → 위젯 아래에 `상품진열 3/3 모두 찾음` 이 뜨면 정상. 확인 후 **끄기**.

## 설정값

| 필드 | 내용 |
|---|---|
| 가로 최대폭(PC) | 숫자(예 1080) · 비우면 꽉 채움 |
| 탭 정렬(PC) | 중앙 · 왼쪽 |
| 글씨 색 | 블랙(밝은 배경) · 화이트(어두운 배경) |
| 진단 표시 | 설치 확인용 스위치. 평소엔 끄기 |
| 카테고리 탭(항목) | 탭 이름 + 상품진열 위젯 ID |

## 동작·안전장치

- 외부 DOM은 **display만 토글** — 상품진열 내용은 절대 건드리지 않음
- 상품진열이 늦게 렌더돼도 **유한 폴링(최대 10초)** 으로 잡음. body 감시자 미사용(아임웹 렌더와 경합 방지)
- 🛡️ **하나도 못 찾으면 아무것도 숨기지 않음** → 상품진열 전부 그대로 노출되어 페이지가 깨지지 않음
- PC/모바일 DOM 복제 렌더 대비: `getElementById` 대신 같은 id 전부 수집해 함께 토글

## 반응형 틀

- **PC**: `가로 최대폭`에서 멈춤 + 탭 중앙 정렬
- **모바일**: 탭 넘치면 가로 스크롤. 여백을 **트랙에 20px**(n12·t02·n13 표준) → 가로영역 100% 확장해도 좌우 벽에 안 붙음

## 알려진 한계

- 숨기는 대상은 `#<WID>` 자체. 아임웹 섹션 래퍼에 자체 여백이 있으면 빈 공간이 조금 남을 수 있음 → 그 경우 래퍼까지 접도록 확장 필요.
- 커스텀 위젯 JS가 위젯 **바깥 DOM**에 접근 가능해야 동작. 진단 스위치로 판정할 것. 불가 판정 시 폴백 = 전역 Header Code 스크립트로 이전.
