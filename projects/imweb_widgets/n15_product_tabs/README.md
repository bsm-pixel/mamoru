# N15. 상품 카테고리 탭 (상품진열 전환/필터)

탭 클릭 → 카테고리별 상품만 표시. 페이지 이동 없이 제자리 전환.

## 모드 2종

| 모드 | 조건 | 동작 |
|---|---|---|
| **상품필터** (권장) | 상품진열 위젯 **1개**만 넣을 수 있을 때 | 그 위젯 안의 상품 카드를 **카테고리 라벨(`.cate-label`)** 로 걸러냄 |
| **위젯전환** | 상품진열 위젯을 카테고리 수만큼 배치 가능할 때 | 탭의 `#WID` 위젯만 표시, 나머지 숨김 |

> ⚠️ **쇼핑기획전(캐러셀)에는 쓰지 말 것.** 쇼핑기획전은 `.owl-carousel`이라 카드를 숨기면 슬라이드 폭·도트 계산이 깨진다. 필터는 **상품진열(그리드)** 위젯에서만.

## 설치 — 상품필터 모드

1. 미용가위 페이지에 **상품진열 위젯 1개**를 놓고, **전체 상품(모든 카테고리)** 이 나오게 설정.
2. 상품 카드에 **카테고리 라벨이 보이도록** 위젯 옵션을 켠다 (`.cate-label`).
3. 그 위젯의 **ID(WID)** 확인 → n15의 `[상품필터 모드 전용] 상품진열 위젯 ID`에 입력.
   (확인 경로: 아임웹 어드민 → 환경설정 → Header Code의 `IDS` 배열. ⚠️ 그 파일은 **읽기만** — 다른 페이지와 공유)
4. n15를 상품진열 **위에** 배치 → `동작 방식` = `상품필터`.
5. **진단 스위치 켜기** → `진단: 상품 12개 · 카테고리 라벨 틴닝(4) · 장가위(5) · 블런트(3)` 처럼 **실제 라벨 이름과 개수**가 뜬다.
6. 그 이름을 그대로 각 탭의 `매칭할 카테고리 이름`에 복사. (`전체` 탭을 원하면 이름을 **비워둔다**)
7. 확인 후 **진단 스위치 끄기**.

## 설정값

| 필드 | 내용 |
|---|---|
| 동작 방식 | `상품필터` · `위젯전환` |
| 상품진열 위젯 ID | 상품필터 모드 전용 |
| 가로 최대폭(PC) | 숫자(예 1080) · 비우면 꽉 채움 |
| 탭 정렬(PC) | 중앙 · 왼쪽 |
| 글씨 색 | 블랙(밝은 배경) · 화이트(어두운 배경) |
| 진단 표시 | 설치 확인용 스위치. 평소엔 끄기 |
| 카테고리 탭(항목) | 탭 이름 + `[위젯전환]` 위젯 ID + `[상품필터]` 카테고리 이름 |

## 동작·안전장치

- 외부 DOM은 **display만 토글** — 상품 내용은 절대 건드리지 않음
- 상품진열이 늦게 렌더돼도 **유한 폴링(최대 10초)**. body 감시자 미사용(아임웹 렌더와 경합 방지)
- 🛡️ **대상을 못 찾거나 카테고리 라벨이 하나도 없으면 아무것도 숨기지 않음** → 상품 전부 그대로 노출, 페이지 안 깨짐
- 진단이 캐러셀을 감지하면 경고 문구를 띄움
- PC/모바일 DOM 복제 렌더 대비: `getElementById` 대신 같은 id 전부 수집해 함께 토글

## 반응형 틀

- **PC**: `가로 최대폭`에서 멈춤 + 탭 중앙 정렬
- **모바일**: 탭 넘치면 가로 스크롤. 여백을 **트랙에 20px**(n12·t02·n13 표준) → 가로영역 100% 확장해도 좌우 벽에 안 붙음
