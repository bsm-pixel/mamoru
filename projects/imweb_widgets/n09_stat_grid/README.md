# N9. 신념·수치 그리드

## 기능 / 가치
"신념 / 100% / ZERO / 자체진행" 처럼 **큰 글자(또는 숫자) + 작은 라벨**을 2열(PC 4열) 그리드로. 메인 히어로 아래 신뢰 밴드에 딱.

## 고객 경험
스크롤 진입 시 순차 등장. **숫자면 0→목표 카운트업**(예: 100%), **글자면 그대로**(신념·ZERO·자체진행).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **항목**에서 [+]로 추가 → 큰 글자/숫자·단위·라벨 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 테마 | outlined-textfield | 다크 | **다크** 또는 **라이트** 입력 |
| 항목(반복) | item | — | 항목별로 ↓ |
| └ 큰 글자/숫자 | outlined-textfield | 신념 | 신념·ZERO·자체진행(글자) 또는 100·1240(숫자) |
| └ 단위 | outlined-textfield | (빈값) | 예: `%` (숫자에 붙음) |
| └ 작은 라벨 | outlined-textfield | 작은 설명 | |

## 사용 예제 (스크린샷 재현)
- 신념 / 권하기보다 맞춥니다
- 100 · 단위 `%` / 맞춤 상담
- ZERO / 상술 · 권유
- 자체진행 / 수냉식 복원수리

## 주의사항
- 숫자만 입력하면 카운트업, 글자는 그대로 표시. 항목 4개면 PC 4열·모바일 2×2.
- fetch·iframe 미사용.
