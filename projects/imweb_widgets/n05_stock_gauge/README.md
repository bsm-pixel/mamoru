# N5. 한정 수량 게이지

## 기능 / 가치
남은 수량을 게이지 바로 보여 희소성·긴박감을 전달(전환↑). 30% 이하면 강조.

## 고객 경험
"한정 수량 · 23개 남음" + 줄어든 게이지 바(스크롤 진입 시 채워짐).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 전체·남은 수량 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | 한정 수량 | |
| 전체 수량 | outlined-textfield | 100 | 숫자만 |
| 남은 수량 | outlined-textfield | 23 | 숫자만 |
| 단위 | outlined-textfield | 개 | |

## 주의사항
- ⚠️ **실시간 재고 아님**(아임웹 fetch 금지) — 패널 숫자로 표기, 수동 갱신.
- 브랜드 톤상 과한 긴박감 대신 절제된 표기 권장. fetch·iframe 미사용.
