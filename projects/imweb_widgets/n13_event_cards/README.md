# N13. 이벤트 목록 카드

이벤트 썸네일 카드 목록. 상태(진행중/종료/예정) 뱃지 + 클릭 시 링크 이동. **PC 그리드 / 모바일 1열.** "이벤트 목록 페이지"(아임웹)에 삽입.

## 흐름
아임웹 메인 이벤트 배너 → **이 위젯이 놓인 이벤트 목록 페이지** → 카드 클릭 → 그 이벤트 **게시글/페이지**로 이동.

## 패널
| 항목 | 기본 | 설명 |
|------|------|------|
| 섹션 제목 | 비움 | 예: 진행중 이벤트 |
| 테마 | 라이트 | 라이트 · 다크(어두운 배경) |
| PC 한 줄 개수 | 3 | 2·3·4 |
| 가로 최대폭 | 비움(꽉참) | 숫자 자유입력(예 1280) |
| 이벤트(아이템) | — | 아래 |

### 이벤트 아이템
- 썸네일(1200×750 권장) · 제목 · **상태(진행중·종료·예정)** · 기간(선택) · 한 줄 설명(선택) · **링크**(게시글/페이지 URL)

## 동작
- **상태 뱃지**: 진행중=Void 채움 / 종료=Sand 흐림(썸네일 흑백) / 예정=아웃라인.
- **링크**는 범용 — 아임웹 게시판 글 URL이든 별도 페이지든 넣으면 클릭 시 이동.
- 카드 순차 페이드 등장. 호버 살짝 떠오름+이미지 줌.
