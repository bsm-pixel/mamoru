# 10. 영업시간 배지 + 카톡 버튼

## 기능 / 가치
방문 시각 기준으로 "영업 중 / 영업 종료"를 자동 판별해 배지로 표시 + 카카오톡 상담 버튼. 상담 진입을 명확히.

## 고객 경험
🟢 영업 중(점 강조) / 영업 종료가 자동 표시 + 오늘 영업시간 + 카톡 버튼.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **요일별 영업시간**에 요일·오픈·마감(또는 휴무) 입력 + 카톡 링크 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 영업중 문구 | outlined-textfield | 지금 영업 중 | |
| 영업외 문구 | outlined-textfield | 영업 종료 | |
| 버튼 문구/링크 | outlined-textfield | 카카오톡 상담 | 링크 없으면 버튼 숨김 |
| 요일별 영업시간(반복) | item | — | 요일별로 ↓ |
| └ 요일 | outlined-textfield | 월 | **월·화·수·목·금·토·일** 글자 포함 |
| └ 오픈/마감 | time-picker | — | |
| └ 휴무 | switch | OFF | ON이면 그날 휴무 |

## 사용 예제
- 월~금: 10:00~19:00 / 토: 10:00~15:00 / 일: 휴무 ON

## 주의사항
- 시각 = **방문자 기기 시간**. 요일 글자에 '월'·'화'… 가 포함돼야 매칭됨(7개 요일 행 권장).
- fetch·iframe 미사용.
