# 05. 정적 누적 카운터

## 기능 / 가치
"복원수리 **1,240**건 · 누적 상담 **3,100**건" 같은 수치를 스크롤 진입 시 0→목표로 카운트업. 규모감·신뢰를 전달.

## 고객 경험
화면에 들어오는 순간 숫자가 0에서 목표치까지 부드럽게 올라감(천 단위 콤마 자동).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭에 각 파일 붙여넣기
2. 패널 **수치 항목**에서 [+]로 항목 추가 → 숫자·단위·라벨 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | (빈값) | 위 제목, 비우면 숨김 |
| 수치 항목(반복) | item | — | 항목별로 ↓ |
| └ 숫자 | outlined-textfield | 0 | 콤마 없이 숫자만(1240) |
| └ 앞 기호 | outlined-textfield | (빈값) | 예: + |
| └ 단위 | outlined-textfield | (빈값) | 건 / % / 명 등 |
| └ 라벨 | outlined-textfield | 항목 | 숫자 아래 설명 |

## 사용 예제
- 항목1: 숫자 1240 · 단위 "건" · 라벨 "누적 복원수리"
- 항목2: 숫자 100 · 단위 "%" · 라벨 "맞춤 상담"

## 주의사항
- ⚠️ **실시간 DB 연동 아님**(아임웹 fetch 금지). 숫자는 패널에 직접 입력 → 가끔 갱신.
- 숫자는 콤마 없이 입력(자동 콤마). 항목은 2~4개 권장(반응형 그리드).
