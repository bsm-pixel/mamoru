# N1. 가위 길이 시뮬레이터

## 기능 / 가치
슬라이더로 인치를 조절하면 큰 숫자(인치)+cm 환산과 비례 바가 즉시 변함. 미용사가 자기 가위 길이 감각을 잡고 적정 사이즈를 고르도록 도움.

## 고객 경험
슬라이더를 움직이면 "5.5″ (14.0cm)" 와 길이 바가 실시간 변화.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 최소·최대·기본 인치 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 |
|---|---|---|
| 최소/최대/기본 인치 | outlined-textfield | 4.5 / 7.0 / 5.5 |
| 안내 | outlined-textfield | * 화면 비례 참고용… |

## 주의사항
- 길이 바는 **비례 참고용**(화면 DPI에 따라 실물 길이와 다름). cm는 정확(1인치=2.54cm).
- fetch·iframe 미사용.
