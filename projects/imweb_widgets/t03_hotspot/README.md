# T3. 가위 해부도 핫스팟

## 기능 / 가치
가위 사진 위에 점(핫스팟)을 찍고, 클릭하면 그 부위 설명이 툴팁으로 뜸. 날·텐션·약지걸이 등 전문 지식을 보여 전문성·교육 효과.

## 고객 경험
사진 위 깜빡이는 점들 → 클릭하면 그 부위 이름·설명 말풍선이 위로 뜸. 다른 점 누르면 전환, 바깥 클릭 시 닫힘.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **가위 사진** 업로드 → **핫스팟**에서 [+]로 점 추가 → 위치(%)·부위명·설명 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 가위 사진 | image | — | 배경 |
| 비율 | segmented-control | 와이드 | |
| 핫스팟(반복) | item | — | 점별로 ↓ |
| └ 가로 위치 % | outlined-textfield | 50 | 0(왼쪽)~100(오른쪽) |
| └ 세로 위치 % | outlined-textfield | 50 | 0(위)~100(아래) |
| └ 부위명 | outlined-textfield | 부위 | |
| └ 설명 | text-editor | 설명 | |

## 사용 예제
- 위치 20·40 "날(블레이드)" / 위치 60·55 "텐션 볼트" / 위치 85·70 "약지걸이"

## 주의사항
- 위치는 **사진 기준 %**. 미리보기에서 점을 보며 숫자를 맞추면 됨.
- fetch·iframe 미사용 / 탭당 1만 자 이내.
