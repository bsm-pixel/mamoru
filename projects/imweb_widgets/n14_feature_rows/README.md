# N14. 이미지+텍스트 교차 진열 (Feature Rows)

서비스/특징 소개 행을 **지그재그**로 진열. main_page_btm의 "복원수리·컨설팅" 소개 섹션을 위젯화.

## 레이아웃
- **PC**: 좌우 배치 — **1행=사진 오른쪽(글씨 왼쪽) / 2행=사진 왼쪽(글씨 오른쪽)** 자동 교차(CSS `nth-child`).
- **모바일**: 상하 스택(이미지 위·텍스트 아래) + 좌우 16px 여백(섹션 100% 확장해도 안정감).

## 패널
| 항목 | 기본 | 설명 |
|------|------|------|
| 테마 | 다크 | 다크(어두운 배경)·라이트 |
| 가로 최대폭(PC) | 비움(꽉참) | 숫자 자유입력(예 1100) |
| 행(아이템) | — | 이미지·소제목·제목·설명·버튼문구·버튼링크 |

## 디테일
- 버튼 문구 비우면 버튼 숨김(화살표 자동). 소제목/설명도 비우면 숨김.
- 폭은 JS 적용 후 페이드인 → 풀폭→축소 깜빡임 없음.
- 테마 다크=크림 글씨/크림 버튼, 라이트=검정 글씨/검정 버튼.

🚫 fetch·iframe·인라인 style {{}}·삼중괄호 0. 가로최대폭·PC/모바일·모바일 여백 표준.
