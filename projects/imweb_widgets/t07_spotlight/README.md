# T7. 마우스 스포트라이트 히어로

## 기능 / 가치
어두운 배경에서 커서 주변만 밝아지며 제품이 드러남. "진짜는 가까이서 드러난다"는 브랜드 메시지를 임팩트 있게.

## 고객 경험
PC: 마우스를 움직이면 그 주변만 스포트라이트처럼 환해짐. 모바일: 은은한 어둠 + 문구(스포트라이트 대신 기본 노출).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 배경 이미지·헤드라인·서브 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 배경 이미지 | image | — | 어두운 분위기 컷 권장 |
| 헤드라인 | outlined-textfield | 진짜는 가까이서… | |
| 서브 문구 | outlined-textfield | (빈값) | 비우면 숨김 |

## 주의사항
- 배경은 **어두운 톤** 사진이 효과적. fetch·iframe 미사용.
