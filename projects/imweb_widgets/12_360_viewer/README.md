# 12. 360° 회전 뷰어

## 기능 / 가치
각도별로 찍은 사진들을 드래그로 빙글 돌려보게 함. 제품 디테일을 입체적으로 보여 신뢰를 높임.

## 고객 경험
제품 위에서 좌우로 드래그(터치)하면 가위가 회전하듯 프레임이 바뀜.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **회전 프레임**에서 [+]로 각도별 사진들을 **순서대로** 추가 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 이미지 비율 | segmented-control | 가로 | |
| 회전 프레임(반복) | image item | — | 각도 순서대로 12~36장 권장 |

## 사용 예제
- 가위를 회전판에 올려 10°씩 36장 촬영 → 순서대로 업로드 → 부드러운 360° 회전.

## 주의사항
- 프레임 **순서 = 회전 순서**. 같은 배경·같은 크기·같은 위치로 촬영해야 자연스러움.
- 프레임이 많을수록(12+) 부드러움. fetch·iframe 미사용.
