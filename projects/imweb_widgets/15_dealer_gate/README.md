# 15. 딜러/아카데미 게이트

## 기능 / 가치
전용 코드를 입력하면 딜러·아카데미 전용 안내/가격이 노출됨. B2B 정보를 일반 고객과 분리.

## 고객 경험
코드 입력칸 → 맞으면 전용 내용이 부드럽게 펼쳐짐. 틀리면 안내 문구.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 통과 코드 + 통과 후 내용 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 안내 문구 | outlined-textfield | 전용 코드를 입력하세요 | |
| 통과 코드 | outlined-textfield | MAMORU | 대소문자 무시 |
| 버튼 문구 | outlined-textfield | 확인 | |
| 오류 문구 | outlined-textfield | 코드가 올바르지… | |
| 통과 후 내용 | text-editor | … | 전용 안내·가격 |

## 주의사항
- ⚠️ **클라이언트 코드 매칭이라 강한 보안용이 아님**(소스에서 코드 확인 가능). 민감정보·실가격 노출엔 부적합, **가벼운 구분용**으로만.
- fetch·iframe 미사용.
