# N6. 이용 안내 가로 스텝

## 기능 / 가치
"상담 → 진단 → 맞춤 → 배송" 같은 절차를 번호 원·연결선의 가로 스텝으로. 이용 흐름을 한눈에 이해시켜 진입을 매끄럽게.

## 고객 경험
- PC: 번호 원들이 가로로 선으로 이어짐, 진입 시 순차 등장.
- 모바일: 세로 스텝으로 자동 전환.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **단계**에서 [+]로 단계 추가 → 단계명·설명 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | (빈값) | 비우면 숨김 |
| 단계(반복) | item | — | 단계별로 ↓ |
| └ 단계명 | outlined-textfield | 단계 | |
| └ 설명 | outlined-textfield | (빈값) | 비우면 숨김 |

## 사용 예제
- 1 상담 · 2 간편 진단 · 3 맞춤 추천 · 4 배송

## 주의사항
- 번호는 자동(CSS 카운터). 3~5단계 권장. fetch·iframe 미사용.
