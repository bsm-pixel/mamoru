# T2. 복원 인터랙티브 타임라인

## 기능 / 가치
복원수리 과정(수거→검수→수리→출고)을 번호·연결선으로 보여주고, 스크롤하면 단계가 순차 등장. 과정의 투명성으로 신뢰를 쌓음.

## 고객 경험
01, 02, 03… 큰 번호와 hairline 선으로 이어진 단계들이 스크롤에 맞춰 부드럽게 나타남.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **단계**에서 [+]로 단계 추가 → 단계명·설명·이미지 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | 복원 과정 | 비우면 숨김 |
| 단계(반복) | item | — | 단계별로 ↓ |
| └ 단계명 | outlined-textfield | 단계명 | |
| └ 설명 | text-editor | 설명 | |
| └ 이미지 | image | — | 비우면 숨김 |

## 사용 예제
- 1 수거 · 2 검수(상태 진단) · 3 수냉식 복원 · 4 출고 — 각 단계 사진 첨부

## 주의사항
- 번호(01,02…)는 **자동 매겨짐**(CSS 카운터). 순서는 패널 항목 순서대로.
- fetch·iframe 미사용 / 탭당 1만 자 이내.
