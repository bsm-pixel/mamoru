# N11. 유튜브 썸네일 배너

## 기능 / 가치
유튜브 영상 URL만 넣으면 **썸네일이 자동**으로 뜨고 재생버튼이 올라감. 클릭하면 유튜브로 이동. "마무르의 시선" 같은 영상 줄에 딱.

## 고객 경험
영상 썸네일 + ▶ 재생버튼 카드. 클릭 → 유튜브 새 탭에서 재생.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **영상**에서 [+]로 추가 → **유튜브 URL** 붙여넣기(+제목) → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | (빈값) | 위 제목, 비우면 숨김 |
| 영상(반복) | item | — | 영상별로 ↓ |
| └ 유튜브 URL 또는 영상ID | outlined-textfield | — | `youtu.be/...`, `watch?v=...`, `shorts/...`, 11자리 ID 모두 인식 |
| └ 영상 제목 | outlined-textfield | (빈값) | 썸네일 아래, 비우면 숨김 |
| └ 썸네일 직접 지정 | image | — | (선택) 자동 썸네일 대신 쓰고 싶을 때 |

## 사용 예제
- URL `https://youtu.be/abc123XYZ90` / 제목 "복원 과정 영상" → 썸네일 자동.

## 주의사항
- ⚠️ **인라인 재생은 불가**(아임웹 iframe 금지). 클릭 시 유튜브로 이동하는 방식.
- 썸네일은 `img.youtube.com`에서 자동 로드(이미지 로드이지 fetch 아님). 자동이 흐리면 "썸네일 직접 지정"으로 고화질 업로드.
- fetch·iframe 미사용.
