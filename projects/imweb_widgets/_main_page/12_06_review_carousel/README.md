# 06. 후기 캐러셀 (수동입력)

## 기능 / 가치
사진·별점·후기 카드가 자동으로 넘어가는 슬라이드. 사회적 증거로 신뢰·전환을 높임.

## 고객 경험
카드가 일정 간격으로 자동 전환(마우스 올리면 멈춤), 점 클릭·터치 스와이프로 이동. 별점은 ★로 표시.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **후기**에서 [+]로 후기 추가 → 사진·별점·내용·이름 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 자동전환 간격(초) | outlined-textfield | 4 | 0이면 자동전환 끔 |
| 후기(반복) | item | — | 후기별로 ↓ |
| └ 사진 | image | — | 비우면 자동 숨김 |
| └ 별점 | segmented-control | 5 | 5~1 |
| └ 후기 내용 | text-editor | … | 서식 가능 |
| └ 이름/매장 | outlined-textfield | (빈값) | 비우면 숨김 |

## 사용 예제
- 후기1: 사진 업로드 · 별점 5 · 내용 "날 텐션이 완벽해요" · 이름 "강남 ○○헤어"

## 주의사항
- ⚠️ **TMS 후기 자동연동 아님**(아임웹 fetch 금지). 후기는 패널에 직접 입력.
- 후기 1개면 자동전환·점 없이 단일 카드로 표시.
- fetch·iframe 미사용 / 탭당 1만 자 이내.
