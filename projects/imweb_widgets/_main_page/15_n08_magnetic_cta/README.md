# N8. 마그네틱 CTA 버튼

## 기능 / 가치
마우스를 가까이 가져가면 버튼이 미세하게 끌려오는 프리미엄 마이크로 인터랙션. 핵심 행동(진단·상담)으로 시선·클릭을 유도.

## 고객 경험
PC: 버튼 근처에서 커서를 따라 살짝 움직이고 화살표가 미끄러짐. 모바일: 일반 버튼.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 문구·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 버튼 문구 | outlined-textfield | 간편 진단 시작하기 | |
| 링크 | outlined-textfield | (빈값) | 이동 주소 |
| 테마 | segmented-control | 다크 | 다크/라이트 |
| 아래 작은 문구 | outlined-textfield | (빈값) | 비우면 숨김 |

## 주의사항
- 마그네틱 효과는 마우스(PC)에서만. 터치는 일반 버튼. 페이지당 1~2개로 절제 사용 권장.
- fetch·iframe 미사용.
