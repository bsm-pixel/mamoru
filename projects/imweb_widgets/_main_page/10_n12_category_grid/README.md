# N12. 카테고리 이미지 그리드 (트렌디)

## 기능 / 가치
사진 카테고리 타일 + 라벨 오버레이 + 호버 줌의 트렌디한 진열 내비. 미용가위·빗·가위집·복원수리 같은 카테고리를 사진으로 보여주며 이동.

## 고객 경험
사진 타일 위에 큰 라벨·작은 설명·화살표. 호버하면 사진이 줌인되고 화살표가 강조. 모바일은 자동 다열 그리드.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **카테고리 타일**에서 [+]로 추가 → 이미지·라벨·설명·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 타일 비율 | outlined-textfield | 3/4 | **3/4 · 1/1 · 4/3 · 16/9** 중 입력 |
| 카테고리 타일(반복) | item | — | 타일별로 ↓ |
| └ 이미지 | image | — | 배경 사진 |
| └ 큰 라벨 | outlined-textfield | 카테고리 | |
| └ 작은 설명 | outlined-textfield | (빈값) | 비우면 숨김 |
| └ 링크 | outlined-textfield | (빈값) | 타일 클릭 시 이동 |

## 사용 예제
- 미용가위 / "프로페셔널 라인" / `/44`
- 복원수리 / "녹·텐션 복원" / `/60`

## 차이 (다른 위젯과)
- `n10_icon_nav` = 아이콘+텍스트 **칩**(가벼움) / **n12** = 사진 **타일 진열**(임팩트).
- `d05_dual_choice` = 딱 2갈래 / **n12** = 여러 카테고리 유연 그리드.

## 주의사항
- 타일 3~8개 권장. 사진은 같은 비율 권장. fetch·iframe 미사용.
