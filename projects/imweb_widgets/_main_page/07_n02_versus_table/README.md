# N2. 마모루 vs 일반 비교표

## 기능 / 가치
"자체복원 / 날 변형 가공 / 추천 없는 구매철학" 같은 차별점을 마모루 ✓ vs 일반 ✕ 로 한눈에. 왜 마모루인가를 설득.

## 고객 경험
항목별로 두 열(마모루/일반)에 ✓·✕ 또는 텍스트가 표시. 마모루 열을 강조.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 좌/우 라벨 + **비교 항목** 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 왼쪽/오른쪽 라벨 | outlined-textfield | MAMORU / 일반 판매처 | |
| 비교 항목(반복) | item | — | 항목별로 ↓ |
| └ 항목명 | outlined-textfield | 항목 | |
| └ 자사 | outlined-textfield | O | **O/X** 입력 시 ✓/✕, 그 외는 텍스트 |
| └ 일반 | outlined-textfield | X | 동일 |

## 사용 예제
- "자체 복원수리" O / X · "날 변형 가공" O / X · "추천 없는 구매철학" O / X

## 주의사항
- O·X(또는 o/x, yes/no)는 자동으로 ✓·✕ 변환. 그 외 글자는 그대로 표시.
- fetch·iframe 미사용.
