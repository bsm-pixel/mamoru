# 01. 복원 Before/After 슬라이더 ⭐

## 기능 / 가치
가위 한 장의 **복원 전 ↔ 복원 후**를 손잡이 드래그로 비교. 자체복원 기술을 한눈에 증명 — MAMORU의 핵심 차별점을 시각적으로 압도하는 위젯.

## 고객 경험
사진 위 가운데 손잡이를 좌우로 드래그(모바일=터치)하면 손상↔복원이 갈라져 보임. 키보드 ←/→ 도 지원.

## 아임웹 삽입 방법
1. 디자인모드 → 커스텀 위젯 새로 만들기
2. **HTML 탭** ← `widget.html` / **CSS 탭** ← `widget.css` / **JavaScript 탭** ← `widget.js`
3. 우측 패널에서 **복원 전/후 사진** 업로드 → 미리보기 → 게시 → 사이트 연동

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 복원 전 사진 | image | — | 왼쪽(손상) 사진 |
| 복원 후 사진 | image | — | 오른쪽(복원) 사진 |
| 사진 비율 | segmented-control | 가로(4/3) | 가로/정사각/세로/와이드 — 올린 사진에 맞춤 |
| 왼쪽 라벨 | outlined-textfield | BEFORE | |
| 오른쪽 라벨 | outlined-textfield | AFTER | |
| 하단 설명 | outlined-textfield | (빈값) | 비우면 안 보임 |
| 시작 위치 % | outlined-textfield | 50 | 처음 손잡이 위치 |

## 사용 예제
- 복원 전(녹슨 날) / 복원 후(광나는 날) 사진 2장을 **같은 각도·같은 크기**로 찍어 업로드 → 비율 "가로" → 끝.

## 주의사항
- ⚠️ **불투명 사진**만 (배경 투명 PNG 누끼는 뒤가 비쳐 겹쳐 보임)
- ⚠️ 전/후 **동일 비율** 권장 (다르면 한쪽이 잘림 — object-fit:cover)
- 탭당 1만 자 / fetch·iframe·외부라이브러리 미사용
