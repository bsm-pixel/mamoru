# T5. 무한 마퀴 띠

## 기능 / 가치
"수냉식 복원 · 자체기술 · 날 변형 가공 …" 핵심 키워드가 끊임없이 흐르는 띠. 트렌디한 시각적 리듬 + 브랜드 메시지 각인.

## 고객 경험
키워드가 가로로 무한히 흐름(마우스 올리면 멈춤). 끊김 없이 루프.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **키워드**에서 [+]로 키워드들 추가 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 키워드(반복) | item(텍스트) | — | 흐를 단어들 |
| 테마 | segmented-control | 다크 | 다크/라이트 |
| 속도(초) | outlined-textfield | 30 | 작을수록 빠름 |

## 주의사항
- 키워드는 JS가 자동 복제해 끊김 없이 루프. 위젯은 전체 너비 배치 권장.
- fetch·iframe 미사용.
