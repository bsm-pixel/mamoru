# D3. 슬림 공지 띠

## 기능 / 가치
페이지 상단/중간에 얇게 까는 안내 띠(배송 공지·이벤트 고지). 깔끔한 한 줄 배너. 긴 문구는 흐르기(마퀴) 옵션.

## 고객 경험
아이콘 + 문구 + 링크의 슬림 바. 흐르기 ON이면 문구가 옆으로 흐름(마우스 올리면 멈춤).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 문구·링크 입력 → 게시 (전체 너비 권장)

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 아이콘 | outlined-textfield | ✦ | 이모지/심볼, 비우면 숨김 |
| 문구 | outlined-textfield | 안내 문구… | |
| 링크 문구/링크 | outlined-textfield | (빈값) | 비우면 숨김 |
| 테마 | segmented-control | 다크 | 다크/라이트 |
| 문구 흐르기 | switch | OFF | 긴 문구일 때 ON |

## 주의사항
- ⚠️ "오늘 그만보기/닫기 기억"은 아임웹 localStorage 금지로 불가 → **상시 노출형**.
- fetch·iframe 미사용.
