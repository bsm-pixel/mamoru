# T10. 그립/손크기 시뮬레이터

## 기능 / 가치
손 크기(작은손/보통/큰손)를 고르면 추천 가위 크기(인치)·이유·모델을 보여줌. 진단의 시각형 버전 — 전환 도구.

## 고객 경험
세그먼트 버튼으로 손 크기 선택 → 큰 숫자로 추천 크기(예: 5.5인치) + 설명 + 버튼이 등장.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 옵션 라벨 3개 + **추천(3개, 옵션 순서대로)** 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 질문 | outlined-textfield | 손 크기를 선택하세요 | |
| 옵션1~3 라벨 | outlined-textfield | 작은손·보통·큰손 | 세그먼트 버튼 |
| 버튼 문구 | outlined-textfield | 추천 모델 보기 | 비우면 버튼 숨김(링크 없을 때) |
| 추천(반복) | item | — | **3개**, 옵션1·2·3 순서로 ↓ |
| └ 추천 크기 | outlined-textfield | 5.5인치 | 큰 숫자로 표시 |
| └ 설명 | text-editor | 추천 이유 | |
| └ 링크 | outlined-textfield | (빈값) | 비우면 버튼 숨김 |

## 사용 예제
- 작은손 → 5.0인치 / 보통 → 5.5인치 / 큰손 → 6.0인치 + 각 추천 모델 링크

## 주의사항
- 추천 항목은 **옵션 순서대로 3개** 입력(작은손=1번 추천…).
- fetch·iframe 미사용 / 탭당 1만 자 이내.
