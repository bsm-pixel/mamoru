# 02. 한정세일 카운트다운

## 기능 / 가치
종료 일시까지 **일·시·분·초**를 실시간으로 줄여 보여줌. 마감 임박 긴박감으로 전환을 끌어올린다. 0이 되면 자동으로 "종료" 문구로 바뀜.

## 고객 경험
"한정 혜택 종료까지 02 : 14 : 33 : 09" 가 매초 줄어듦 → 아래 버튼으로 바로 이동. 마감되면 타이머·버튼이 사라지고 종료 문구만 노출.

## 아임웹 삽입 방법
1. 커스텀 위젯 새로 만들기 → HTML/CSS/JS 3탭에 각 파일 붙여넣기
2. 패널에서 **종료 날짜·시간** 지정 → 미리보기 → 게시 → 사이트 연동

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | 한정 혜택 종료까지 | 타이머 위 문구 |
| 종료 날짜 | date-picker | — | 마감일 |
| 종료 시간 | time-picker | (비우면 23:59) | 마감 시각 |
| 테마 | segmented-control | 라이트 | 라이트(크림)/다크(보이드) |
| 버튼 문구 | outlined-textfield | 지금 보러가기 | 비우면 버튼 숨김 |
| 버튼 링크 | outlined-textfield | (빈값) | 이동할 주소 |
| 종료 후 문구 | outlined-textfield | 이번 혜택은 마감되었습니다 | 0 이후 표시 |

## 사용 예제
- 종료 날짜 2026-07-15 / 시간 18:00 / 테마 다크 / 버튼 "특가 보러가기" + 링크 → 그날 18시까지 카운트다운, 이후 자동 마감 문구.

## 주의사항
- 시간 기준 = **방문자 기기 로컬 시간**(국내 고객이면 사실상 KST).
- 날짜·시간 선택값 형식이 다른 경우를 대비해 JS가 유연하게 파싱하지만, **미리보기에서 숫자가 맞게 줄어드는지 꼭 확인**.
- 종료 시간 비우면 그날 23:59로 처리.
- fetch·iframe 미사용 / 탭당 1만 자 이내.
