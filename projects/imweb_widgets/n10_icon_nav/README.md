# N10. 아이콘 칩 내비

## 기능 / 가치
아이콘 + 라벨 알약(pill) 버튼들로 만든 빠른 내비게이션(미용가위·빗·가위집·복원수리·컨설팅·고객후기 등). 메인 히어로 아래 바로가기 줄에 딱.

## 고객 경험
아이콘이 들어간 칩을 누르면 해당 링크로 이동. 다크/라이트 두 가지 톤.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **칩**에서 [+]로 추가 → 아이콘 키워드·라벨·링크 입력 → 게시
3. (스크린샷처럼 두 줄이면 **다크 칩 위젯 1개 + 라이트 칩 위젯 1개**로 각각 만들어 위아래 배치)

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 테마 | outlined-textfield | 다크 | **다크** 또는 **라이트** |
| 칩(반복) | item | — | 칩별로 ↓ |
| └ 아이콘 키워드 | outlined-textfield | 가위 | 아래 키워드 표 참고 |
| └ 라벨 | outlined-textfield | 메뉴 | |
| └ 링크 | outlined-textfield | (빈값) | 이동 주소 |

## 아이콘 키워드 (내장 SVG)
| 입력 | 아이콘 |
|---|---|
| 가위 / 미용가위 / scissors | ✂ 가위 |
| 빗 / 브러시 / brush | 빗(콤) |
| 가위집 / 케이스 / box | 케이스 |
| 복원 / 수리 / AS / wrench | 렌치 |
| 상담 / 컨설팅 / 문의 / chat | 말풍선 |
| 후기 / 리뷰 / 별 / star | 별 |
| 홈 / home · 전화 / phone | 홈·전화 |

## 사용 예제 (스크린샷 재현)
- 다크 칩: 가위→미용가위(/44) · 빗→빗·브러시(/sideproduct) · 가위집→가위집(/37)
- 라이트 칩: 복원→복원수리(/60) · 상담→컨설팅(/61) · 후기→고객후기(...)

## 주의사항
- 아이콘은 **내장 SVG**(외부 라이브러리 아님). 키워드가 표에 없으면 아이콘 없이 라벨만.
- fetch·iframe 미사용.
