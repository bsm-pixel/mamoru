# 14. 스크롤 절단 히어로

## 기능 / 가치
화면에 들어오면 키커 → hairline(칼날 선)이 가로질러 그어지고 → 헤드라인이 떠오름. "CUT THE FAKE" 브랜드 첫인상을 임팩트 있게.

## 고객 경험
스크롤로 히어로가 보이는 순간 절제된 모션으로 문구가 순차 등장.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 배경(선택)·키커·헤드라인·서브·버튼 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 배경 이미지 | image | — | 비우면 단색 |
| 테마 | segmented-control | 다크 | 다크(보이드)/라이트(크림) |
| 키커(영문) | outlined-textfield | CUT THE FAKE… | |
| 헤드라인 | outlined-textfield | 좋은 미용가위… | |
| 서브 문구 | outlined-textfield | (빈값) | 비우면 숨김 |
| 버튼 문구/링크 | outlined-textfield | (빈값) | 비우면 버튼 숨김 |

## 주의사항
- 풀블리드 느낌 원하면 아임웹 위젯 영역을 전체 너비로. fetch·iframe 미사용.
