# D5. 듀얼 선택 배너

## 기능 / 가치
"제품 보러가기 / 복원수리 접수" 같은 **두 갈래 길**을 큰 이미지 타일 2개로. 디자인적이면서 내비게이션 역할.

## 고객 경험
큰 이미지 타일 위에 라벨·설명·화살표. 호버 시 이미지 확대. 모바일은 위아래 스택.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **타일**에서 [+]로 2개 추가 → 이미지·라벨·설명·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 설명 |
|---|---|---|
| 타일(반복, 2개 권장) | item | 타일별로 ↓ |
| └ 이미지 | image | 배경 |
| └ 큰 라벨 | outlined-textfield | |
| └ 작은 설명 | outlined-textfield | 비우면 숨김 |
| └ 링크 | outlined-textfield | 타일 클릭 시 이동 |

## 사용 예제
- 타일1: 제품 이미지 / "제품 보러가기" / 링크
- 타일2: 복원 이미지 / "복원수리 접수" / 링크

## 주의사항
- **2개**가 가장 깔끔(3개도 가로 배치 가능). fetch·iframe 미사용.
