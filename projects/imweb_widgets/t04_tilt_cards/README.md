# T4. 3D 틸트 제품 카드

## 기능 / 가치
마우스를 따라 카드가 살짝 3D로 기울어지는 프리미엄 인터랙션. 제품을 고급스럽게 보이게 함.

## 고객 경험
PC에서 카드 위에 마우스를 올리면 커서 방향으로 입체적으로 기울어지고 그림자가 깊어짐. (모바일은 일반 카드)

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **카드**에서 [+]로 카드 추가 → 이미지·제목·설명·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 설명 |
|---|---|---|
| 카드(반복) | item | 카드별로 ↓ |
| └ 이미지 | image | |
| └ 제목 | outlined-textfield | |
| └ 설명 | outlined-textfield | 비우면 숨김 |
| └ 링크 | outlined-textfield | 카드 클릭 시 이동 |

## 주의사항
- 틸트는 마우스(PC)에서만. 터치는 일반 카드로 동작. fetch·iframe 미사용.
