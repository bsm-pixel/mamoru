# D4. 대형 브랜드 인용 배너

## 기능 / 가치
"좋은 가위는 권하지 않습니다" 같은 **브랜드 한 문장**을 거대한 따옴표로 박는 선언형 배너. 여백·타이포로 조용히 압도.

## 고객 경험
큰 따옴표 + 대형 문구 + 서명. 진입 시 은은하게 떠오름.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 인용문·서명 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 테마 | segmented-control | 라이트 | 라이트(크림)/다크(보이드) |
| 정렬 | segmented-control | 가운데 | 가운데/왼쪽 |
| 인용문 | outlined-textfield | 좋은 가위는… | |
| 출처/서명 | outlined-textfield | (빈값) | 비우면 숨김 |

## 주의사항
- 짧고 강한 한 문장일수록 효과적(브랜드 보이스). fetch·iframe 미사용.
