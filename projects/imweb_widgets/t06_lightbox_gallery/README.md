# T6. 라이트박스 사례 갤러리

## 기능 / 가치
복원 사례 썸네일을 격자로 보여주고, 클릭하면 큰 이미지 모달로 확대(좌우 이동). 사례를 몰입감 있게 보여줌.

## 고객 경험
썸네일 그리드 → 클릭 → 어두운 배경 위 확대 이미지 + 캡션. ‹ › 이동, ×·배경클릭·Esc 닫기.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **사진**에서 [+]로 사진·캡션 추가 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 사진(반복) | item | — | 사진별로 ↓ |
| └ 사진 | image | — | |
| └ 캡션 | outlined-textfield | (빈값) | 확대 시 하단, 비우면 숨김 |

## 사용 예제
- 복원 전후 사례 사진 12장 + "녹 제거 / 텐션 복원" 캡션

## 주의사항
- 모달은 **순수 DOM**(iframe 아님)이라 아임웹 규격 안전.
- 사진 많으면 자동 격자 + 지연로드(lazy). fetch·iframe 미사용.
