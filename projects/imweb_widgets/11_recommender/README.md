# 11. 가위 추천 진단 (가이드형)

## 기능 / 가치
질문 하나에 선택지를 누르면 **맞춤 모델 추천 카드 + 구매/상담 버튼**이 나타남. 망설이는 고객을 결정으로 이끄는 인터랙티브 전환 도구.

## 고객 경험
"어떤 가위를 찾으세요?" → [초보예요][커트 위주][장가위] 중 클릭 → 아래에 추천 모델(사진·이유·버튼)이 부드럽게 등장.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **선택지 & 추천**에서 [+]로 선택지 추가 → 버튼라벨·추천모델·설명·이미지·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 질문 | outlined-textfield | 어떤 가위를 찾으세요? | 상단 질문 |
| 추천 버튼 문구 | outlined-textfield | 자세히 보기 | 모든 추천 카드 CTA 공통 |
| 선택지 & 추천(반복) | item | — | 선택지별로 ↓ |
| └ 선택지 버튼 | outlined-textfield | 선택지 | 고객이 누르는 버튼 |
| └ 추천 모델명 | outlined-textfield | 추천 모델 | |
| └ 추천 설명 | text-editor | 추천 이유 | |
| └ 추천 이미지 | image | — | 비우면 숨김 |
| └ 추천 링크 | outlined-textfield | (빈값) | 비우면 버튼 숨김 |

## 사용 예제
- 선택지 "커트 위주" → 추천 "A2-55 / 가벼운 커트용" + 상품링크
- 선택지 "장가위 찾아요" → 추천 "롱 7.0인치" + 링크

## 주의사항
- ⚠️ 폼 제출(상담접수 직접전송)은 아임웹 fetch 금지로 불가 → **추천 링크로 상담/상품 페이지 연결**.
- 선택지는 2~5개 권장. fetch·iframe 미사용.
