# N4. 텍스트 마스크 헤드라인

## 기능 / 가치
거대한 글자 안으로 이미지가 비쳐 보이는 타이포그래피 헤드라인. 브랜드 이름·키워드를 프리미엄하게 각인.

## 고객 경험
"MAMORU" 같은 큰 글자 속에 가위·작업 사진이 채워져 보임. 진입 시 은은하게 떠오름.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 글자 속 이미지 + 헤드라인 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 글자 속 이미지 | image | — | 텍스처/사진 |
| 헤드라인 | outlined-textfield | MAMORU | **짧고 굵은** 단어가 효과적 |
| 아래 문구 | outlined-textfield | (빈값) | 비우면 숨김 |
| 정렬 | segmented-control | 가운데 | 가운데/왼쪽 |

## 주의사항
- **짧은 단어**(1~2단어)일수록 이미지가 잘 보임. 디테일 많은 사진보다 톤이 또렷한 이미지 권장.
- 미지원 브라우저는 검정 글자로 폴백. fetch·iframe 미사용.
