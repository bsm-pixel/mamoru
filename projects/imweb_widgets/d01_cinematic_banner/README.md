# D1. 시네마틱 이미지 배너 (Ken Burns)

## 기능 / 가치
풀폭 이미지가 천천히 확대(Ken Burns)되며 키커·헤드라인·CTA를 올린 고급 배너. 어디든 섹션 배너·프로모로 가장 범용적으로 재사용.

## 고객 경험
배경이 은은하게 줌인되고, 어둡게 깔린 위에 문구·버튼이 또렷이 보임.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 배경 이미지·문구·버튼 입력 → 게시 (전체 너비 배치 권장)

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 배경 이미지 | image | — | |
| 어둡게 | color-picker | 검정 50% | **검정의 투명도 슬라이더를 드래그**해 어둡기 조절(가독성). 투명도↑=더 어둡게 |
| 정렬 | segmented-control | 가운데 | 가운데/왼쪽 |
| 키커/헤드라인/서브 | outlined-textfield | — | 키커·서브 비우면 숨김 |
| 버튼 문구/링크 | outlined-textfield | (빈값) | 비우면 버튼 숨김 |

## 주의사항
- 밝은 이미지엔 "강", 어두운 이미지엔 "약" 권장(가독성). fetch·iframe 미사용.
