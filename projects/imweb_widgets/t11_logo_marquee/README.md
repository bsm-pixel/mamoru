# T11. 롤링 로고 띠 (Marquee)

로고 이미지들이 가로로 끊김없이 흐르는 띠. 아임웹 기본 "롤링 로고" 대체 + **가로 최대폭 지정** 가능(영역 확장해도 설정 폭에서 멈춤).

## 붙여넣기
아임웹 디자인모드 → 커스텀 위젯 → `widget.html`/`widget.css`/`widget.js`를 각 탭에.

## 패널 설정
| 항목 | 기본 | 설명 |
|------|------|------|
| 가로 최대폭 | 비움(꽉참) | **숫자 자유 입력**(예 1280). 영역 확장해도 이 폭에서 멈춤. full=꽉참 |
| 배경 컬러 | #5F5F5FFF | 띠 배경색(투명도 포함 8자리) |
| 로고 크기(px) | 20 | 로고 높이 |
| 로고 간 간격(px) | 48 | |
| 내부 상하 여백(px) | 10 | |
| 전환 속도(초) | 30 | 한 바퀴 시간(클수록 느림) |
| 방향 | 좌 | 좌 · 우 |
| 흑백 이미지 | off | 로고 흑백 처리 |
| 마우스 오버 시 정지 | off | |
| 롤링 로고(아이템) | — | 로고 이미지들(배경 투명 PNG 권장) |

## 동작 원리
- 숫자·컬러 설정 = JS가 CSS 변수로 주입 + `MutationObserver`로 패널값 변경 즉시 반영(편집기 실시간).
- 방향·흑백·정지 = CSS 속성선택자(즉시 반영).
- 끊김없는 흐름 = JS가 로고 세트를 화면폭 이상으로 채운 뒤 1회 복제 → `translateX(-50%)` 루프.
