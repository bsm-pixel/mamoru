# T9. 읽기 진행바 + 맨위로

## 기능 / 가치
페이지 스크롤 진행도를 상단(또는 하단) 얇은 바로 표시 + "맨 위로" 버튼. 긴 페이지의 읽기 UX·체류를 개선.

## 고객 경험
스크롤하면 상단 바가 차오르고, 어느 정도 내려가면 우측 하단에 ↑ 버튼이 나타남(클릭 시 맨 위로 부드럽게).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. **페이지에 1개만** 배치(어디든) → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 바 위치 | segmented-control | 상단 | 상단/하단 |
| 바 두께(px) | outlined-textfield | 4 | |
| 맨위로 버튼 | switch | ON | 끄면 버튼 숨김 |

## 주의사항
- 페이지 **전체 스크롤**을 추적(고정 바). 한 페이지에 1개만 넣으세요.
- fetch·iframe 미사용.
