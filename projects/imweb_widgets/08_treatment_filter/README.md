# 08. 시술별 가위 선택 가이드 (필터)

## 기능 / 가치
시술 태그(커트/틴닝/장가위/드라이)를 누르면 해당 시술에 적합한 모델만 보임. 초보 미용사의 선택 진입장벽을 낮춤.

## 고객 경험
상단 칩(전체·커트·틴닝…)을 누르면 아래 모델 카드가 해당 시술용만 필터링.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **모델**에서 [+]로 모델 추가 → 이름·이미지·**시술 태그(쉼표)**·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| '전체' 버튼 문구 | outlined-textfield | 전체 | |
| 모델(반복) | item | — | 모델별로 ↓ |
| └ 모델명 | outlined-textfield | | |
| └ 이미지 | image | — | 비우면 숨김 |
| └ 시술 태그 | outlined-textfield | (빈값) | **쉼표로 구분**: 커트,틴닝 |
| └ 상품 링크 | outlined-textfield | (빈값) | 카드 클릭 시 이동 |

## 사용 예제
- A2-55 / 태그 "커트,드라이" · 롱7.0 / 태그 "장가위"
- → 칩 "커트" 누르면 A2-55만 표시.

## 주의사항
- 칩은 입력한 태그에서 **자동 생성**됨. 태그 표기 통일(예: "커트"로 일관) 권장.
- fetch·iframe 미사용 / 탭당 1만 자 이내.
