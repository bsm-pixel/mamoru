# T8. 타이핑 헤드라인

## 기능 / 가치
"마모루는 **정직**입니다 / 마모루는 **기술**입니다 …" 처럼 단어가 타이핑되며 순환. 슬로건을 리듬감 있게 각인.

## 고객 경험
앞·뒤 고정 문구 사이에서 단어가 한 글자씩 입력·삭제되며 순환(커서 깜빡임).

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널에서 앞/뒤 문구 + **바뀌는 단어** 항목들 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 앞 고정 문구 | outlined-textfield | 마모루는 | |
| 뒤 고정 문구 | outlined-textfield | 입니다 | 비우면 숨김 |
| 정렬 | segmented-control | 가운데 | 가운데/왼쪽 |
| 바뀌는 단어(반복) | item(텍스트) | — | 순환할 단어들 |

## 사용 예제
- 앞 "마모루는" / 단어 [정직, 기술, 복원, 기준] / 뒤 "입니다"

## 주의사항
- fetch·iframe 미사용 / 탭당 1만 자 이내.
