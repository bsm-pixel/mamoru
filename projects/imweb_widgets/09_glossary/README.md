# 09. 미용가위 용어사전 (검색)

## 기능 / 가치
가위 용어를 검색·필터로 찾아보게 함. 교육 콘텐츠로 전문성·SEO·체류시간을 높임.

## 고객 경험
검색창에 "텐션" 입력 → 해당 용어만 즉시 필터. 비우면 전체 목록.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **용어**에서 [+]로 용어·뜻 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 검색창 안내문구 | outlined-textfield | 용어 검색… | placeholder |
| 용어(반복) | item | — | 용어별로 ↓ |
| └ 용어 | outlined-textfield | 용어 | |
| └ 뜻/설명 | text-editor | 뜻 | 서식 가능 |

## 사용 예제
- "텐션" → "가위 날의 맞물림 강도" / "약지걸이" → "..." / "수냉식" → "..."

## 주의사항
- 검색은 용어·설명 텍스트 모두에서 매칭. fetch·iframe 미사용.
