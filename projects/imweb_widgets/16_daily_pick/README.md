# 16. 오늘의 추천 모델

## 기능 / 가치
등록한 모델 풀에서 날짜 기준으로 매일 다른 1개를 추천 카드로 노출. "오늘은 뭘 추천하나" 재방문 동기를 만듦.

## 고객 경험
"오늘의 추천" 키커 + 모델 카드(이미지·설명·버튼). 날짜가 바뀌면 자동으로 다른 모델로 순환.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **추천 풀**에 모델들 추가 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 키커 | outlined-textfield | 오늘의 추천 | |
| 버튼 문구 | outlined-textfield | 자세히 보기 | 링크 없으면 숨김 |
| 추천 풀(반복) | item | — | 모델별로 ↓ |
| └ 모델명/이미지/설명/링크 | image·textfield·text-editor | — | |

## 주의사항
- 추천은 **날짜 기준 자동 순환**(같은 날 = 같은 추천). 풀에 5~14개 권장.
- fetch·iframe 미사용.
