# 13. 마감/컬러 옵션 미리보기

## 기능 / 가치
무광/유광/블랙 등 옵션을 누르면 제품 이미지가 즉시 그 마감으로 교체. 옵션을 눈으로 확인시켜 구매 확신을 높임.

## 고객 경험
큰 제품 이미지 + 아래 옵션 버튼. 버튼 클릭 → 이미지가 부드럽게 페이드되며 교체.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **옵션**에서 [+]로 옵션 추가 → 옵션명·이미지 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 기본값 | 설명 |
|---|---|---|---|
| 제목 | outlined-textfield | (빈값) | 비우면 숨김 |
| 이미지 비율 | segmented-control | 가로 | 옵션 이미지 비율 |
| 옵션(반복) | item | — | 옵션별로 ↓ |
| └ 옵션명 | outlined-textfield | 옵션 | 버튼에 표시 |
| └ 옵션 이미지 | image | — | 그 옵션의 제품 사진 |

## 사용 예제
- 무광(블랙 무광 사진) / 유광(광나는 사진) / 골드 → 클릭마다 교체

## 주의사항
- 옵션 이미지들은 **같은 각도·같은 비율**로 찍어야 자연스럽게 교체됨.
- 첫 옵션이 기본 표시. fetch·iframe 미사용.
