# T1. 스크롤 스토리텔링 (스티키)

## 기능 / 가치
PC에서 이미지가 한쪽에 고정된 채, 스크롤에 따라 장면(제목·내용)이 바뀌고 이미지도 전환. 브랜드 철학·스토리를 몰입감 있게 전달.

## 고객 경험
- PC: 왼쪽 이미지 sticky 고정, 오른쪽 장면들이 스크롤되며 활성 장면의 이미지로 전환.
- 모바일: 장면마다 이미지+텍스트가 위아래로 흐름.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **장면**에서 [+]로 장면 추가 → 이미지·제목·내용 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 설명 |
|---|---|---|
| 장면(반복) | item | 장면별로 ↓ |
| └ 이미지 | image | 그 장면의 사진 |
| └ 제목 | outlined-textfield | |
| └ 내용 | text-editor | |

## 주의사항
- 장면 2~5개 권장. 위젯 영역을 충분히 넓게(전체 너비) 배치하면 sticky 효과가 살아남.
- fetch·iframe 미사용.
