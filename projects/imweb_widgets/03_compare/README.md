# 03. 가위 스펙 비교표

## 기능 / 가치
모델 2~3개를 나란히 놓고 무게·길이·강재·용도를 비교. 모델 선택 망설임을 줄여 구매 결정을 가속.

## 고객 경험
PC=나란히 카드, 모바일=가로 스크롤(스냅). 각 카드에 이미지·스펙·"자세히 보기" 버튼.

## 아임웹 삽입 방법
1. 커스텀 위젯 → HTML/CSS/JS 3탭 붙여넣기
2. 패널 **모델**에서 [+]로 모델 추가 → 이름·이미지·스펙·링크 입력 → 게시

## 패널 설정 항목
| 항목 | @type | 설명 |
|---|---|---|
| 모델(반복) | item | 모델별로 ↓ |
| └ 모델명 | outlined-textfield | |
| └ 이미지 | image | 비우면 숨김 |
| └ 무게/길이/강재/용도 | outlined-textfield | 비우면 — 표시 |
| └ 상품 링크 | outlined-textfield | 비우면 버튼 숨김 |

## 사용 예제
- A2-55 / 55g / 5.5인치 / VG10 / 커트
- 롱7.0 / 62g / 7.0인치 / 코발트 / 장가위

## 주의사항
- 모델 2~3개 권장(4개 이상이면 모바일 가독성↓).
- fetch·iframe 미사용 / 탭당 1만 자 이내.
