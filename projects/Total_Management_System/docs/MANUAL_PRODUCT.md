# 🏷️ 제품관리 사용 매뉴얼

> 최종 업데이트: 2026-06-13 · 대상: 처음 쓰는 분도 따라할 수 있게

## 0. 제품관리 한눈에 (먼저 읽기)

파는 제품(가위·빗·케이스 등)의 **정보·가격·시리얼·재고**를 등록·관리하는 화면입니다.

**기본 흐름**: 제품 등록 → 시리얼 일괄 생성(가위) → 창고 이동(보관→준비) → 판매. 사이드바 → **상품·재고 → 제품**.

**알아둘 3가지**:
1. **가격 4단**: 소매가 / 딜러가 / 아카데미가 / 매입가 — 고객 유형에 맞춰 판매 시 자동 적용
2. **시리얼**(가위만): 한 자루마다 고유번호 `MR2610816` (마모루 정품·보증 추적). B2B 납품은 시리얼 없음
3. **창고 3단**: 보관(매입원본) → 준비(각인완료, B2C출고) → 디스플레이(전시)

> 💡 우측 상단 **"라벨 디자이너"** 버튼으로 바코드/시리얼 라벨을 직접 디자인, 제품 상세에서 **"바코드 라벨 출력"** 가능. [라벨 매뉴얼](MANUAL_LABEL.md)

## 1. 제품 등록

### 1-1. 아임웹 등록 → TMS 동기화

아임웹 쇼핑몰에 상품을 먼저 등록한 경우:

1. 아임웹 관리자에서 상품 등록 (이름, 가격, 상품번호 확인)
2. TMS → **설정** → **상품 동기화** 클릭
3. 아임웹 상품이 TMS에 자동 등록됨 (이름, 가격, 아임웹 상품번호 매핑)
4. TMS에서 추가 정보 입력: SKU, 매입가, 딜러가, 아카데미가, 카테고리 등

> **주의**: 아임웹 동기화는 상품 정보만 가져옴. 시리얼/재고는 TMS에서 별도 관리.

### 1-2. TMS 직접 등록

아임웹 없이 TMS에서 직접 등록하는 경우:

1. TMS → **제품** → **[+ 제품 등록]** 클릭
2. 필수 입력:
   - **제품명**: 예) 마모루 블런트 6.0
   - **SKU**: 예) MAM-BL-060 (카테고리-모델-사이즈)
   - **카테고리**: BL(블런트) / TH(틴닝) / LO(장가위) / SL(슬라이싱)
   - **소매가**: 고객 판매가
3. 선택 입력:
   - **딜러가**: B2B 딜러 거래 가격 (딜러 고객 선택 시 자동 적용)
   - **아카데미가**: 아카데미 거래 가격 (아카데미 고객 선택 시 자동 적용)
   - **매입가**: 원가 (마진 계산용)
   - **매입처**: B2B 거래처에서 선택
   - **아임웹 상품번호**: 아임웹 연동 시 매핑용

### 1-3. TMS 먼저 등록 후 아임웹에도 등록하는 경우 (중복 방지)

> **주의**: 동기화는 `아임웹 상품번호` 기준으로 매칭합니다. TMS에 먼저 등록한 제품의 아임웹 상품번호가 비어있으면 동기화 시 **중복 생성**됩니다.

**올바른 순서:**
1. TMS에서 제품 등록
2. 아임웹에서 같은 제품 등록 → **아임웹 상품번호** 확인
3. TMS → 해당 제품 상세 → [수정] → **아임웹 상품번호** 입력 → [저장]
4. 이후 동기화 시 아임웹 상품번호로 매칭되어 **업데이트만** 발생 (중복 없음)

**또는** 아임웹에 먼저 등록 → TMS 동기화 → TMS에서 추가 정보(딜러가, 매입가 등) 입력하는 순서가 더 안전합니다.

### 1-3. 4단 가격 체계

| 가격 | 대상 | 자동 적용 |
|------|------|----------|
| 소매가 | 일반 고객 (retail/online) | 기본 |
| 딜러가 | 딜러 거래처 (dealer) | 고객 유형이 '딜러'일 때 자동 |
| 아카데미가 | 아카데미 거래처 (academy) | 고객 유형이 '아카데미'일 때 자동 |
| 매입가 | 내부 참고용 | 마진/COGS 계산에 사용 |

> 판매 입력 시 고객을 선택하면 해당 고객의 유형에 맞는 가격이 자동으로 적용됨.

### 1-4. 제품군 (product_group) — 리뷰 그룹핑

동일 시리즈 제품(R4-58ST, R4-58-MS 등)의 리뷰를 묶어서 표시하려면 **제품군**을 설정합니다.

1. 제품 상세 → [수정]
2. **제품군 (리뷰 그룹)** 필드에 그룹 키 입력 (예: `R4`, `M5`, `CS600`)
3. 같은 시리즈 제품은 **동일한 값** 입력

| 예시 제품 | product_group |
|-----------|---------------|
| R4-58ST | R4 |
| R4-58-MS | R4 |
| R4-60ST | R4 |
| M5-58 | M5 |

아임웹 상품 페이지에서 자동으로 해당 그룹의 리뷰가 표시됩니다.

## 2. 시리얼 관리

### 2-1. 시리얼이 필요한 경우 / 불필요한 경우

| 거래 유형 | 시리얼 필요 | 이유 |
|-----------|-----------|------|
| B2C 마모루 판매 | ✅ 필요 | 마모루 로고 각인, 정품인증 |
| B2B 딜러/아카데미 납품 | ❌ 불필요 | 딜러 브랜드 로고, 딜러 쪽에서 관리 |
| 온라인 판매 | ✅ 필요 | 마모루 제품, 정품인증 |

### 2-2. 시리얼 등록 방법

#### 단건 등록
1. TMS → **제품** → 제품 선택 → **시리얼 관리** (또는 시리얼 관리 & 조회 → 제품별 관리)
2. 시리얼 번호 입력 → [등록]

#### 일괄 등록 (자동 채번)
1. **수량**만 입력 (1~N) — 시작번호 직접입력 불필요
2. **로트번호**: 생산 배치 식별 (선택)
3. [일괄 생성] → `MR2610816`부터 **자동 연속** 생성

**예시**: 수량 `10` → `MR2610816 ~ MR2610825` (10개). 형식 = `MR{연도2}{5자리 누적}`, 연도 바뀌어도 리셋 없음. [시리얼 매뉴얼](MANUAL_SERIAL.md)

### 2-3. 정품인증 (verify_token)

- 시리얼 생성 시 **정품인증 토큰**이 자동 생성됨 (12자리 고유 코드)
- 고객이 QR 코드 또는 URL로 정품 여부 확인 가능
- 시리얼 번호 자체는 노출되지 않음 (보안)

## 3. 창고 관리 (3단계 Zone)

### 3-1. 창고 구분

```
보관 (raw)  →  준비 (ready)  →  디스플레이 (display)
  │                │                   │
  │                │                   └── 고객에게 보여주는 샘플
  │                └── 마모루 로고 각인 완료, B2C 출고 가능
  └── 매입 원본 그대로, B2B 딜러에게 딜러 로고 각인 후 출고
```

| 창고 | 코드 | 역할 | 판매 대상 |
|------|------|------|----------|
| **보관** | raw | 매입 원본 보관. B2B 딜러에게 딜러 로고 각인 후 출고 | B2B 딜러/아카데미 |
| **준비** | ready | 마모루 로고 각인 + 포장 완료. B2C 출고 가능 상태 | B2C 고객 (오프라인/온라인) |
| **디스플레이** | display | 쇼케이스/매장 전시 샘플. 판매도 가능 | B2C 고객 (매장 방문) |

### 3-2. Zone 전환 방법

#### 개별 전환
- 시리얼 관리 페이지에서 각 시리얼 옆 드롭다운으로 zone 변경

#### 일괄 전환
1. 체크박스로 여러 시리얼 선택
2. 상단 버튼: [준비로 이동] / [디스플레이로 이동] / [보관으로]

### 3-3. 일반적인 워크플로우

**매입 입고 시:**
1. 공장에서 가위 도착 → 시리얼 일괄 등록 (zone: `보관`)

**B2C 판매 준비:**
2. 마모루 로고 레이저 각인 작업
3. 각인 완료 → zone을 `보관` → `준비`로 이동
4. 쇼케이스 전시할 것은 `준비` → `디스플레이`로 이동

**B2B 딜러 납품:**
2. 딜러 브랜드 로고 각인 작업
3. 시리얼 없이 판매 입력 (수량 + 딜러가)

### 3-4. 판매 시 시리얼 선택

- **판매 입력 → 시리얼 선택 가능 zone**: `준비` + `디스플레이`만
- `보관` zone은 시리얼 선택 목록에 표시되지 않음 (B2B는 시리얼 없이 판매)
- 디스플레이 시리얼은 `디스플레이` 뱃지가 표시됨

### 3-5. 판매 취소 시 Zone 자동 복원

- 판매 시 해당 시리얼의 zone이 기록됨 (`previous_zone`)
- 판매 취소 시 원래 zone으로 자동 복원
- 예: 디스플레이에서 판매 → 취소 → 다시 디스플레이로 복귀

## 4. 판매 연동 흐름

### 4-1. B2C 판매 (마모루 브랜드)

```
제품 등록 → 시리얼 일괄 등록 (보관)
  → 마모루 각인 → zone: 준비로 이동
  → 판매 입력 → 고객 선택 → 시리얼 선택 → 결제
  → 시리얼: sold 상태, 재고 -1
  → (취소 시) 시리얼: in_stock 복원, zone 복원, 재고 +1
```

### 4-2. B2B 딜러/아카데미 납품

```
제품 등록 (딜러가/아카데미가 설정)
  → 딜러/아카데미 고객 등록 (고객 유형: dealer/academy)
  → 판매 입력 → 딜러 고객 선택 → 딜러가 자동 적용
  → 시리얼 선택 없이 수량+금액만 입력
  → 결제상태 관리 (미수금/결제완료)
```

### 4-3. 온라인 판매 (아임웹)

```
아임웹 주문 발생 → TMS 자동 동기화
  → 주문관리에서 확인 → 송장 생성 (ALPS)
  → 아임웹에 송장번호 자동 입력
  → TMS 재고 자동 차감 (주문 시) / 복원 (취소 시)
```

### 4-4. 계약서 연결

```
매장 방문 상담 → 계약서 작성 (제품 선택 + 서명)
  → 계약서 이미지 자동 생성 → Supabase Storage 저장
  → [판매 전환] 클릭 → 판매 입력 화면으로 이동 (고객/제품 자동 기입)
```

## 5. 재고 관리

### 5-1. 재고 = 시리얼 수

- `재고 수량` = `in_stock` 상태인 시리얼 개수 (zone 무관)
- 시리얼 등록 → 재고 +1
- 판매 → 재고 -1
- 판매 취소 → 재고 +1

### 5-2. 아임웹 재고 동기화

- TMS에서 재고 변동 시 아임웹 재고도 자동 반영
- 입고(시리얼 등록), 판매, 조정, 취소 모두 연동
- 설정 → **상품 동기화**에서 아임웹 상품번호가 매핑된 제품만 동기화

### 5-3. 재고 현황 페이지

- **보관**: 매입 원본 수량
- **준비**: 각인 완료, 출고 가능 수량
- **디스플레이**: 전시 중 수량
- **저재고 알림**: 재고 3개 이하 시 빨간색 표시

## 6. SKU 체계 (자동 채번)

- **TMS에서 직접 등록**: SKU 자동 = **카테고리코드 + 번호** → 블런트 `BL001`, 슬라이싱 `SL003` (자릿수 설정 있으나 현재 3자리 고정). 수정 가능.
- **아임웹에서 가져온 제품**: SKU = **`IW-{아임웹 상품번호}`** (예 `IW-91`). 화면에선 보통 숨김(내부 코드).

| 카테고리 | 코드 |
|---------|------|
| 블런트 BL · 틴닝 TH · 장가위 LO · 슬라이싱 SL · 빗 CB · 케이스 CS · 부자재 SUP |

> 바코드 라벨의 바코드 = 이 SKU를 인코딩 → 스캔하면 그 제품으로 매칭됩니다.

## 7. FAQ

**Q: B2B 딜러에게 파는 가위도 시리얼을 등록해야 하나요?**
A: 아니요. B2B 납품은 딜러 브랜드 로고로 각인하므로 마모루 시리얼이 불필요합니다. 판매 입력 시 시리얼 선택 없이 수량과 금액만 입력하세요.

**Q: 디스플레이 가위를 팔면 재고에서 빠지나요?**
A: 네. 디스플레이 zone의 시리얼도 판매 가능하며, 판매 시 `sold` 상태로 변경되고 재고에서 차감됩니다.

**Q: 판매 취소하면 가위가 어느 창고로 돌아가나요?**
A: 판매 시 기록해둔 원래 zone으로 자동 복원됩니다. 준비에서 팔았으면 준비로, 디스플레이에서 팔았으면 디스플레이로 돌아갑니다.

**Q: 아임웹에 등록 안 한 제품도 TMS에서 관리할 수 있나요?**
A: 네. TMS에서 직접 등록하면 됩니다. 아임웹 상품번호 없이도 시리얼·재고·판매 모두 관리 가능합니다. 단, 아임웹 재고 동기화는 상품번호가 매핑된 제품만 작동합니다.

**Q: 보관 창고 가위를 바로 고객에게 팔 수 있나요?**
A: 시리얼 선택 시 `준비`와 `디스플레이` zone만 표시됩니다. 보관 가위를 B2C 판매하려면 먼저 마모루 각인 후 `준비` zone으로 이동하세요.
