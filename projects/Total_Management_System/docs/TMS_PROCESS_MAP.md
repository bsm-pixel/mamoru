## 2. 모듈 간 데이터 흐름

### 상담 → 계약서 → 판매
```
상담 접수 → 상담 확정 → 상담 완료
                          ↓
                     계약서 작성 (customer_name, customer_phone 전달)
                          ↓
                     판매 입력 (contract_id 연결)
                          ↓
                     시리얼 sold + 재고 차감 + 아임웹 동기화
```
**연동 키**: 상담.customer_phone → 계약.customer_phone → 판매.contract_id

### 복원수리 → 회계
```
복원수리 접수 → 비용안내 → 입금확인(paid_at)
                                ↓
                          회계 리포트 매출 집계 (repair_sales)
                          복원수리 매출 카드 (대시보드/복원수리 페이지)
```
**연동 키**: repairs.paid_at → 회계 API에서 기간별 합산

### 판매 → 고객 → 회계
```
판매 등록 → 미수금 자동 반영 (customer.outstanding_balance)
         → 시리얼 상태 변경 (in_stock → sold)
         → 재고 차감 (stock_quantity, raw_stock)
         → 아임웹 재고 동기화
         → 회계 매출 집계

판매 취소 → 위 모든 것 역전 (시리얼 복원, 재고 복원, 미수금 차감)
```

### 주문(아임웹) → 송장 → 배송
```
아임웹 주문 발생 → Cron 동기화 → TMS orders 테이블
                                    ↓
                              송장 생성 (ALPS)
                                    ↓
                              아임웹 송장 입력 (push-invoice)
                                    ↓
                              배송 추적 Cron → 배송완료 → 리뷰 요청 알림톡
```

### 고객 ← 모든 모듈
```
고객 상세 페이지
  ├── 통합 타임라인 (판매 + 계약 + 상담 + 복원수리)
  ├── 거래 요약 (총 판매액, 미수금, 최근 거래일)
  ├── RFM 분류 (VIP / 일반 / 휴면)
  └── 미수금 추적 (outstanding_balance)
```

## 4. Cron 작업

| 스케줄 | 경로 | 기능 | 연동 |
|--------|------|------|------|
| */10 * * * * | /api/cron/send-reminders | 상담 리마인더 | 알림톡 |
| 0 0 * * * | /api/cron/sync-orders | 아임웹 주문 동기화 | orders 테이블 |
| 0 0 * * * | /api/cron/track-delivery | 배송 추적 | orders 상태 변경 |
