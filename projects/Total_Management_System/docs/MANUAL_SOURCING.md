# 🧪 샘플 소싱 사용 매뉴얼

> 최종 업데이트: 2026-06-13 · 대상: 처음 쓰는 분도 따라할 수 있게 · 위치: 사이드바 상품·재고 → 샘플 소싱

**이 도구는?** 1688에서 들여온 신상 샘플을 **놓치지 않게 관리 + 실테스트 후 골라내는** 도구입니다. 합격한 제품만 리스트로 뽑아서 **등록은 직접** 합니다. (이 도구가 아임웹/제품에 자동 등록하지 않음)

---

## 1. 새 소싱 만들기

1. **샘플 소싱** 메뉴 → **[새 소싱]** 클릭 → 작업 화면 진입
2. 상단:
   - **회차명**(선택): 예) "5월 가위집 1차" — 안 적어도 됨
   - **환율 1¥ = ___ 원**: 현재 환율 입력 (예 195). → 라벨 한화 가격에 적용됨

## 2. 품목 입력 (STEP 1)

품목마다 아래를 입력 (위에서부터):
```
🏢 회사명 · 회사링크      ← 어느 공장인지 (업체 선정용)
   📷 제품 이미지          ← 1688 이미지 복사 → 붙여넣기 (Ctrl+V) 또는 업로드
   품목링크               ← 그 제품의 1688 페이지
   품목명 · 단가¥ · MOQ
   특징메모
```
- **제품 이미지**: 1688에서 이미지 복사 → 이미지칸 **클릭 후 Ctrl+V** (또는 [+]로 파일 업로드). **서버에 저장돼 나중에 열어도 보임.** → 도착 후 일일이 사진 찍을 필요 없음
- **단가**는 소수점 OK (예 `3.33`) → 옆에 **≈ ₩649** 자동 표시
- **[품목 추가]** 로 계속 추가 (추가 즉시 저장 → 이미지 바로 붙여넣기 가능)

### 💡 복제 버튼 ⎘ (삭제 왼쪽) — 같은 업체 여러 품목 빠르게
- 한 회사에서 여러 제품 봤을 때: 한 품목 입력 후 **복제** → 회사명·회사링크는 그대로, **새 바코드** 부여
- 복제된 품목에서 **품목링크·품목명·단가만 바꾸면** 끝

> 같은 회사명은 복제로 정확히 복사 → 나중에 "업체별 채택 현황"이 안 깨집니다.

## 3. 라벨 인쇄 (STEP 2)

라벨 = **QR + 번호 + 품목명 + 한화가격**

1. **라벨 사이즈** 선택 (40×20mm 권장)
2. 품목별 **[매수]** 조절 (− N +): 한 제품에 여러 장 붙일 거면 숫자 올리기
3. **[라벨 N장 인쇄]** → 인쇄 → 라벨프린터 출력 → 샘플에 부착

### KM-106D(또는 라벨프린터) 최초 1회 세팅 ⚠️ 필수
1. 윈도우 설정 → 프린터 → KM-106D → **인쇄 기본 설정**
2. **용지 크기 = 사용자 정의 → 라벨 크기(예 40×20mm), 여백 0**
3. 라벨지 끼우고 **갭 캘리브레이션**: 전원 OFF → FEED 누른 채 ON
4. 인쇄 다이얼로그: 그 용지 / **여백 없음 / 배율 100% / 머리글·바닥글 끄기**

> 이 세팅을 안 하면 라벨이 종이 구석에 찍힙니다. (한 번만 하면 됨)

## 4. 입고 (물건 도착) — 라벨만 붙이면 끝

도착한 제품에 **인쇄한 라벨을 맞춰 붙이면** 어느 게 어느 품목인지 파악됩니다. 제품 이미지는 STEP 1에서 이미 넣었으니 **도착품을 일일이 사진 찍을 필요 없습니다.**

> 📌 (선택) 실물이 1688 이미지와 많이 다르거나 메모를 남기고 싶으면 — 라벨 QR을 폰/PC 스캐너로 스캔 → 입고매칭 화면에서 사진·메모 추가 가능. **필수 아님.**

### (선택) 스캔으로 품목 열기

**방법 A — 폰** (사진 촬영 편함)
1. 폰으로 TMS 로그인 1회
2. 라벨 QR 카메라로 스캔 → 입고매칭 화면 열림
3. **사진 촬영** → 메모 → **[매칭 완료]**

**방법 B — PC + 바코드 스캐너** (책상에서 빠름)
1. `/sourcing` 상단 **스캔 박스에 커서** 두기
2. 가위 집어서 **스캐너로 라벨 QR 스캔** → 그 품목 화면 자동 열림
3. 사진은 파일 업로드 (PC엔 카메라 없음)

> 매칭 후 다시 스캔해도 그 품목이 또 열립니다. 사진 있으면 보이고, 없으면 추가.

## 5. 선별 (STEP 3)

- 사진 보고 품목별 **[채택]** / **[탈락]**
- 상단 **업체별 채택 현황**: `光达美容工具 채택 3/3` · `C工具 채택 2/5` …
  → **"이 공장에 좋은 게 많네"** 한눈에 → 업체 선정 판단

## 6. 선별 리스트 → 등록 (STEP 4)

1. 채택된 것만 **선별 리스트**에 모임 (회사명·회사링크·품목링크·단가·사진)
2. **[리스트 복사]** → 엑셀/시트에 붙여넣기 (탭 구분)
3. 이 리스트 보고 **아임웹/TMS에 직접 제품 등록**

## ❓ 자주 묻는 것

| 질문 | 답 |
|------|-----|
| 색상별로 나눠야 하나? | ❌ 한 모델=한 품목. 색상은 아임웹 옵션. ("따로 결정할 거 아니면 안 나눔") |
| 수량은 어디 입력? | 이 단계는 수량 아닌 **선별**이라 수량 없음 |
| 채택하면 제품 등록됨? | 자동은 아님. 단 선별리스트에서 **[제품등록]/[부자재등록]/[기존 연결]** 버튼으로 바로 등록·연결 가능(아래) |
| 탈락 품목 삭제? | 기록 남겨두면 같은 거 또 주문하는 실수 방지 (권장) |
| QR에 뭐가 들었나? | 입고매칭 페이지 주소 → 스캔하면 그 품목 열림 |

## 2026-06-01 추가 기능

- **제품 이미지**: 주문할 때 1688 이미지 복사 → 품목 이미지칸 **클릭 후 Ctrl+V**(또는 업로드). 도착품은 라벨만 붙이면 됨(촬영 불필요).
- **라벨**: 가격은 라벨에 안 박힘(QR+번호+품목명). 가격은 상단 **[가격 리스트(A4)]** 버튼으로 따로 출력.
- **품목별 즉시 인쇄**: STEP1 품목 우측 **[라벨인쇄]** 칩 → 사이즈·수량 정하고 그 품목만 바로 인쇄.
- **등록/연결** (STEP4 선별리스트): **[부자재로 등록]**(가위집 등) / **[제품으로 등록]** / **[기존 제품 연결]**. 등록하면 그 제품·부자재 상세에 소싱 정보(업체·링크·단가)가 보임. (아임웹 등록은 여전히 직접)
