# 🛒 주문관리 사용 매뉴얼

> 최종 업데이트: 2026-08-23 · 대상: 처음 쓰는 분도 따라할 수 있게

> **🆕 2026-08-23 변경**: **송장 생성 버튼 한 번**이면 아임웹 쇼핑몰도 **자동으로 "배송대기"**가 됩니다.
> (예전처럼 아임웹 관리자에서 직접 "배송대기 처리"할 필요 없음.) 기사님이 물건을 가져가면(집하) 아임웹이 **자동으로 "배송중"**으로,
> 배송이 끝나면 **자동으로 "배송완료"**가 됩니다. 즉 사장님은 **송장 생성**만 누르면 나머지는 알아서 굴러갑니다.

## 0. 주문관리 한눈에 (먼저 읽기)

**아임웹 쇼핑몰(온라인) 주문**을 TMS에서 보고 처리하는 화면입니다. (매장·출장 판매는 `판매관리`에서 따로)

**기본 흐름**: 아임웹 주문 발생 → (자동으로 들어옴) → TMS에 뜸 → **송장 생성** → 출고 → (자동) 배송완료. 사이드바 → **주문관리**.

- 주문은 대부분 **자동**으로 들어오고 재고도 자동 차감됩니다. 직원은 주로 **송장 생성**만 하면 됩니다.
- 배송완료되면 후기 요청 알림톡도 자동으로 나갑니다.
- **급하면** 상단 **"아임웹 동기화"** 버튼으로 최신 주문을 바로 당겨올 수 있습니다.

**이 화면에서 하는 일 (요약)**
| 상황 | 무엇을 누르나 |
|------|--------------|
| 온라인 주문 발송 | 주문 선택 → **송장 생성** |
| 고객이 매장에서 직접 받아감 | 주문 선택 → **직접수령 완료** |
| 미용가위 개별번호(시리얼) 기록 | 주문 선택 → **배정 시리얼 → 배정** |
| 주문 취소 | 주문 선택 → **주문 취소** (재고 자동 복구) |

## 1. 개요

주문관리는 **아임웹 쇼핑몰 주문**을 TMS에서 통합 관리합니다.

**데이터 흐름**: 아임웹 주문 → TMS 자동 동기화 (Cron 또는 수동)

---

## 2. 화면 구성

### 상단
- **검색**: 주문번호, 고객명, 송장번호
- **기간 필터**: 전체 / 오늘 / 이번주 / 이번달
- **아임웹 동기화** 버튼: 최신 주문 가져오기

### 상태 탭 (9개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 전체 | - | 모든 주문 |
| **입금대기** | pay_wait | **무통장 미입금** — 입금 기다리는 중 (입금되면 결제완료로, 안 하면 자동취소) |
| 결제완료 | pay_done | 결제 완료, **송장 생성 필요** |
| 준비중 | preparing | 상품 준비 중 |
| **배송대기** | ready_to_ship | **송장 생성 완료, 기사님 픽업 대기** (아임웹도 배송대기) — 🆕 |
| 배송중 | shipping | 기사님이 가져감(집하) 이후 (아임웹도 배송중) |
| 배송완료 | delivered | 고객 수령 |
| ALPS취소대기 | cancel_pending | 택배사 취소 처리 중 |
| 취소 | cancelled | 취소/환불 완료 |

### PC 레이아웃
좌측 40% 목록 + 우측 60% 상세 패널 (ESC 키로 닫기)

---

## 3. 주문 목록

### 표시 정보
- 고객명 + 주문 상태 뱃지 + 결제 상태 뱃지
- 아임웹 주문번호
- 주문 일시
- 송장번호 (있을 경우)
- 수령자 메모 (말줄임)
- 금액 (원)

### 인라인 액션
- **송장생성**: 결제완료(pay_done) + 송장 없을 때 표시

---

## 4. 주문 상세 패널

### 표시 정보
- 주문번호 + 상태 뱃지
- 주문 일시
- **주문자 정보**: 이름, 연락처
- **배송지 정보**: 수령인, 연락처, 주소, 배송 메모
- **주문 상품**: 상품명, 옵션, 수량, 단가, 합계
- **결제 정보**: 결제 수단, 결제 금액

---

## 5. 가능한 액션

| 액션 | 언제 뜨나 | 설명 |
|------|------|------|
| 송장 생성 | 결제완료 + 송장 없음 | ALPS(롯데택배) 송장 자동 생성 → 아임웹에도 자동 입력 |
| **직접수령 완료** | 결제완료 + 송장 없음 | 매장 대면 픽업. 송장 없이 배송완료로 마감 (§9) |
| **주문 취소** | 결제완료 + 송장 없음 | 취소 + **재고·배정 시리얼 즉시 자동 복구** (§8) |
| 송장 취소 | 송장 있음 + 집하 전 | ALPS 송장 취소 |
| 아임웹 송장 연동 | 송장 생성 후 | 아임웹에 송장번호 다시 입력(자동 안 됐을 때) |
| ALPS 취소 확인 | ALPS취소대기 | 택배사 취소 처리 상태 확인 |

> 모든 취소·완료 액션은 **한 번 더 확인창**이 떠서 실수 방지됩니다.

> ⚠️ **아임웹 취소/수령은 따로**: TMS에서 취소하거나 직접수령 완료해도, **아임웹 쇼핑몰 관리자에서도 같은 처리를 해줘야** 합니다(시스템 제약상 아임웹으로 자동 전달이 안 됨). 처리 후 "아임웹에서도 처리해주세요" 안내가 뜹니다.

## 6. 재고 연동

### 자동 차감 (결제 시)
- 결제완료(pay_done) → `stock_quantity` - N, `raw_stock` - N
- `stock_deducted = true` 플래그로 중복 차감 방지

### 자동 복원 (취소/환불 시)
- cancelled/refunded → `stock_quantity` + N, `raw_stock` + N
- `stock_deducted = false`로 리셋
- **TMS에서 "주문 취소"를 누르면 즉시 복원**됩니다(예전엔 아임웹 동기화까지 기다렸음). 배정했던 **시리얼도 자동으로 재고로 되돌아갑니다.**
- 시리얼이 배정된 주문은 재고 계산이 자동으로 보정되니 직원이 손댈 필요 없습니다.

### 아임웹 재고 동기화
- 차감/복원 시 아임웹에도 자동 반영
- 디스플레이 시리얼은 제외하고 판매 가능 재고만 전달

---

## 7. 동기화 흐름

```
[아임웹 주문 발생]
       │
       ▼
[TMS Cron 또는 수동 동기화]
       │
       ▼
[orders + order_items 테이블 upsert]
       │
       ├─ 결제완료 → 재고 자동 차감 (stock + raw)
       ├─ 취소/환불 → 재고 자동 복원
       └─ 상태 변경 → TMS 반영 (cancel_pending 보호)
```

## 8. 시리얼(개별번호) 배정 — 미용가위

미용가위는 자루마다 **고유 시리얼번호**가 있어 보증·복원수리 때 추적합니다. 온라인 주문에도 **어떤 실물이 나갔는지** 기록할 수 있습니다.

### 배정 방법
1. 주문을 선택하면 우측 상세에 **"배정 시리얼"** 칸이 있습니다.
2. **배정**(또는 이미 있으면 **수정**) 버튼을 누릅니다.
3. 품목마다:
   - **재고에 시리얼이 등록돼 있으면** → 목록에서 나가는 번호를 고릅니다.
   - **재고에 없으면** → **"자동 번호생성"** 버튼(번호가 자동으로 만들어짐) 또는 직접 입력.
4. **저장**을 누릅니다. 배정된 번호가 상세에 표시됩니다.

### 알아둘 점
- **재고는 자동으로 맞춰집니다.** 시리얼을 배정해도 판매 가능 수량이 틀어지지 않게 시스템이 알아서 처리하니, 직원은 번호만 고르면 됩니다.
- **주문을 취소하면** 배정했던 시리얼도 **자동으로 재고로 되돌아갑니다.**
- 판매관리(매장 판매)의 시리얼 입력과 **똑같은 방식**입니다.

## 9. 직접수령(대면 픽업) 완료

고객이 **매장에 직접 와서** 아임웹으로(쿠폰 등) 결제하고 물건을 **그 자리에서 가져가는** 경우입니다. 택배 송장이 필요 없습니다.

### 처리 방법
1. 그 주문을 선택합니다. (상태: 결제완료)
2. 우측 상세 아래 **"직접수령 완료"** 버튼을 누릅니다.
3. 확인창에서 진행하면 → **송장 없이 배송완료로 마감**됩니다.
4. 주문에 **"직접수령"** 배지가 붙습니다. (나중에 매장 픽업 건을 구분해서 볼 수 있음)

### 자동으로 되는 것 / 직접 해야 하는 것
- ✅ **자동**: 후기 요청 알림톡 발송(택배 배송완료와 동일). 재고는 결제 때 이미 빠졌으므로 그대로.
- ⚠️ **직접**: **아임웹 쇼핑몰 관리자에서도** 그 주문을 수령/배송완료로 처리해 주세요(자동 전달 안 됨).
- 시리얼을 남기려면 위 **§8**대로 배정하면 됩니다.

## 10. 회계·매출 반영 (아임웹 온라인 주문)

아임웹 온라인 주문 매출은 **자동으로 집계**됩니다(2026-08-20부터). 직원이 따로 입력할 필요 없습니다.

- **메인 대시보드 "이번달 매출"**: 아임웹 온라인 주문이 **B2C 제품 매출에 합산**되어 표시됩니다.
- **회계 리포트(매출·손익)**: 아임웹 주문 매출이 "제품 매출"과 손익에 포함됩니다. (예전엔 원가만 반영돼 손익이 낮게 나오던 것을 수정)
- **결제수단별**: 아임웹 주문의 **카드 / 무통장입금(→이체로 분류)** 이 결제방식별 집계에 구분되어 잡힙니다.
- **인식 기준**: **결제완료 이상** 주문만 매출로 잡습니다(무통장 미입금=결제대기 주문은 제외). 배송비는 제품 매출에서 뺍니다.

> ⚠️ **무통장 미입금(결제대기)** 주문은 아직 매출·미수금 어디에도 안 잡힙니다. **입금되면** 그때 매출로 반영됩니다. (미입금을 미수금으로 자동 집계하는 기능은 추후 지원 예정)
