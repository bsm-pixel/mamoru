# 주문관리 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

주문관리는 **아임웹 쇼핑몰 주문**을 TMS에서 통합 관리합니다.

**데이터 흐름**: 아임웹 주문 → TMS 자동 동기화 (Cron 또는 수동)

---

## 2. 화면 구성

### 상단
- **검색**: 주문번호, 고객명, 송장번호
- **기간 필터**: 전체 / 오늘 / 이번주 / 이번달
- **아임웹 동기화** 버튼: 최신 주문 가져오기

### 상태 탭 (7개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 전체 | - | 모든 주문 |
| 결제완료 | pay_done | 결제 완료, 배송 준비 필요 |
| 준비중 | preparing | 상품 준비 중 |
| 배송중 | shipping | 발송 완료 |
| 배송완료 | delivered | 고객 수령 |
| ALPS취소대기 | cancel_pending | 택배사 취소 처리 중 |
| 취소 | cancelled | 취소/환불 완료 |

### PC 레이아웃
좌측 40% 목록 + 우측 60% 상세 패널 (ESC 키로 닫기)

---

## 3. 주문 목록

### 표시 정보
- 고객명 + 주문 상태 뱃지 + 결제 상태 뱃지
- 아임웹 주문번호
- 주문 일시
- 송장번호 (있을 경우)
- 수령자 메모 (말줄임)
- 금액 (원)

### 인라인 액션
- **송장생성**: 결제완료(pay_done) + 송장 없을 때 표시

---

## 4. 주문 상세 패널

### 표시 정보
- 주문번호 + 상태 뱃지
- 주문 일시
- **주문자 정보**: 이름, 연락처
- **배송지 정보**: 수령인, 연락처, 주소, 배송 메모
- **주문 상품**: 상품명, 옵션, 수량, 단가, 합계
- **결제 정보**: 결제 수단, 결제 금액

---

## 5. 가능한 액션

| 액션 | 조건 | 설명 |
|------|------|------|
| 송장 생성 | 결제완료 상태 | ALPS(롯데택배) API로 송장 자동 생성 |
| 송장 취소 | 송장 있음 + 집하 전 | ALPS 송장 취소 |
| 아임웹 송장 연동 | 송장 생성 후 | 아임웹에 송장번호 자동 입력 |
| 주문 취소 | - | 주문 취소 처리 (확인 모달) |
| ALPS 취소 확인 | cancel_pending | 택배사 취소 처리 상태 확인 |

> 모든 위험 액션은 **확인 모달**로 보호됩니다.

---

## 6. 재고 연동

### 자동 차감 (결제 시)
- 결제완료(pay_done) → `stock_quantity` - N, `raw_stock` - N
- `stock_deducted = true` 플래그로 중복 차감 방지

### 자동 복원 (취소/환불 시)
- cancelled/refunded → `stock_quantity` + N, `raw_stock` + N
- `stock_deducted = false`로 리셋

### 아임웹 재고 동기화
- 차감/복원 시 아임웹에도 자동 반영
- 디스플레이 시리얼은 제외하고 판매 가능 재고만 전달

---

## 7. 동기화 흐름

```
[아임웹 주문 발생]
       │
       ▼
[TMS Cron 또는 수동 동기화]
       │
       ▼
[orders + order_items 테이블 upsert]
       │
       ├─ 결제완료 → 재고 자동 차감 (stock + raw)
       ├─ 취소/환불 → 재고 자동 복원
       └─ 상태 변경 → TMS 반영 (cancel_pending 보호)
```
