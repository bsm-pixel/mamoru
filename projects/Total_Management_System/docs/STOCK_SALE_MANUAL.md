# 📦 재고판매(LS) 운영 매뉴얼

> 사무실 재고를 아임웹에서 고객에게 팔고, 접수 → 입금 → 발송 → 후기까지 TMS로 관리하는 시스템.
> 최초 작성 2026-07-21 · 코드 단계0~5 배포 완료 · **가동하려면 아래 "가동 전 준비" 5가지를 마쳐야 합니다.**

---

## 1. 한눈에 보는 전체 흐름

```
[고객]
  아임웹 재고판매 페이지 (폼 임베드)
        │  제품 담기 → 성함·연락처·배송지 입력 → 주문 접수
        ▼
  📱 알림톡 "주문 접수 + 입금 안내(계좌·금액)"  ← STOCK_RECEIVED
        │  고객이 계좌로 입금
        ▼
[사장님 · TMS]
  재고판매 메뉴 → 신규접수에서 해당 주문 클릭
        │  입금 확인했으면 [입금확인 → 판매 전환] 클릭
        ▼
  📱 알림톡 "입금 확인 완료"  ← STOCK_PAYMENT_CONFIRMED
  자동으로 판매관리에 등록 + 재고 차감 + (아임웹 연동상품이면) 아임웹 재고도 자동 반영
        ▼
  판매관리 → 해당 건 → 송장 생성(롯데택배) → 제품 포장·발송
        │  택배사 집하 감지되면 자동으로 "출고완료"
        ▼
  📱 알림톡 "출고 안내 (송장번호)"  ← SALES_SHIPPED (자동)
        ▼
  배송완료 감지 → 📱 알림톡 "후기 요청"  ← PURCHASE_REVIEW_REQUEST
        ▼
  고객이 후기 작성 → 아임웹 후기 페이지 '제품구매' 탭에 노출
```

**핵심**: 접수는 바로 판매가 되지 않습니다. **입금확인 버튼을 눌러야** 판매로 전환되고 재고가 빠집니다(계좌이체 입금 게이트).

## 2. 🚨 가동 전 준비 (이거 해야 실제로 돌아갑니다)

### ① 제품 등록 — 카테고리 "재고판매"
`TMS → 제품` 에서 팔 재고를 등록합니다.
- **카테고리**: `재고판매` 선택 (SKU가 `LS001`, `LS002`… 로 자동 채번됨)
- **판매가**: 고객에게 보일 특가
- **재고 수량**: 실제 보유 수량 (0이면 고객 폼에서 자동으로 안 보임 / "소진 완료")
- **사진(이미지)**: 카탈로그 카드에 나오는 사진. 없으면 회색 "MAMORU" 박스로 표시
- (선택) **정위치**: `창고 배치도`에서 어느 렉·칸에 뒀는지 지정하면 발송 시 찾기 쉬움

> 등록만 하면 고객 카탈로그(`/api/stock-sale/public/products`)에 **자동으로** 뜹니다. 별도 등록 불필요.

### ② 솔라피 알림톡 템플릿 4종 등록 + 카카오 검수
솔라피 콘솔에서 아래 템플릿을 등록하고 검수 신청(1~3영업일). **변수명은 아래를 그대로** 사용하세요.

| 템플릿(카톡) | 발송 시점 | 사용 변수 | 비고 |
|---|---|---|---|
| **STOCK_RECEIVED** | 고객 주문 접수 즉시(자동) | `#{name}` `#{order_number}` `#{items}` `#{total_amount}` `#{address}` | **본문에 입금 계좌·금액 안내를 넣으세요** (예: `국민 000000-00-000000 마모루`) |
| **STOCK_PAYMENT_NOTICE** | 입금안내 재발송(어드민 선택) | `#{name}` `#{order_number}` `#{total_amount}` | 접수 알림톡에 계좌를 이미 넣으면 거의 안 씀 |
| **STOCK_PAYMENT_CONFIRMED** | 입금확인 → 판매전환 시(자동) | `#{name}` `#{order_number}` `#{total_amount}` | "입금 확인됐고 곧 발송" 안내 |
| **PURCHASE_REVIEW_REQUEST** | 배송완료 후 후기요청(자동) | 후기 폼 링크(버튼) | 이미 정의돼 있으면 재사용. 버튼 URL은 `docs/SOLAPI_TEMPLATES_ORDERS.md` 참조 |

- `#{items}` 는 줄바꿈으로 "제품명 N개"가 여러 줄로 들어갑니다.
- `#{total_amount}` 는 숫자(원 단위)만 들어오니 템플릿에서 `원`을 붙이세요.
- 출고 알림톡(**SALES_SHIPPED**)은 판매관리가 이미 쓰는 템플릿이라 **추가 등록 불필요**(이미 있으면).

### ③ Make 시나리오 분기 추가
재고판매 알림톡은 **상담(consultation) 웹훅 시나리오**로 들어옵니다(EVENT와 동일 경로).
Make의 그 시나리오 라우터에 아래 **이벤트명** 분기를 추가하세요:
- `STOCK_RECEIVED` → STOCK_RECEIVED 템플릿 발송
- `STOCK_PAYMENT_NOTICE` → STOCK_PAYMENT_NOTICE 템플릿
- `STOCK_PAYMENT_CONFIRMED` → STOCK_PAYMENT_CONFIRMED 템플릿
- (`PURCHASE_REVIEW_REQUEST` 은 기존 제품구매 후기 분기 재사용)

### ④ 아임웹에 고객 폼 임베드
아임웹 디자인모드 → 재고판매용 페이지 → **코드위젯**에 아래 iframe 붙여넣기:
```html
<iframe src="https://page.mamoru.kr/projects/stock_sale/page_form.html?embed=1"
        style="width:100%;border:0;" scrolling="no"></iframe>
```
- 높이는 전역 헤더의 `banner-widget.js` 리사이저가 자동 조절(EVENT 폼과 동일 방식). **공통코드 수정 불필요.**
- 코드위젯 속성에서 '그리드 사용 안 함'.

### ⑤ 알림톡 토글 확인
`TMS → 설정 → 알림` 에서 재고판매 알림톡이 켜져 있는지 확인:
- `재고판매 접수`, `재고판매 입금확인` — (설정 키가 없어도 기본은 **발송됨**. 끄고 싶을 때만 OFF)
- `판매 출고 안내(sales_shipped)` — 출고 알림톡용, 켜져 있어야 함

## 3. 일상 운영 (주문이 들어오면)

1. **알림 옴** — 고객이 접수하면 사장님 앱에 푸시("새 재고판매 접수"). `TMS → 재고판매` 로 이동.
2. **신규접수 탭** — 주문 클릭 → 품목·금액·배송지 확인.
3. **입금 확인** — 계좌에 입금 들어왔으면 **[입금확인 → 판매 전환]** 클릭.
   - 재고가 자동 차감되고, 판매관리에 판매건(OS-번호)으로 등록됩니다.
   - 고객에게 "입금 확인" 알림톡 자동 발송.
4. **송장·발송** — `TMS → 판매관리` 에서 그 건을 찾아 **송장 생성(롯데택배)** → 제품 포장 후 발송.
   - 택배사 집하가 감지되면 **자동으로 "출고완료"** + 고객에게 출고 알림톡(송장번호).
5. **후기** — 배송완료가 감지되면 후기 요청 알림톡이 자동 발송(설정에 따라). 고객 후기는 아임웹 후기페이지 '제품구매' 탭에 뜹니다.

> **취소/오등록**: 재고판매 상세에서 [접수 취소]. 이미 판매전환된 건은 **판매관리에서** 취소하세요(재고 원복은 판매쪽 소관).

## 5. 자주 묻는 것 (FAQ)

**Q. 접수를 바로 판매로 넣으면 안 되나?**
계좌이체라 미입금 건이 판매·재고로 잡히면 꼬입니다. 그래서 "입금확인" 버튼을 게이트로 둡니다.

**Q. 같은 고객이 예전에도 있었으면?**
전화번호가 같으면 **자동으로 같은 고객**으로 묶입니다(하이픈 무관). 잘못 묶이면 고객 상세의 `[병합]`으로 수동 보정.

**Q. 재고가 아임웹에도 걸려 있는 제품이면?**
`imweb_product_no`가 연결돼 있으면 판매전환 시 **아임웹 재고도 자동 차감**됩니다(양방향).

**Q. 후기가 안 올라와요.**
① 솔라피 `PURCHASE_REVIEW_REQUEST` 템플릿이 검수 통과했는지 ② Make 분기 ③ 콘솔 템플릿 활성 — 이 3가지를 먼저 확인(외부 설정 문제일 확률이 높음).

**Q. 접수 알림톡이 안 가요.**
솔라피 템플릿 검수(1~3영업일) 전에는 발송 불가. 검수 통과 후 발송됩니다.

## 6. 기술 메모 (개발자용)

- 접수 저장: `event_submissions` 재사용, `kind='stock_sale'`로 EVENT와 분리(마이그 117). 접수번호 `SS-YYYYMMDD-NNN`.
- 판매 전환: `convertEventToSale(db, ev, {category:'LS', memoLabel:'재고판매 전환'})` — 재고차감·아임웹push·회계 자동. 판매번호 `OS-`.
- 공개 API: `GET /api/stock-sale/public/products`(카탈로그) · `POST /api/stock-sale/public/submit`(접수, **서버에서 가격 재조회**).
- 어드민: `/stock-sale` (`useEvents('all','stock_sale')` + 기존 `/api/events` 재사용, kind 파라미터).
- 후기: `reviews/info`·`reviews/submit` purchase 분기가 `orders`(아임웹) → 없으면 `offline_sales`(OS-) 순으로 조회. 품목→`products.imweb_product_no` 매핑으로 이미지 연동.
- 알림톡 템플릿/이벤트명: `src/lib/notification/make-webhook.ts` (`stock_received`/`stock_payment_notice`/`stock_payment_confirmed`).
- 재고 수량 로직은 일절 변경하지 않음(정합성 안전). 관련 메모리 `project_stock_sale_LS`.
