# 🔄 반품 · 교환 사용 매뉴얼

> 최종 업데이트: 2026-08-29 · 대상: 처음 쓰는 분도 따라할 수 있게

> **한 줄 요약**: 고객이 산 제품을 **바꾸거나(교환)** **돌려받을(반품)** 때 씁니다.
> 매장에서 지금 바로 받으면 **판매관리에서 끝**나고, 택배로 회수해야 하면 **반품·교환 메뉴**에서 수거·입고까지 추적합니다.

---

## 0. 먼저 알아두기 — 두 갈래

교환·반품은 **어디서 처리하냐가 두 갈래**입니다.

| 상황 | 어디서 | 결과 |
|------|--------|------|
| **매장에서 지금 물건을 받으며 교환/반품** | 판매관리 → 그 판매 → **제품 교환 / 반품 처리** | 그 자리에서 끝. 반품·교환 메뉴에 안 뜸 |
| **택배·방문으로 구 제품을 회수해야 함** | 판매관리에서 교환 접수 → **반품·교환 메뉴**에서 수거~입고 추적 | 회수 송장·진행상태를 계속 관리 |

> 즉 **반품·교환 메뉴(`/returns`)는 "택배로 돌려받아야 하는 건"만** 모이는 곳입니다. 매장 즉시 교환은 여기 안 뜨는 게 정상입니다.

---

## 1. 매장에서 지금 교환 (가장 흔함)

고객이 **매장에 와서 구 제품을 그 자리에서 반납**하고 새 제품을 받아가는 경우.

1. **판매관리** → 그 고객의 판매 건을 엽니다.
2. **제품 교환** 버튼을 누릅니다.
3. **① 반납받을 품목**(구 제품)을 고릅니다. → 시리얼 제품은 **반품창고**로 격리, 비시리얼은 판매가능 재고로 복구됩니다.
4. **② 교환해줄 새 제품**을 검색해 고릅니다.
5. **③ 새 제품 시리얼**:
   - 재고에 시리얼이 있으면 → 목록에서 선택
   - 없으면(미리 마킹 안 한 제품) → **자동생성** 또는 직접입력
6. **④ 구 제품 회수** → **"매장/직접 지금 받음"** 선택 (기본값).
7. **⑤ 차액**을 확인합니다. (비싼 걸로 바꾸면 추가징수, 싼 걸로 바꾸면 환불)
8. **교환 확정**.

✅ 이렇게 하면 구 제품은 반품창고로, 새 제품에 새 시리얼이 배정되고 **끝**입니다. 반품·교환 메뉴에는 뜨지 않습니다.

> ⚠️ **시리얼은 절대 덮어쓰지 않습니다.** 구 가위 시리얼과 새 가위 시리얼은 각각 따로 관리됩니다.

---

## 2. 택배로 구 제품을 회수하는 교환 (배송 판매건)

이미 택배로 나간 제품을 교환하는 경우 — 새 제품은 보내주고, 구 제품은 **롯데 택배로 회수**합니다.

### 2-1. 교환 접수 (판매관리)
1. **판매관리** → 그 판매 건 → **제품 교환**.
2. ①~③은 위와 동일(반납 품목·새 제품·새 시리얼).
3. **④ 구 제품 회수**에서 회수 방식을 고릅니다:
   - **택배수거**: 롯데 기사가 고객집 방문 회수 (가장 흔함)
   - **방문수거**: 예약일 지정
   - **고객 직접반납(나중)**: 고객이 나중에 직접 가져옴
4. **교환 확정** → 새 제품 배정 + **반품·교환 메뉴에 수거 건이 자동 생성**됩니다.
   - 접수되면 고객에게 **접수 알림톡**(`return_received`)이 나갑니다.

### 2-2. 수거·출고 처리 (반품·교환 메뉴)
사이드바 → **반품·교환**(`/returns`)으로 가서 방금 생긴 건을 엽니다.

- **롯데 반품 수거접수** 버튼: 누르면 **고객집 → 매장 회수 송장**이 자동 발행됩니다. (구 제품 회수용)
  - ⚠️ **접수 후 취소는 ALPS(롯데) 화면에서 수동**으로 해야 합니다. (롯데가 취소 API를 안 열어줌)
- **교환 출고 송장 발행** 버튼: 누르면 **새 제품 1개를 고객에게 보내는 송장**이 발행됩니다.
  - 원 주문에 여러 품목이 있어도 **교환품만** 담깁니다.

---

## 3. 반품·교환 메뉴 화면 보기

사이드바 → **주문·배송 > 반품·교환**.

### 상태 탭
| 탭 | 뜻 | 이럴 때 |
|----|-----|--------|
| **수거접수** | requested | 방금 접수됨. 회수 송장 발행 대기 |
| **수거예약** | pickup_scheduled | 롯데 수거접수 완료, 기사 방문 대기 |
| **입고완료** | inbound | 구 제품이 매장 도착 → 반품창고 확정 |
| **검수완료** | inspected | 구 제품 상태 확인 끝 |
| **완료** | completed | 교환/환불까지 전부 끝 |
| **취소** | cancelled | 이 건 취소 |

### 상세 패널
- **회수 송장 / 교환 출고 송장** 발행 버튼 (§2-2)
- **진행 막대**: 지금 어느 단계인지 + "지금 무엇을 하면 되는지" 안내
- **큰 버튼 = 지금 할 일** (예: 구 제품 도착 → "구 제품 입고완료")

---

## 4. 구 제품 회수 진행 순서

```
[교환 접수]
   │  (택배수거 선택 시 → 롯데 반품 수거접수 버튼)
   ▼
수거접수 → 수거예약 → 입고완료 → 검수완료 → 완료
                        │
                (구 제품이 반품창고로 확정)
```

- **직접반납·매장수거**는 수거예약을 건너뛰고 도착 즉시 **"구 제품 입고완료"**를 눌러도 됩니다.
- 각 단계에서 **큰 버튼(대표 액션)**만 누르면 됩니다. 헷갈리면 화면의 안내 문구를 따라가세요.

---

## 5. 순수 반품(환불) — 교환 없이 돌려주기

새 제품 없이 **돈만 돌려주는** 경우:

- **매장에서 지금** 받으면 → 판매관리 → 그 판매 → **반품 처리** 버튼. 재고 복구 + "반품 완료"로 마감됩니다.
- **택배로 회수**해야 하면 → 반품·교환 메뉴에서 진행 (회수 송장은 §2-2와 동일).

---

## 6. 복원수리 "정밀 재점검 재수거"

복원수리로 출고했던 가위를 **다시 점검하려고 회수**할 때 씁니다. (반품이 아니라 재점검용 회수)

- 복원수리 상세 → **정밀 재점검 재수거** 버튼 → 롯데 반품 수거접수(02)로 회수합니다.
- 이 건은 고객 알림톡이 나가지 않습니다(내부 회수).

---

## 7. 자주 하는 질문

**Q. 매장에서 교환했는데 반품·교환 메뉴에 왜 안 떠요?**
→ 정상입니다. 매장 즉시 교환은 판매관리에서 바로 끝나므로 이 메뉴엔 안 뜹니다. (택배 회수 건만 뜸)

**Q. 롯데 수거접수를 잘못 눌렀어요. 취소는요?**
→ **ALPS(롯데) 화면에서 수동**으로 취소해야 합니다. TMS에서는 롯데 취소가 안 됩니다.

**Q. 구 제품이 아직 안 왔는데 새 제품 먼저 보내도 되나요?**
→ 됩니다. **교환 출고 송장**을 먼저 발행하고, 구 제품은 **회수 송장**으로 따로 받으면 됩니다. 두 송장은 독립입니다.

**Q. 시리얼이 안 보여요 / 미리 마킹 안 한 제품이에요.**
→ 교환 모달의 **"새 시리얼 만들기 → 자동생성"**으로 보관재고에서 1개 꺼내 배정하면 됩니다.
