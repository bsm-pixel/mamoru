# 복원수리 접수 알림톡(as_received) — 수거 시간 안내 문구 수정안

> 2026-09-03. 방문수거 "매장카운터/직접전달 + 시간" 옵션이 우체국 집배원 조기방문과 어긋나 수거 실패가 나던 문제 대응.
> 접수 페이지(page_form.html)에 이미 반영한 안내를 **알림톡에도 한 번 더** 각인.
> **사장님이 솔라피 콘솔에서 본문에 반영 → 재검수 신청** (재검수 1~3영업일, 그동안 옛 템플릿 발송되어 무중단).

## 대상 = as_received의 4변형 중 2개
Make가 `#{delivery_method}` 값으로 4변형 분기(직접발송/직접전달/카운터보관/문앞보관).
- ✅ **매장카운터 보관** 변형 → 아래 문구 추가
- ✅ **직접전달** 변형 → 아래 문구 추가
- ⛔ 문앞보관 / 직접발송 변형 → 추가 안 함(문앞보관은 시간 무관하게 안전, 직접발송은 고객이 부침)

## 추가할 문구 (알림톡 본문 하단, 텍스트 전용)

```
■ 수거 시간 안내
안내드린 시간은 '요청 시간'이며, 우체국 집배원님은 배달 동선에 따라 더 일찍 방문하실 수 있어요.
당일 확실한 수거를 위해, 가능하면 오전 9시쯤엔 전달 준비(또는 문앞 보관)를 부탁드립니다.
```

- 짧은 버전(글자수 빠듯할 때):
```
※ 안내 시간은 요청 시간이며 집배원님이 더 일찍 오실 수 있어요. 확실한 수거를 위해 오전 9시쯤 미리 준비(또는 문앞 보관) 부탁드려요.
```

- 이모지 넣을 경우 카카오 정책상 과도한 장식은 반려 위험 → `※` 정도만 권장.

## ⚠️ 반영 전 반드시 확인 — Make 분기 방식
접수 페이지 라벨을 바꿨다(예: "매장카운터 보관 - 10시 **이후 방문**" → "…10시 **이후 수거요청**", 11시 옵션 제거).
이 값이 `#{delivery_method}`로 Make에 전달되어 4변형을 고른다.
- Make 필터가 **"매장카운터"·"직접전달" 키워드 포함(contains)** 으로 분기 → **안전**(키워드 유지됨).
- Make 필터가 **전체 문자열 완전일치(equals)** 로 분기 → 옛 문자열("…11시 이후 방문" 등)과 안 맞아 **변형 선택 실패** 가능.
- 👉 콘솔에서 분기 조건이 contains(포함)인지 한 번만 확인. equals면 새 라벨로 갱신.
