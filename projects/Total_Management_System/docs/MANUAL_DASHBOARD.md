## 1. 개요

대시보드는 TMS 전체 현황을 한눈에 파악하고, 즉시 대응이 필요한 항목을 표시합니다.

---

## 2. 허브 카드

각 모듈로 바로 이동할 수 있는 카드형 네비게이션:
- **주문** → /orders
- **판매** → /sales
- **복원수리** → /repairs
- **상담** → /consultations
- **부자재** → /supplies

---

## 3. 오늘 할 일 (Today's Actions)

우선순위별 색상으로 즉시 대응 필요 항목을 표시:

| 항목 | 색상 | 설명 |
|------|------|------|
| 주문 결제 확인 → 배송 준비 | 파란색 | 결제완료 주문 처리 필요 |
| 주문 준비 → 송장 생성 | 주황색 | 준비 완료 → 발송 필요 |
| 신규 상담 접수 확인 | 노란색 | 미처리 상담 접수 |
| 상담 일정 재요청 | 빨간색 | 고객 재요청 대응 |
| 복원수리 신규 접수 확인 | 파란색 | 미처리 수리 접수 |
| 복원수리 출고 대기 | 녹색 | 출고 처리 필요 |
| 매입 입고 대기 | 남색 | 발주한 상품 입고 확인 |
| 부자재 주문 필요 | 회색 | 부자재 재주문 |

---

## 4. 매출 요약

### 주간/월간 매출
- 이번 주 주문 매출 (아임웹)
- 이번 달 주문 매출
- 오프라인 판매 매출 (별도 집계)

### 복원수리 요약
- 이번 주 수리 매출
- 마모루 가위 vs 타사 가위 비율

---

## 5. 알림 카드

### 미결제 주문
- 미결제/부분결제 주문 건수 + 금액

### 오늘 상담 일정
- 오늘 예정된 매장방문/출장 건수

### 저재고 알림
- stock_quantity ≤ 3인 제품 목록
- **"발주 작성 →"** 액션 링크 (해당 제품으로 발주 페이지 이동)

### 매입 입고 대기
- 발주 완료(ordered) 또는 선납완료(deposit_paid) 상태의 PO 건수

### 부자재 주문 필요
- "주문필요" 상태인 부자재 건수
