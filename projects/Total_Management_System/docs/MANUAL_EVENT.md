# 🎟️ EVENT(고객 접수 이벤트) 사용 매뉴얼

> 최종 업데이트: 2026-06-15 · 대상: 처음 쓰는 분도 흐름을 익히게

## 0. EVENT 한눈에 (먼저 읽기)
인스타 릴스/DM으로 안내한 **접수 페이지**에서 고객이 가위를 고르면, TMS에서 **입금안내 → 입금확인**만 누르면 **자동으로 판매로 넘어가** 평소처럼 발송·배송·후기가 처리됩니다.

- **EVENT 품목 = 그냥 제품**(카테고리만 EVENT). 재고·판매는 평소 그대로
- **캠페인** = 진행하는 이벤트 하나하나(예: "재고 전환 EVENT"). 카드로 보임
- **사장님이 누르는 건 딱 3번**: 입금안내 · 입금확인 · (발송 or 수령완료)
- 매장에 그냥 오신 손님 = 접수 페이지 필요 없이 **판매입력에서 EVENT 품목 선택**하면 끝

사이드바 → **판매 → EVENT**

---

## 1. 준비 (한 번만)

### 1-1. EVENT 품목 등록 (제품 → 제품 등록)
1. 카테고리 = **EVENT (재고 전환 이벤트)** 선택
2. 나타나는 **EVENT 전용 입력**:
   - **종류**: 블런트 / 틴닝 / 장가위 / DRY
   - **옵션(spec)**: 블런트·장가위는 인치(예 `6.0`), 틴닝은 `under20`/`21to29`/`over30`, DRY는 `stroke`/`slicing`/`curve`
3. 제품명(예 "EVENT 6.0"), SKU, **소매가**, **재고수량** 입력 → 저장
4. 같은 종류·인치라도 **가격대(5/10/20만)별로 따로** 만들면 고객이 가격대별로 고릅니다

> ⚠️ 옵션(spec)을 비우면 고객 폼에 그 인치 선택지가 안 생깁니다. **정확히 같은 값**(예 `5.25`)으로 입력해야 같은 옵션으로 묶입니다.

### 1-2. 캠페인 만들기 / 할인 설정 (EVENT → ⚙️)
1. EVENT 화면 → **새 캠페인** (또는 기존 "재고 전환 EVENT" 카드의 **⚙️**)
2. 캠페인명·유형 입력
3. **묶음 할인** (선택): `단가 / 최소수량 / 묶음가` 줄 추가
   - 예: `50000 / 3 / 130000` → 5만원 가위 3자루 = 13만 (4자루=18만, 6자루=26만)
   - **같은 단가끼리만** 묶음 (10만2+20만1 혼합은 할인 없음)
4. 저장

---

## 2. 고객에게 링크 보내기
- EVENT 화면 → 캠페인 카드의 **↗ 접수 페이지 열기** → 그 주소를 릴스 캡션/DM에 넣기
- 주소: `page.mamoru.kr/projects/event/page_form.html?campaign=<캠페인>` (카드 버튼이 자동으로 해당 캠페인 링크를 엶)

---

## 3. 접수 들어온 뒤 처리 (사장님)

| 순서 | 화면 | 할 일 | 자동 발생 |
|------|------|-------|-----------|
| ① 접수 | (고객) | — | 접수확인 알림톡 + 카드 **신규접수 +1** |
| ② 확인 | EVENT → 카드 → 접수 | 재고 확인 후 **[입금안내 발송]** | 입금안내 알림톡(총액·계좌) → '입금대기' |
| ③ 입금 | 같은 화면 | 통장 확인 후 **[입금확인 → 판매 전환]** | 입금확인 알림톡 + **판매 자동생성·재고차감** → '판매전환' |
| ④ 발송 | 판매관리 | **[택배 발송(송장 생성)]** 또는 **[고객 수령 완료]**(매장방문) | 발송 알림톡 / 배송완료 자동 / 후기 자동 |

- 카드의 4칸 숫자(신규접수/입금대기/판매전환/취소)로 진행 상황을 한눈에 봅니다
- 잘못 들어온 접수는 상세에서 **접수 취소**

---

## 4. 알림톡 (검수 필요)
접수확인·입금안내·입금확인 3종은 **솔라피 콘솔 등록+검수(1~3영업일) + Make 분기 추가** 후 실제 발송됩니다. 그 전에도 접수·전환·재고는 정상 작동합니다.
- 발송 안 되면: ① 솔라피 템플릿 검수/활성 ② Make 시나리오 분기 ③ 콘솔 상태 점검

---

## 5. 자주 묻는 것
- **매장에 그냥 온 손님?** → 판매입력(`/sales/new`)에서 EVENT 품목 골라 평소처럼 판매. 접수 페이지 불필요.
- **재고 표시?** → 고객 폼은 재고 적을 때만 "마감임박 N자루", 0이면 "품절". 평소엔 수량 숨김.
- **다른 이벤트 추가?** → EVENT → 새 캠페인. 한정판매·공동구매·체험단 등 같은 흐름.
