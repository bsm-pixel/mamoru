# 상담관리 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

상담관리는 **매장방문**, **출장요청**, **톡상담** 3가지 유형의 상담을 통합 관리합니다.

| 유형 | 설명 | 접수 경로 |
|------|------|-----------|
| 매장방문 | 고객이 매장에 직접 방문하여 상담 | Google Form → GAS → TMS |
| 출장요청 | 고객 위치로 출장 방문 상담 | Google Form → GAS → TMS |
| 톡상담 | 카카오톡을 통한 비대면 상담 | Google Form → GAS → TMS |

---

## 2. 화면 구성

### 상단 요약 카드
- **신규**: 미처리 접수 건수 (클릭 → 출장요청 탭 이동)
- **진행**: 현재 진행 중인 상담 건수
- **완료**: 이번 달 완료 건수
- **새로고침**: 외부 데이터 동기화

### 3개 탭
| 탭 | 내용 |
|-----|------|
| 매장방문 | 확정 일정 목록 + 달력 (PC: 3열 — 목록/달력/상세) |
| 출장요청 | 6개 서브탭 + 카카오맵 (PC: 3열 — 목록/지도/상세) |
| 톡상담 | 3개 서브탭 (신규/진행/완료) |

---

## 3. 매장방문

### 서브탭
- **확정**: 확정된 예약 일정
- **지난내역**: 완료/취소된 과거 내역

### 달력 (PC 우측)
- 월별 달력에 확정 일정 표시
- 초록 점: 매장방문 / 보라 점: 출장요청
- 날짜 클릭 → 해당 일 일정 목록 표시

### 가능한 액션
| 현재 상태 | 액션 | 결과 |
|-----------|------|------|
| 확정 (confirmed) | 상담 완료 | → completed |
| 모든 상태 | 취소 | → cancelled (확인 모달) |
| 완료 | 계약서 작성 | → /contracts/new로 이동 (고객 정보 자동 연결) |

---

## 4. 출장요청

### 서브탭 (6개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 오늘출장 | confirmed (오늘) | 오늘 예정된 출장 |
| 신규접수 | pending_admin | 새로 들어온 요청 |
| 제안중 | suggested | 시간 제안 완료, 고객 응답 대기 |
| 일정재요청 | reschedule/change | 고객이 변경/재요청 |
| 확정 | confirmed | 일정 확정 완료 |
| 지난내역 | completed/cancelled | 완료 또는 취소 |

### 시간 제안 기능
- **대상**: 신규접수, 일정재요청 상태
- 최대 **3개 시간대** 제안 가능
- 고객의 가능요일/시간대 참고 표시
- 제안 후 → "제안중" 상태로 전환

### 카카오맵 (PC 중앙)
- 출장 요청 위치를 지도에 마커로 표시
- 서브탭 전환 시 해당 상태의 마커만 표시
- 마커 클릭 → 상세 패널에 해당 건 표시

### 가능한 액션
| 현재 상태 | 액션 | 결과 |
|-----------|------|------|
| 신규접수 | 시간 제안 | → suggested |
| 재요청 | 시간 제안 | → suggested |
| 확정 | 상담 완료 | → completed |
| 모든 상태 | 취소 | → cancelled |

---

## 5. 톡상담

### 서브탭 (3개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 신규접수 | pending_admin | 카카오톡 접수 |
| 진행중 | in_progress | 상담 진행 중 |
| 완료 | completed/cancelled | 종료 |

### 가능한 액션
| 현재 상태 | 액션 | 결과 |
|-----------|------|------|
| 신규접수 | 상담 시작 | → in_progress |
| 진행중 | 상담 완료 | → completed |
| 모든 상태 | 취소 | → cancelled |

---

## 6. 상세 패널 (공통)

### 표시 정보
- 고객명, 전화번호 (탭하여 전화 가능)
- 방문 예정일/시간
- 주소 (출장의 경우)
- 접수 메모 / 재요청 메모 (분리 표시)
- 가능요일, 시간대 (출장의 경우)
- 상태 이력 (최근 5건)

### 완료 후 CTA
- 상담 완료 시 **"계약서 작성하기"** 링크 표시
- 클릭 → 계약서 작성 페이지로 고객 정보 자동 전달

---

## 7. 상태 흐름도

```
[접수] pending_admin
  ├─ 매장방문 → 자동 확정 (confirmed)
  ├─ 출장요청 → 시간 제안 (suggested) → 고객 선택 → 확정 (confirmed)
  └─ 톡상담 → 상담 시작 (in_progress)
       │
       ▼
[확정/진행] → 상담 완료 (completed)
       │
       ▼
[완료] → 계약서 작성 CTA
```

---

## 8. 대응필요 뱃지

각 탭에 빨간색 뱃지로 대응 필요 건수를 표시합니다:
- **출장요청**: 신규접수 + 재요청 건수
- **톡상담**: 신규접수 건수
- **매장방문**: 없음 (자동 확정)
