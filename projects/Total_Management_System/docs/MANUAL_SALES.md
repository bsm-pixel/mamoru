# 📦 판매관리 사용 매뉴얼

> 최종 업데이트: 2026-06-13 · 대상: 처음 쓰는 분도 읽고 바로 따라할 수 있게

---

## 1. 판매관리가 뭐 하는 곳인가요?

매장·출장·상담으로 **가위(제품)를 판 것 + 복원수리 받은 것**을 한 곳에서 기록·관리하는 화면입니다.
- **B2C(고객)**: 일반 손님, 온라인 상담 손님
- **B2B(거래처)**: 딜러·아카데미 납품
- 두 가지를 `판매관리` 한 화면에서 봅니다. (온라인 쇼핑몰 주문은 `주문관리`에서 따로)

사이드바 → **판매 → 판매 관리**

---

## 2. 화면 한눈에 보기

```
┌─ 위쪽: 매출 요약 카드 2개 ────────────────┐
│  [고객(B2C)]  이번달 290만 · 미수금 0      │
│  [거래처(B2B)] 이번달 500만 · 미수금 20만   │
└────────────────────────────────────────┘
[준비표 뽑기]   [🔍 검색: 판매번호·고객명·전화]
상태  전체 | 처리 필요(🟠3) | 미수금(2) | 취소
대상  고객 | 거래처 | 전체        기간  오늘 이번주 이번달 …
🟢완료  🟠처리대기  🔴미결제  🟡부분결제  ⚪취소   ← 색 범례
┌─ 왼쪽 목록 ──────┬─ 오른쪽 상세 ──────────┐
│ ▌김성은  290,000 │ (목록에서 클릭하면      │
│ ▐ 박유림  미결제  │  여기에 상세가 뜸)      │
└──────────────────┴────────────────────────┘
```

### 두 가지 필터 (헷갈리지 마세요)
- **상태**(윗줄 탭): 그 건이 어떤 단계인가 → 전체 / **처리 필요** / 미수금 / 취소
- **대상**(아랫줄 칩): 누구와의 거래인가 → 고객(B2C) / 거래처(B2B) / 전체

### 왼쪽 색으로 1초에 상태 파악 (가장 중요)
**왼쪽 세로 줄 색 = "내(사장님)가 더 할 일이 있나?"**

| 표시 | 뜻 | 내가 할 일 |
|---|---|---|
| 🟢 **초록 줄** | 완료 (출고완료/배송완료/수령완료) | **없음 — 끝남** |
| 🟠 황색 점 | 처리 대기 (출고·수령 안 함) | 출고하거나 "수령완료" 누르기 |
| 🔴 빨강 줄 | 미결제 | 결제 받기 |
| 🟡 노랑 줄 | 부분결제 | 잔금 받기 |
| ⚪ 회색 줄 | 취소됨 | 없음 |

> 핵심: **초록이면 손 떼도 되는 것, 초록이 아니면 아직 할 일이 남은 것.**

## 3. 판매 등록하기 (가장 많이 쓰는 기능)

### 들어가기
`판매관리` 우측 상단 **`+ 판매 입력`** → 등록 화면(`/sales/new`)

### ⚡ 방법 A — 바코드 스캔 (가장 빠름)
화면 위 **파란 "바코드 스캔" 칸**에 커서를 두고 스캐너로 찍으면 자동으로 장바구니에 담깁니다.
- **품목 바코드(SKU)** 찍기 → 그 제품이 담김 (같은 제품 또 찍으면 수량 +1)
- **시리얼 라벨(MR…)** 찍기 → 그 가위 1자루 + **시리얼까지 자동 배정**돼서 담김
- 삑–삑–삑 연속으로 찍으면 계속 담깁니다 (칸이 자동으로 비워짐)
- 이미 팔린 시리얼을 찍으면 → "사용 불가" 경고로 막아줍니다 (잘못 배정 방지)

### 방법 B — 직접 선택
1. **고객 선택**: 이름·전화번호로 검색 (없으면 `+ 신규 고객`)
2. **제품 선택**: 목록에서 클릭 → 장바구니에 담김, 수량 조절
3. **시리얼**(가위만): 장바구니 항목에서 시리얼 선택(준비/디스플레이 창고) 또는 자동생성
4. **결제 정보**: 결제수단(카드/현금/이체/복합) + 결제상태(완료/부분/미결제) + 할인
5. **판매 등록** 클릭

### 복원수리를 팔았다면
등록 화면 위 **[제품 판매 | 복원수리]** 탭에서 **복원수리** 선택 → 마모루/타사 가위 자루 수·단가 입력. (B2B 거래처 복원수리는 `납품` 화면의 `+B2B수리`)

### 💡 가격은 자동으로 맞춰집니다
거래처마다 가위 단가가 달라도, 고객을 선택하면 **그 거래처 전용 단가/이름**이 자동으로 장바구니에 적용됩니다. (딜러A 8만 / 딜러B 7.5만 등 — 설정에 등록된 값)

## 4. 판매 후 처리 흐름 (등록 → 출고 → 완료)

판매를 등록하면 끝이 아니라, 고객에게 **전달**까지 해야 "완료(초록)"가 됩니다.

```
판매 등록 (결제완료)
   │
   ├─ 택배로 보낼 때
   │    1) 상세에서 송장 발급/입력 → 출고완료
   │    2) 택배사 배송 → (자동) 배송완료 감지 → 🟢 초록
   │
   └─ 매장에서 직접 줄 때
        1) 포장해서 전달
        2) 상세에서 "고객 수령 완료" 클릭 → 🟢 초록
```

- **"처리 필요" 탭**을 누르면 → 아직 출고·수령 안 한 건(=내가 할 일)만 모아서 보여줍니다. 매일 이 탭부터 보면 됩니다.
- 택배는 배송 추적이 자동이라, 출고만 해두면 며칠 뒤 알아서 초록으로 바뀝니다.

## 5. 판매 상세 화면 (왼쪽에서 클릭하면 오른쪽)

- **고객 정보**: 고객명·연락처 + (있으면) **매장명·활동명·직급** 함께 표시 → 유선·응대 시 "하은 원장님" 식으로 확인
- **제품·시리얼**: 판매한 제품과 배정된 시리얼(클릭하면 그 시리얼 라벨 출력 가능)
- **금액**: 소계·할인·합계·부가세
- **버튼**: 결제완료 변경 / 출고완료 / 고객 수령 완료 / 판매 취소 / 후기 요청
- **상담 연결**: 어제 만난 상담 건이면 "이 판매는 ○○상담에서 시작됨" 표시

---

## 6. 미수금 (못 받은 돈)

- 미결제·부분결제로 등록하면 → 그 고객의 **미수금**에 자동 합산
- 나중에 결제완료로 바꾸면 → 미수금에서 자동 차감
- **"미수금" 탭**에서 못 받은 건만 모아 봅니다 (탭에 건수 배지)

---

## 7. 후기(리뷰) 요청

고객에게 후기 작성 링크를 알림톡으로 보냅니다. **자동**과 **수동** 두 가지.

### 자동 발송 (추천)
1. **설정 → 알림 설정 → "배송완료 시 자동 후기요청" 토글 ON**
2. 판매 상세에서 **리뷰 약속 스위치 ON**(고객이 후기 써주기로 한 경우)
3. 그 뒤 **출고완료(택배) 또는 고객 수령 완료(매장)** 되면 → **자동으로 후기 알림톡 발송** ✅
   - 택배: 배송완료 자동 감지 시 / 매장: 수령완료 누르는 즉시
   - 약속 안 한 고객은 자동 발송 안 됨 (사장님이 수동으로만)

### 수동 발송
판매 상세 → **"후기 요청"** 버튼 → 유형(상담/복원수리/제품구매) 선택 → 발송

> ⚠️ 약속 + 토글이 켜져 있어야 자동 발송됩니다. 한 번 보낸 건 중복 발송 안 됨.

## 8. B2B 거래처 매출 (딜러·아카데미)

- `+ 거래처 매출` 버튼 → 납품 입력 (제품 납품 / 복원수리)
- 거래처는 **출고완료 + 결제완료 = 판매완료(초록)**
- 거래처는 시리얼을 안 답니다 (보관창고에서 수량만 차감)
- 자세한 납품 목록·통계는 `납품` 화면에서 (URL 직접 접근)

## 9. 자주 묻는 질문

**Q. 옛날 판매가 갑자기 "처리 필요"로 잔뜩 떠요.**
A. "완료" 기준이 "출고·수령까지 끝난 것"으로 바뀌면서, 예전에 수령 처리를 안 해둔 건들이 드러난 거예요. (정리는 관리자가 일괄 처리)

**Q. "이번달"을 눌렀는데 지난달 것도 나와요.**
A. (2026-06-13 수정됨) 이제 이번달 1일부터만 나옵니다. 안 그러면 새로고침(Ctrl+Shift+R) 한 번.

**Q. 매장에서 바로 주고 끝났는데도 "고객 수령 완료"를 눌러야 하나요?**
A. 네. 그래야 초록(완료)이 되고, 후기 자동발송도 그때 나갑니다.

**Q. 바코드 스캐너는 따로 설정하나요?**
A. 아니요. USB로 꽂거나 블루투스 연결만 하면 키보드처럼 입력됩니다. 스캔 칸에 커서 두고 찍으면 끝.

## 10. 재고는 자동 연동 (참고)

- 판매하면 재고가 자동 차감 (B2C는 시리얼 sold 처리, B2B는 보관창고 차감)
- 판매 취소하면 시리얼·재고가 자동 복원됩니다
