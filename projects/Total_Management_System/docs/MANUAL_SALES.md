# 판매관리 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

판매관리는 **오프라인 판매** (매장/출장/톡상담 채널)를 TMS에서 직접 관리합니다. 온라인 주문은 주문관리에서 별도 관리.

---

## 2. 화면 구성

### 상단
- **검색**: 판매번호, 고객명
- **탭**: 전체 / 오늘 / 미수금
- **+ 판매 등록** 버튼

### 목록 표시
- 고객명 + 결제상태 뱃지 (결제완료/미결제/부분결제)
- 판매번호 (OS-YYYYMMDD-NNN)
- 판매 일시
- 결제수단 (카드/현금/이체/복합)
- 채널 칩 (오프라인/온라인/톡상담)
- 금액

### PC 레이아웃
마스터-디테일 2열 (ESC 키로 닫기)

---

## 3. 판매 등록

### 입력 항목

| 항목 | 필수 | 설명 |
|------|------|------|
| 고객 | ✅ | 자동완성 검색 (이름/전화번호) |
| 제품 | ✅ | 제품 선택 + 수량 (여러 개 가능) |
| 시리얼 | 선택 | 가위 제품: 준비/디스플레이 창고에서 선택 |
| 결제수단 | ✅ | 카드 / 현금 / 이체 / 복합 |
| 결제상태 | ✅ | 결제완료 / 미결제 / 부분결제 |
| 채널 | ✅ | 오프라인 / 온라인 / 톡상담 |
| 할인 | 선택 | 할인 금액 입력 |
| 메모 | 선택 | 판매 관련 메모 |

### 고객 유형별 자동 가격
| 고객 유형 | 적용 가격 |
|-----------|-----------|
| 일반/온라인 | 소매가 |
| 딜러 | 딜러가 (자동 전환) |
| 아카데미 | 아카데미가 (자동 전환) |

### 복합 결제
카드/현금/이체 금액을 각각 입력. 합계가 결제 금액과 일치해야 등록 가능. VAT는 **카드 결제 금액**에만 적용.

### B2C vs B2B 차이
| | B2C (일반/온라인) | B2B (딜러/아카데미) |
|--|-------------------|---------------------|
| 시리얼 | 준비/디스플레이에서 선택 | 시리얼 없음 (보관창고에서 차감) |
| 가격 | 소매가 | 딜러가/아카데미가 |
| 재고 차감 | stock_quantity (시리얼 sold 처리) | stock_quantity + raw_stock |

---

## 4. 판매 상세

### 표시 정보
- 판매번호 + 결제상태 뱃지
- 고객명 + 고객 유형 뱃지
- 결제수단 + 채널
- 제품 목록 (시리얼 번호 포함)
- 금액 (소계/할인/합계/VAT)
- 메모

### 가능한 액션
| 액션 | 설명 |
|------|------|
| 결제완료 변경 | 미결제/부분결제 → 결제완료 |
| 판매 취소 | 확인 모달 → 시리얼 복원 + 재고 복원 + 미수금 차감 |
| 메모 수정 | 인라인 편집 |

---

## 5. 미수금 관리

- 미결제/부분결제 시 고객의 `outstanding_balance`에 자동 반영
- 결제완료 변경 시 자동 차감
- 판매 취소 시 자동 차감
- 고객 상세에서 미수금 확인 가능

---

## 6. 재고 연동

```
판매 등록
  ├─ B2C (시리얼 있음)
  │   ├─ 시리얼 → status: sold, sold_via: offline
  │   ├─ previous_zone 저장 (취소 시 복원용)
  │   └─ stock_quantity -N
  │
  └─ B2B (시리얼 없음)
      ├─ stock_quantity -N
      └─ raw_stock -N (보관창고에서 차감)

판매 취소
  ├─ 시리얼 → status: in_stock, zone 복원
  ├─ stock_quantity +N
  └─ 아임웹 재고 동기화 (디스플레이 제외)
```
