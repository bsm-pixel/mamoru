# 상품·재고·매입 프로세스 흐름도
> 최종 업데이트: 2026-03-22

---

## 1. 전체 흐름

```
[아임웹 상품 등록]
       │
       ▼
[TMS 설정 > 상품 동기화] ──→ TMS 제품 자동 생성
       │                      (매입가/매입처는 TMS에서 수동 편집)
       ▼
[제품 목록] ← 아임웹 판매 상품 (BL/TH/LO/SL)
[부자재]   ← TMS 직접 등록 (박스, 포장재 등 — 아임웹 무관)
[B2B 거래처] ← 딜러(납품처) + 아카데미(납품처) + 매입처(공장)
               └ 서브탭: 딜러 | 아카데미 | 매입처

       ┌──────────────────────────────────────┐
       │           재고 변동 경로              │
       ├──────────────────────────────────────┤
       │ 발주 입고     → TMS +N → 아임웹 +N   │
       │ 오프라인 판매 → TMS -N → 아임웹 -N   │
       │ 온라인 주문   → 아임웹 자체 -N        │
       │               → TMS 동기화 -N        │
       │ 수동 조정     → TMS ±N → 아임웹 ±N   │
       │ 취소/환불     → TMS +N (자동 복구)    │
       └──────────────────────────────────────┘
       │
       ▼
[회계] ← 매출/매입/COGS/마진/미지급금/미수금
```

---

## 2. 제품 관리

### 등록 흐름
```
고객 판매 상품:  아임웹 등록 → TMS 동기화 → 매입가/매입처 편집
부자재:         TMS /supplies 직접 등록 (주문 링크 + 상태 토글)
```

### 제품 카테고리
| 코드 | 이름 | 아임웹 연동 | 용도 |
|------|------|------------|------|
| BL | 블런트 | ✅ | 가위 (고객 판매) |
| TH | 틴닝 | ✅ | 가위 (고객 판매) |
| LO | 장가위 | ✅ | 가위 (고객 판매) |
| SL | 슬라이싱 | ✅ | 가위 (고객 판매) |

### 재고 미사용 규약
- 아임웹 재고 수량관리 OFF → TMS `stock_quantity = -1`
- UI에서 "미사용" 뱃지 표시
- 재고 연동 API 호출 스킵

## 3. 매입 (발주) 프로세스

```
[매입처 등록] ← 상품·재고 > 매입처 > "매입처 추가"
       │        (업체명, 사업자번호, 대표자, 담당자, 연락경로)
       ▼
[발주 작성] ← 매입관리 > "발주 작성"
       │      매입처 드롭다운 선택 → 제품/수량 선택
       │      PO 번호 자동 채번: PO-YYYYMMDD-NNN
       ▼
[발주 확정] → status: ordered
       │
       ▼ (선택)
[선납 처리] → status: deposit_paid
       │      deposit_amount 기록, balance_amount 자동 계산
       ▼
[입고 확인] → status: received ★
       │      TMS 재고 +N (멱등성 가드: 1회만 실행)
       │      아임웹 재고 +N (재고 관리 상품만)
       ▼
[잔금 완료] → status: balance_paid
```

### 상태 전이 규칙
```
draft → ordered → deposit_paid → received → balance_paid
                       │              ↑
                       └──────────────┘ (deposit 없이 바로 입고 가능)

입고 이후 취소 불가
이미 received 상태에서 재클릭 → 409 에러 (재고 중복 방지)
```

## 4. 부자재 관리

```
[부자재 페이지] ← 상품·재고 > 부자재
       │
       ├── 부자재 추가 (이름, 주문 링크, 메모)
       │
       ├── 상태 토글 (뱃지 클릭)
       │   충분 → 주문필요 → 주문완료 → 충분 (순환)
       │
       └── "주문하기" 링크 → 외부 쇼핑몰 바로 이동

재고 숫자 관리 없음 — 상태 뱃지만으로 관리
발주 시스템 사용 안 함
```

---

## 5. 재고 수동 조정

```
TMS 재고 페이지 > "재고 조정" 버튼
       │
       ▼
[조정 모달]
  → 제품 선택
  → 조정 유형: 실사 보정 / 파손·불량 / 반품 입고 / 기타
  → 수량: +N 또는 -N
  → 사유 입력
       │
       ▼
  → TMS 재고 반영 (음수 방지)
  → 아임웹 재고 자동 반영 (재고 관리 상품만)
  → stock_adjustments 테이블에 이력 기록
```

---

## 6. 회계 연동

```
[회계 페이지]
  ├── 매출 요약: 오프라인 판매 집계
  ├── 매입 요약: 발주 집계
  ├── 매출이익: 매출 - COGS (제품별 price_purchase 기반)
  ├── 제품별 랭킹: 매출순/마진순
  ├── 매입처별 지출: 매입처별 총 지출액
  ├── 미지급금: 미완료 PO의 매입처별 잔금
  ├── 미수금: 고객별 outstanding_balance
  └── 엑셀 내보내기: 매출/매입/마진 분석
```
