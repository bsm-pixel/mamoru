# 출장 맡김 · 함께 출고 알림톡 등록안 (2026-10-27)

> 흐름: [TMS_FLOW_REPAIR.md](TMS_FLOW_REPAIR.md) 2026-10-27 절 · 마이그 165
> 가동 순서: ① 솔라피 템플릿 2개 등록·검수 → ② Make 새 시나리오(아래 분기 2개) → ③ TMS 설정 「Make 웹훅 URL (출장 맡김·함께 출고)」에 URL 입력 = 가동
> URL 이 비어 있는 동안: 맡김 확인은 나가지 않고, 함께 출고는 지금처럼 2통(복원수리 출고 + 판매 출고)으로 나간다.

🚨 솔라피 변수명 = TMS 가 보내는 키 그대로 (대소문자·밑줄까지). 키를 바꾸면 빈칸으로 나간다.

---

## ① 출장 맡김 확인 — `as_field_received`

- **Make 분기 조건**: `template` = `as_field_received` (event `AS_FIELD_RECEIVED`)
- **카테고리**: 서비스이용 > 신청접수 (004002)
- **유형**: 이미지형

**본문**
```
#{name}님, 안녕하세요
오늘 맡겨 주신 가위를 마모루가 잘 받았습니다

✅ 맡김 내용
• 접수번호 : #{as_id}
• 맡기신 가위 : #{qty}자루 (마모루 #{qty_mamoru} · 타사 #{qty_other})
• 수리비 : #{pay_status}
• 받으신 날 : #{received_date}

✅ 앞으로의 과정
• 사무실에서 가위 한 자루씩 상태를 기록하고 수리를 시작해요
• 수리가 끝나면 택배로 보내 드리고, 수리내역서도 함께 안내해 드려요

가위마다 접수번호 꼬리표를 달아 섞이지 않게 관리합니다 ✂️
```

**버튼**: 웹링크 [접수 내용 보기] → `https://page.mamoru.kr/projects/as/page_as_report.html?uid=#{as_uid}`
(검수 전에는 페이지에 "작업 준비 중" 안내가 보이고, 내역서를 쓰면 가위별 내역으로 채워진다)

**배너** (800×400 · 크림 배경 · 글자 Void · 좌하단 MAMORU 워드마크)
- 파일명: `as_field_received.png`
- 영문 라벨: `REPAIR RECEIVED`
- 1줄: 가위를 맡겨 주셨습니다
- 2줄: 수리가 끝나면 내역서와 함께 보내 드려요

**검수 요청 메모**
```
광고·홍보 아님(정보성)
[발송 대상] 출장 상담 현장에서 가위 복원수리를 맡기고 수리비를 결제한 고객
[발송 목적] 맡긴 가위의 접수번호·수량·결제 상태를 확인시켜 드리는 접수 확인 안내
[버튼] 해당 고객의 접수 내용(수리내역) 조회 페이지
[변수] name=고객명, as_id=접수번호, qty=총 자루 수, qty_mamoru/qty_other=브랜드별 자루 수, pay_status=결제 상태(결제 완료), received_date=접수일, as_uid=조회 페이지 식별값
```

## ② 제품·복원수리 함께 출고 — `combined_shipped`

- **Make 분기 조건**: `template` = `combined_shipped` (event `COMBINED_SHIPPED`)
- **카테고리**: 배송 > 상태안내 (006001)
- **유형**: 이미지형
- **언제**: 같은 롯데 송장에 B2C 판매 제품과 복원수리 가위가 함께 들어 있고, 기사님 집하 스캔이 감지됐을 때 (크론, 자동)

**본문**
```
#{name}님, 안녕하세요
주문하신 제품과 맡기신 가위가 한 상자로 함께 출발했습니다

✅ 보내 드린 것
• 제품 : #{product_name}
• 복원수리 가위 : #{qty}자루 (접수번호 #{as_id})

✅ 배송 정보
• 택배사 : #{courier}
• 송장번호 : #{tracking}

가위마다 어떤 작업을 했는지 수리내역서에 정리해 두었어요 📦
```

**버튼**
1. 웹링크 [수리내역서 보기] → `https://page.mamoru.kr/projects/as/page_as_report.html?uid=#{as_uid}`
2. 웹링크 [배송 조회] → 기존 판매 출고(`sales_shipped`) 템플릿의 배송조회 버튼과 같은 롯데 조회 링크 (송장 변수 `#{tracking}`)

**배너**
- 파일명: `shipped_combined.png`
- 영문 라벨: `SHIPPED TOGETHER`
- 1줄: 제품과 가위가 함께 출발했습니다
- 2줄: 수리내역서에서 작업 내용을 확인하세요

**검수 요청 메모**
```
광고·홍보 아님(정보성)
[발송 대상] 제품을 구매하고 가위 복원수리도 맡긴 고객 중, 두 건을 한 상자로 함께 발송한 고객
[발송 목적] 제품과 수리 완료 가위의 출고 사실 및 송장번호 안내
[버튼] ① 해당 고객 가위의 수리내역서 페이지 ② 택배 배송 조회
[변수] name=고객명, product_name=제품명(여러 개면 "OO 외 1건"), qty=가위 자루 수, as_id=접수번호, courier=택배사, tracking=송장번호, as_uid=수리내역서 식별값
```

## Make 시나리오
- 새 시나리오 1개(웹훅 1개) → 라우터 분기 2개(`template` 값) → 솔라피 알림톡.
- 새 시나리오마다 `Store incomplete executions` = **Yes** 확인 (솔라피 순단 1회로 시나리오가 꺼지는 사고 예방).
- 웹훅 URL 을 TMS 설정 → 알림·연동 → 「Make 웹훅 URL (출장 맡김·함께 출고)」에 넣고 저장.
