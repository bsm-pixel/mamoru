## ① 이번 달 상품 입력 (월초)

1. 화면 위에서 **달을 이번 달로** 맞춘다.
2. 등수별로 **상 이름(비우면 "1등") · 인원 · 상품명 · 설명 · 이미지**를 넣는다.
   - 인원이 0이거나 상품명이 빈 등수는 고객 화면·게시물에서 빠진다.
3. **마감일**을 확인한다. 발표일은 자동(마감 다음 달 첫 금요일 오후 8시).
4. **[저장]** → **[진행중]** 으로 게시.
   - 이때부터 고객 리뷰 이벤트 페이지에 이번 달 상품이 보인다.
   - 게시해야 피그마 프로젝트의 Claude가 값을 읽을 수 있다.

## ② 이벤트 안내 게시물·스토리 (월초)

피그마 제작 프로젝트에서: **"이번 달 리뷰 이벤트 홍보물 만들어줘"** (스킬 저장 전이면 저장해 둔 요청문 붙여넣기)

- Claude가 읽는 주소: `https://app-eta-sandy-75.vercel.app/api/reviews/event-public`
- Claude가 값 표를 먼저 보여준다 → TMS 값과 같은지 보고 "진행".
- 결과: 게시물 4장(1080×1350) + 스토리 1장(1080×1920).
- 게시물은 프로필에 **고정**, 지난달 이벤트 게시물은 **보관**. 스토리는 게시물 공유 + 링크 스티커.

## ③ 추첨 (발표일)

1. 달을 **지난달(마감된 달)** 로 맞춘다.
2. 선정 방식: **[랜덤 룰렛]**(녹화용) 또는 **[직접 지정]**.
   - 룰렛: 등수 선택 → [추첨] 한 번에 그 등수 인원만큼 연속 추첨.
   - 잘못 뽑았으면 [직접 지정] 탭에서 되돌린다.
   - 응모 풀을 넓히려면 응모 시작일을 앞당기거나 [처음부터 전체].
3. **[저장]**. (저장만으로는 고객에게 공개되지 않는다)

## ④ 당첨자 발표 게시물 (공개 전에 먼저 만든다)

1. **[게시물용 명단 복사]** — 가려진 이름·번호(`백*민 님 (3562)`)로 등수별 명단이 복사된다.
2. 피그마 프로젝트에 붙여넣고: **"이 명단으로 당첨자 발표 게시물 만들어줘"**
3. 결과 확인 (이름·인원이 TMS와 같은지).

> 실명·전체 전화번호는 TMS 밖으로 나가지 않는다. 복사되는 건 가려진 값뿐.

## ⑤ 공개 (같은 시각에)

- TMS **[선정자 게시하기]** → 고객 페이지 「지난 당첨자」에 공개
- 인스타에 당첨자 발표 게시물 업로드

## ⑥ 당첨 안내 (발표 직후)

화면 맨 아래 **「당첨자 배송」**.

- **[당첨 안내 보내기 (N명)]** — 아직 안 보낸 전원에게 알림톡(배송지 입력 버튼 포함).
- 알림톡이 안 되는 상황(템플릿 승인 전 등)이면 당첨자별 **[링크]** → 안내 문구+링크 복사 → 카톡 채널 1:1 채팅에 붙여넣기.
- 「당첨자 배송」이 안 보이면: 저장 안 한 변경이 있다는 뜻 → [저장].

## ⑦ 주소 → 송장

- 당첨자가 주소를 저장하면 **앱 알림 「당첨자 배송지 입력 📦」** 이 온다. 목록에 주소가 채워진다.
  - 예전에 구매·복원수리 때 남긴 주소가 있으면 당첨자 화면에 미리 채워져 있다(확인만 하고 저장).
  - 저장된 주소는 **고객 정보의 주소로도 갱신**된다.
- 전화로 주소를 받았으면 **[직접 입력]**.
- **[송장 생성]** → 롯데 ALPS에서 그 송장번호로 출력 → 포장·발송.
  - 송장 생성 후엔 당첨자가 주소를 못 바꾼다. 바꿔야 하면 송장 옆 **X(취소)** → 주소 수정 → 다시 생성. (집하 전만 가능)

## ⑧ 자동으로 되는 것

- 기사님이 집하 스캔 → (30분 주기 확인) → **「당첨 상품 출고」 알림톡 1회** → 목록에 "출고" 표시
- 배달 완료 → 목록에 "배달완료" 표시

## 연습 추첨을 지우고 싶을 때

**설정 → 시스템 → 「리뷰 추첨 초기화」** 에서 년·월을 고르고 [○월 추첨 초기화].

- 추첨 화면에는 초기화 버튼이 없다(녹화에 "다시 뽑기"가 보이면 안 되므로).
- 당첨 표시만 해제되고 **상품·마감일 설정은 그대로** 남는다.
- 이미 **발표했거나 / 당첨 안내를 보냈거나 / 고객이 주소를 저장했거나 / 송장을 만든** 달은 초기화되지 않는다.
- 룰렛은 그 등수 인원을 다 뽑으면 [추첨하기] 버튼이 사라지고 "축하합니다" 완료 화면이 된다.

## 자주 막히는 곳

| 증상 | 원인 → 해결 |
|---|---|
| 피그마 Claude가 "이벤트가 게시되지 않았다"고 함 | 그 달이 [비공개] 상태 → [진행중]으로 게시 (반영까지 최대 5분) |
| 연습으로 뽑은 당첨자를 지우고 싶음 | 설정 → 시스템 → 「리뷰 추첨 초기화」 |
| 「당첨자 배송」에 아무도 없음 | 당첨자 [저장]을 안 했거나, 달이 다름 |
| [송장 생성]이 안 눌림 | 배송지가 아직 없음 → 고객 입력 대기 또는 [직접 입력] |
| 당첨 안내를 보냈는데 고객이 못 받음 | 알림톡 템플릿·Make 연결 확인. 급하면 [링크]로 직접 전송 |
| 주소를 저장했다는데 알림이 안 옴 | 목록 새로고침(↻). 주소가 채워져 있으면 정상 — 알림은 폰 미수신 시 메일로도 온다 |
