## 현재 상태 분석

### 현재 페이지: `/inventory` (재고 현황)
- 요약 카드 4개: 총 재고 / 미입고 / 저재고 / 재고 원가
- 카테고리 탭: 전체/가위/빗/케이스/악세서리/기타
- 테이블: 제품명 | 현재고 | 창고별(보관/준비/디스플레이) | 미입고 | 원가합계
- 검색 + 저재고 필터
- 재고 조정 모달

### 사장님 지적 사항
1. **명칭**: "재고" → "창고·재고"
2. **시리얼**: 가위만 필요. 부자재(분무기, 빗 등)는 동일 바코드/QR로 수량 관리
3. **카테고리 탭**: 제품 페이지와 동일한 분류 칩으로 통일 (케이스→가위집)
4. **재고 미사용**: 어떻게 처리?
5. **요약 카드**: 카테고리별로 분리 표시
6. **부자재 재고 차감**: 추후 연동 (현재는 복잡하므로 Phase)

## 🎨 UX아키텍트

### 1. 명칭 변경
- 사이드바: "재고" → **"창고·재고"**
- Topbar: "재고 현황" → **"창고·재고 관리"**
- 이건 제품-시리얼-창고가 하나의 흐름이라는 IA적 표현

### 2. 카테고리 탭 통일
현재 재고 페이지는 `가위/빗/케이스/악세서리/기타`인데, 제품 페이지는 `BL/TH/LO/SL`.
이 두 체계가 다르다 — **통일해야 한다.**

제안: 가위를 서브 카테고리로 세분화하되, 재고에서는 **대분류** 사용:
```
전체 | 가위 | 빗 | 가위집 | 악세서리 | 기타
```
- "케이스" → **"가위집"** (사장님 요청)
- 가위 탭 안에서 BL/TH/LO/SL은 표시하되 탭으로 세분화하지 않음 (제품 카드에 카테고리 뱃지로 표시)

### 3. 요약 카드 — 카테고리별
현재: 전체 합산만 표시
변경: **선택된 카테고리에 따라 요약이 바뀜**
- "전체" 선택 시: 전체 합산
- "가위" 선택 시: 가위만의 총 재고, 저재고, 원가

### 4. 재고 미사용 처리
`stock_quantity = -1`은 "시리얼/재고 추적하지 않는 제품"이라는 뜻.
- B2B 전용 제품 (딜러에게만 납품, 마모루 시리얼 불필요)
- 또는 아직 재고 설정 안 한 제품

**표시 방식**: 재고 목록에서 `미사용` 뱃지 + 수량 `-` 표시 (현재와 동일)
**필터**: "미사용 숨기기" 토글 추가 → 기본 ON (미사용 제품 숨김)

### 5. 창고별 시각 강화
현재 창고별 수치가 텍스트로만 표시되어 한눈에 안 들어옴.
→ **미니 바 차트** 또는 **색상 도트 + 숫자** 형태로 시각화

### 6. 부자재 재고 차감
현재 부자재 페이지(`/supplies`)가 별도 존재하지만 재고와 연결 안 됨.
→ **Phase로 미룸** (판매 시 부자재 자동 차감 = 상당한 로직 추가)

## 💻 수석개발자

### 구현 분석

1. **명칭 변경**: `constants.ts` 1줄 + `page.tsx` Topbar 1줄 — 즉시 가능

2. **카테고리 탭**: 현재 `CATEGORY_TABS`가 하드코딩된 한글 카테고리.
   API(`/api/inventory`)는 `category` 파라미터로 필터링하는데, DB의 `products.category`는 `BL/TH/LO/SL` 코드.
   재고 API에서는 이걸 한글로 변환하지 않고 그대로 사용.

   **현실적 접근**: 재고 API의 category 필터는 DB 카테고리 코드(BL/TH/LO/SL)를 직접 사용.
   "가위" 탭 → `BL,TH,LO,SL` 전부 포함 / "빗" → `CB` / "가위집" → `CS` 등.

   → API에 `categoryGroup` 파라미터 추가하거나, 클라이언트에서 매핑 후 필터링.

3. **요약 카드 카테고리별**: 현재 summary는 API에서 전체 합산만 반환.
   → 클라이언트에서 `items` 배열로부터 직접 계산 (이미 전체 데이터 로드됨)

4. **미사용 숨기기**: 클라이언트 필터 — `items.filter(i => i.stock_quantity !== -1)`

5. **창고별 시각화**: CSS만으로 구현 가능 (프로그레스 바 또는 도트)

## 🎯 잡스

사장님 아침 루틴:
1. 대시보드에서 "저재고 2건" 알림 → 클릭
2. 창고·재고 페이지 → 가위 탭 → 저재고 필터 ON
3. "블런트 6.0 — 보관 0 / 준비 1 / 디스플레이 1" → 발주 필요 판단
4. 매입관리로 이동 → 발주 작성

핵심: **카테고리 선택 → 해당 카테고리의 요약만 보임** → 즉시 판단 가능
"가위 전체 재고 23개, 저재고 2종" vs "전체 재고 156개, 저재고 2종" — 전자가 훨씬 유용

## 🏢 COO

### 부자재 연동 로드맵
현재: 부자재(/supplies)는 상태 토글 + 주문 링크만 있음
Phase 1: 부자재에 재고 수량 필드 추가 + 수동 차감
Phase 2: 판매 시 부자재 자동 차감 (가위 1자루 판매 → 오일 1개, 박스 1개 자동 차감)
→ BOM(Bill of Materials) 개념. 현재는 복잡하므로 미룸.

### "재고 미사용" 정리 제안
- 미사용 = "이 제품은 수량 추적 안 함" (예: 서비스, 무형 상품)
- 대부분의 실물 제품은 미사용이면 안 됨
- **기본적으로 미사용 숨기기** + 설정에서 미사용 해제 가능하도록
