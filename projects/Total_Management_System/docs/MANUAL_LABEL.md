# 라벨 출력 시스템 매뉴얼 (ZT231 + 라벨 디자이너)

> 작성: 2026-06-12 · 대상: 사장님(운영자) · 프린터: Zebra ZT231 (203dpi, 이더넷)

TMS에서 **품목 바코드 라벨 · 시리얼 라벨**을 디자인하고 ZT231로 즉시 출력하는 시스템. 라벨 레이아웃은 사장님이 **라벨 디자이너에서 직접** 만들고 수정한다(클로드 코드수정 불필요).

---

## 1. 라벨 종류

| 종류 | 바코드 내용 | 용도 | 출력 위치 |
|------|------------|------|----------|
| **품목 바코드 라벨** | SKU | 재고·박스(같은 품목=같은 라벨) | 제품 상세 |
| **시리얼 라벨** | 시리얼(MR…) | 가위 1자루 = 1라벨(개체 추적) | 시리얼 관리 · 판매 직후 |
| **커스텀(빗 등)** | 지정 | 다른 크기 품목 | 직접 생성 |

- 시리얼 형식: **`MR{YY}{NNNNN}`** (예 `MR2610816`) = MR(마모루)+연도2+5자리 전역누적(연도 리셋 없음).

## 2. 출력 진입점 (4곳)

1. **제품 상세** → "바코드 라벨 출력" → 품목 라벨
2. **시리얼 관리 & 조회 → 제품별 관리** → 시리얼 행 🖨 → 시리얼 라벨
3. **판매 상세** → 항목의 시리얼 칩(🖨) 클릭 → 시리얼 라벨 (주문→생성→각인→라벨 흐름)
4. **제품 관리 우측 상단 "라벨 디자이너"** → 레이아웃 편집 전용

출력 모달에서 **① 템플릿 선택 ② 매수 입력 ③ "프린터 출력"**(즉시) 또는 "ZPL 다운로드"(테스트).

## 3. 라벨 디자이너 사용법 (`/labels`)

**진입**: 제품 관리 우측 상단 "라벨 디자이너" 버튼, 또는 출력 모달 "레이아웃 편집".

1. 상단 탭에서 템플릿 선택 (품목/시리얼/커스텀)
2. **요소 드래그**로 위치 잡기 → 요소 클릭 → 오른쪽에서 **±0.5mm 정밀 조정**
3. 조정 가능: 위치(X/Y) · 글자크기 · **폰트(11종)** · 굵기 · 바코드 폭/높이 · 선 길이/굵기 · 로고 크기
4. **요소 추가**: + 텍스트 / + 구분선 / + 바코드
5. **변수**: 텍스트 "내용"칸에 `{product}` `{sku}` `{serial}` 입력(또는 변수 칩 클릭) → 출력 시 실제 값 자동 치환
6. **저장** 필수 (저장해야 출력에 반영. 탭 전환 시 미저장 변경 사라짐)

### 새 크기 템플릿 만들기 (빗 등)
1. **"+ 새 템플릿"** → 이름(예: 빗 라벨) + 가로×세로(mm) → **만들기**
2. 요소 배치·저장
3. 출력 시 모달 "템플릿" 드롭다운에서 그 템플릿 선택
- 커스텀 템플릿은 "템플릿 삭제"로 제거 가능(기본 템플릿은 "기본값 복원").

## 4. Browser Print 설정 (즉시출력 핵심)

ZT231 즉시출력은 PC의 **Zebra Browser Print** 앱을 거친다(1회 설치).

1. zebra.com → `software/printer-software/browser-print.html`(무료, 양식 제출 후 다운) → 설치
2. 실행 → **트레이 상주**(윈도우 시작 시 자동). 설정창은 닫아도 됨
3. **Default Device = ZT231** 등록 (Set)
4. 첫 출력 시 **"이 사이트 허용?" 팝업 → 허용** (Accepted Hosts에 `app-eta-sandy-75.vercel.app` 추가)
5. 인증서 경고 시 그 브라우저에서 `https://localhost:9101` 한 번 열어 수락

→ 이후 "프린터 출력" 누르면 다이얼로그 없이 ZT231로 바로 나옴. (TMS=HTTPS라 `https://localhost:9101` 사용)

## 5. 라벨지 교체 시 (다른 크기)

1. 라벨 롤 교체
2. **프린터 캘리브레이션**: 본체 **PAUSE + CANCEL 길게**(SmartCal) → 새 라벨 길이·갭 자동 측정
3. TMS에서 그 크기 템플릿 골라 출력
- 같은 크기 라벨이면 캘리브레이션 생략 가능.

## 6. 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| "프린터(Browser Print) 미연결" | Browser Print 미실행 | 트레이에서 실행 / 재설치. 임시: ZPL 다운로드→ZSU |
| **ZebraDesigner 인쇄 안 됨(대기열 멈춤)** | 재부팅으로 프린터 IP 변경 → 드라이버 포트 옛 IP | 제어판→프린터→ZDesigner ZT231→속성→포트→포트구성→IP를 현재값으로 수정(현재 **192.168.219.44**, 포트 9100) |
| 라벨 어긋남/2장씩 | 라벨지 교체 후 미캘리브 | SmartCal(PAUSE+CANCEL) |
| 디자이너 흰 화면 | (해결됨 2026-06-12) | 최신 배포 확인 |
| 변경이 출력에 반영 안 됨 | 디자이너에서 저장 안 함 | "저장" 클릭 |

- **프린터 IP는 DHCP라 재부팅마다 바뀔 수 있음**. TMS(Browser Print)는 자동탐색해 영향 없으나, **ZebraDesigner(윈도우 드라이버)는 포트 IP 수동 갱신** 필요. 근본해결=공유기 DHCP 예약(미설정).
- ZT231은 **내부 운영용**(재고·입출고·시리얼). 고객 노출 예쁜 택은 성원애드피아 외주.

## 7. 기술 참고 (개발)

- 코드: `lib/label/zpl.ts`(ZPL 빌더) · `render-label.ts`(캔버스 합성+jsbarcode+^GFA 래스터, 미리보기=출력) · `browser-print.ts`(9101→9100 전송) · `templates.ts`(기본 템플릿) · `hooks/use-label-templates.ts`(저장본 로드, settings `label.templates`) · `components/labels/label-editor.tsx` · `label-print-modal.tsx`
- 한글/브랜드폰트 = 캔버스 래스터, 바코드 = jsbarcode(Code128), 전체를 1비트 ^GFA로 출력
- 로고 = `public/labels/mamoru-logo.png`(Aggressive 폰트 디자인, 이미지 임베드)
- 변수 치환은 출력 시점(제품명/SKU/시리얼). 템플릿은 settings에 JSON 저장 → 모든 출력경로 공유
