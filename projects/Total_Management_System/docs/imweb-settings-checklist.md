# 아임웹 관리자 설정 확인 요구서

아래 항목들을 아임웹 관리자 페이지에서 확인해주세요.
각 항목에 대해 **있는지/없는지, 현재 설정값, 경로(메뉴 위치)**를 정리해주세요.

---

## 1. 주문 상태 자동 전환 설정

> 경로 추정: 쇼핑 설정 > 주문관리 설정 또는 배송 설정

- [ ] "결제 완료 시 자동으로 배송대기(또는 상품준비) 전환" 옵션이 있는가?
- [ ] "송장번호 입력 시 자동으로 배송중 전환" 옵션이 있는가?
- [ ] "배송완료 자동 처리" (택배사 배송완료 감지 시 자동 전환) 옵션이 있는가?
- [ ] "구매확정 자동 처리" (배송완료 N일 후 자동 확정) 옵션이 있는가?
- [ ] 주문 상태 전환 흐름을 커스터마이징할 수 있는 설정이 있는가?

## 2. 웹훅(Webhook) / 알림 설정

> 경로 추정: 환경설정 > 외부 서비스 연동 또는 알림 설정

- [ ] 주문 상태 변경 시 외부 URL로 웹훅(HTTP 호출)을 보내는 기능이 있는가?
- [ ] 웹훅 URL을 직접 설정할 수 있는가? (있다면 설정 가능한 이벤트 목록)
- [ ] 카카오 알림톡 자동 발송 설정이 있는가? (배송 시작, 배송완료 등)
- [ ] 이메일/SMS 자동 알림 설정 항목

## 3. API 설정 (REST API v2)

> 경로 추정: 환경설정 > 외부 서비스 연동(API) > Rest API V2

- [ ] 현재 API 키/시크릿이 발급되어 있는가?
- [ ] API 권한 범위(scope) 설정이 있는가? (읽기/쓰기 구분)
- [ ] API 호출 제한(rate limit) 정보가 표시되는가?
- [ ] v3 API 또는 Ground API 사용 가능 여부

## 4. 배송 설정

> 경로 추정: 쇼핑 설정 > 배송 설정

- [ ] 기본 택배사 설정 (롯데택배가 기본으로 설정 가능한가?)
- [ ] 송장번호 자동 입력 관련 설정이 있는가?
- [ ] 굿스플로 연동 설정이 있는가? (있다면 현재 상태)
- [ ] 배송비 정책 설정 현황
- [ ] 배송 시작 시 고객에게 자동 알림 설정

## 5. 주문관리 v2 설정

> 경로 추정: 쇼핑 설정 > 주문관리 설정 또는 주문관리 페이지 내 설정

- [ ] 주문관리 버전 (v1 / v2) 현재 어떤 버전 사용 중인가?
- [ ] 일괄 처리 기능 (일괄 배송대기, 일괄 발송처리) 어떤 것들이 있는가?
- [ ] 엑셀 업로드로 송장번호 일괄 입력 기능이 있는가?
- [ ] 주문 상태별 필터/분류 옵션

## 6. 취소/환불 설정

> 경로 추정: 쇼핑 설정 > 취소/환불 정책

- [ ] 자동 환불 처리 옵션이 있는가?
- [ ] 취소 사유 선택/입력 설정
- [ ] 부분 취소 가능 여부

## 7. 외부 서비스 연동 현황

> 경로 추정: 환경설정 > 외부 서비스 연동

- [ ] 현재 연동된 외부 서비스 목록 (PG사, 택배사, CRM 등)
- [ ] Make(Integromat) / Zapier 등 자동화 서비스 연동 옵션이 있는가?
- [ ] Google Sheets 연동 옵션이 있는가?

---

## 확인 목적

위 설정들을 파악하면 TMS ↔ 아임웹 연동에서:
1. **"배송대기 처리" 수동 클릭을 자동화**할 수 있는지 판단
2. **웹훅으로 주문 이벤트를 TMS에 실시간 전달**할 수 있는지 판단
3. **취소/환불 처리의 자동화 가능 범위** 판단
4. 현재 API 권한으로 **추가로 할 수 있는 것**이 있는지 확인
