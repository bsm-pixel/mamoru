## 1. 개요

고객관리는 모든 고객 정보와 거래 이력을 한 곳에서 확인합니다.

**고객 생성 경로**:
- 오프라인 판매 등록 시 자동 생성
- 계약서 작성 시 자동 생성
- 온라인 주문 동기화 시 자동 생성
- 수동 등록
- **상담/복원수리 접수 시 phone 기반 자동 매칭/생성 (2026-04-30 추가, 072)** — 같은 phone이면 기존 customer로 매칭, 없으면 신규 생성

## 2. B2B 거래처 관리 (`/거래처`)

`/거래처` 페이지에서 B2B 거래처 (딜러/아카데미/사장님이 추가한 카테고리/매입처) 통합 관리.

### 탭 동적 구성 (074)
- **B2B**: 사장님이 설정에서 추가한 카테고리 자동 노출
- **매입처(supplier)**: system 고정

### 거래처 상세 — 탭 2개
| 탭 | 용도 |
|----|------|
| 기본정보 | 업체명/담당자/연락처/이메일/메모 + **거래처 카테고리** 변경 가능 |
| 납품품목 (B2B) / 매입품목 (매입처) | 제품별 catalog 등록 (납품명/납품가/특징) |

### catalog 등록 흐름 (073/074)
1. 거래처 선택 → "납품품목" 탭
2. "제품에서 불러오기" → 제품 검색 → 추가
3. 항목 클릭 → 편집 모드 → **납품명** + **납품가** + **특징** 입력 + 저장
4. 카드 헤더에 **납품명**(파란색)이 크게 표시 + 작게 "TMS 제품: ..." 식별
5. 이후 그 거래처에 판매할 때 자동 적용 → 송장 출력

### B2B 카테고리 관리 (074)
**설정 → 고객 관리 → "B2B 납품처 카테고리"**:
- 기본: 딜러, 아카데미 (삭제 차단)
- 사장님 추가: 학교, 공기관, 병원 등 자유
- 추가 항목: key (영문) / 표시명 / 아이콘 / 순서 / 활성 토글
- 추가 후 즉시 /거래처 탭에 자동 노출

→ 미래 새 채널 시작 시 카테고리 1줄 추가 → 거래처 등록 + 거래 시작.

## 3. 고객 유형

| 유형 | 뱃지 색상 | 설명 |
|------|-----------|------|
| 일반 (retail) | 회색 | 오프라인 매장 고객 |
| 온라인 (online) | 파란색 | 아임웹 쇼핑몰 고객 |
| 딜러 (dealer) | 보라색 | B2B 딜러 (납품) |
| 아카데미 (academy) | 에메랄드 | B2B 아카데미 (납품) |

### 유형별 영향
- **딜러** 선택 시 판매 등록에서 → 딜러가 자동 적용
- **아카데미** 선택 시 판매 등록에서 → 아카데미가 자동 적용
- **딜러/아카데미** → 시리얼 없이 보관창고에서 직접 출고

---

## 4. 고객 상세 패널

### 프로필 탭
- 이름, 유형, 연락처
- 메모 (인라인 편집 가능)
- 총 매출 금액 / 결제 상태

### 타임라인 탭
모든 거래 이력을 시간순으로 통합 표시:

| 아이콘 | 유형 | 표시 내용 |
|--------|------|-----------|
| 쇼핑백 (파란색) | 판매 | 판매번호, 결제상태, 금액 |
| 서명 | 계약서 | 계약서 번호 |
| 말풍선 | 상담 | 상담 유형 (매장방문/출장/톡상담) |
| 렌치 | 복원수리 | 수리 상태 (접수/수거/비용안내/작업중/출고/완료/취소) |

## 5. 미수금 추적

- 미결제/부분결제 판매 시 `outstanding_balance` 자동 증가
- 결제완료 처리 시 자동 감소
- 판매 취소 시 자동 감소
- 고객 상세에서 미수금 잔액 확인 가능
