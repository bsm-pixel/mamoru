# 👤 고객관리 사용 매뉴얼

> 최종 업데이트: 2026-06-13 · 대상: 처음 쓰는 분도 따라할 수 있게

---

## 1. 고객관리가 뭐 하는 곳인가요?

모든 손님·거래처의 **정보와 거래 이력**을 한 곳에서 보는 화면입니다. 누가 언제 뭘 샀고, 상담·수리는 어땠는지, 못 받은 돈(미수금)은 얼마인지 한눈에.

사이드바 → **고객 → 고객**

---

## 2. 고객은 언제 자동으로 만들어지나요?

대부분 **자동으로** 등록됩니다. 직접 등록은 가끔만.
- 판매·계약서 작성 시 → 자동 생성
- 온라인(아임웹) 주문 → 자동 동기화
- **상담·복원수리 접수 시 → 전화번호로 자동 인식** (같은 번호면 기존 고객에 합쳐짐 = 단골 자동 추적)
- 필요하면 직접 `+ 신규 고객`

> 핵심: **전화번호가 고객을 구분하는 기준**입니다. 같은 번호로 다시 오면 새로 안 만들고 기존 고객으로 이어집니다.

---

## 3. 화면 한눈에

```
[🔍 검색: 고객명·전화]   유형: 전체 일반 온라인 딜러 아카데미
┌─ 왼쪽 목록 ────┬─ 오른쪽 상세 ──────────────┐
│ 김성은  일반   │ 하은 (김성은)   [복제][상세] │
│ 박유림  일반   │ 010-…  · 고정헌헤어 · 원장   │
│ 김도연  일반   │ [기본정보] 활동명·직급·주소…  │
└────────────────┴────────────────────────────┘
```
PC에서는 왼쪽에서 고객을 클릭하면 오른쪽에 상세가 뜹니다.

---

## 4. 고객 등록하기 (직접 등록 시)

`+ 신규 고객` → 입력:
- **이름**(실명, 필수) · **연락처**(필수)
- **유형**: 일반 / 온라인 / 딜러 / 아카데미
- **매장/회사명**: 근무 미용실 이름 (예: 고정헌헤어)
- **활동명 (매장 사용 이름)**: 미용실에서 부르는 이름 (예: 하은) — *성함과 같으면 비워두세요*
- **직급**: 원장 / 디자이너 / 실장 등
- **주소 · 메모 · 태그**

> 💡 **활동명이 왜 필요한가?** 출장·전화 응대 때 실명(김순실)으론 못 알아보는 경우가 많아요. 미용실에선 "하은쌤"으로 통하니, 활동명을 적어두면 **"하은 원장님~"** 하고 자연스럽게 부를 수 있습니다.

---

## 5. 같은 매장 동료 등록 = "복제" 버튼 ⭐

한 미용실에서 2~3명이 고객이면, 매장명·주소를 매번 다시 칠 필요 없어요.
1. 기존 동료 고객을 클릭 → 상세 우측 상단 **"복제"** 버튼
2. 고객 등록 창이 **매장명·주소·유형이 채워진 채로** 열림
3. **이름·연락처만 새로** 입력 → 저장 → 끝
- (활동명·직급은 사람마다 다르니 비워둠 → 새로 입력)

---

## 6. 고객 상세 화면

### 기본 정보 카드
- 연락처 · 유형 · **활동명 · 직급** · 등록일 · 매장명 · 주소 · 태그
- 우측 **연필(✏️)** → 활동명·직급 **바로 수정** (전화 등록 고객도 나중에 채워넣기 가능)
- 헤더 이름: 활동명이 있으면 **"하은 (김성은)"** 으로 표시

### 타임라인 탭 — 이 고객의 모든 거래
| 아이콘 | 종류 | 내용 |
|---|---|---|
| 🛍 | 판매 | 판매번호·결제상태·금액 |
| ✍ | 계약서 | 계약 번호 |
| 💬 | 상담 | 매장방문/출장/톡상담 |
| 🔧 | 복원수리 | 접수~완료 상태 |

---

## 7. 고객 유형

| 유형 | 색 | 설명 | 판매 시 |
|---|---|---|---|
| 일반 | 회색 | 매장 손님 | 소매가 |
| 온라인 | 파랑 | 쇼핑몰 손님 | 소매가 |
| 딜러 | 보라 | B2B 납품 | 딜러가 자동 |
| 아카데미 | 에메랄드 | B2B 납품 | 아카데미가 자동 |

딜러·아카데미는 시리얼 없이 보관창고에서 출고됩니다.

---

## 8. 미수금 (못 받은 돈)

- 미결제·부분결제 판매 → 그 고객 미수금에 자동 합산
- 결제완료/판매취소 → 자동 차감
- 고객 상세에서 미수금 잔액 확인

---

## 9. B2B 거래처 관리 (`거래처` 화면)

딜러·아카데미·매입처는 `거래처`에서 따로 관리합니다.
- **거래처별 납품가·납품명** 등록: 거래처 → 납품품목 탭 → 제품마다 단가·이름 입력 → 판매 시 자동 적용 + 송장에 박힘 (같은 가위라도 딜러A 8만 / 딜러B 7.5만)
- **B2B 카테고리 추가**: 설정 → 고객 관리 → "B2B 납품처 카테고리" → 학교·병원 등 자유 추가
