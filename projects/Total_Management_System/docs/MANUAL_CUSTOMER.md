# 고객관리 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

고객관리는 모든 고객 정보와 거래 이력을 한 곳에서 확인합니다.

**고객 생성 경로**:
- 오프라인 판매 등록 시 자동 생성
- 계약서 작성 시 자동 생성
- 온라인 주문 동기화 시 자동 생성
- 수동 등록

---

## 2. 화면 구성

### 상단
- **검색**: 고객명, 전화번호
- **유형 필터**: 전체 / 일반 / 온라인 / 딜러 / 아카데미

### PC 레이아웃
마스터-디테일 2열 (좌측 선택 → 우측 상세)

---

## 3. 고객 유형

| 유형 | 뱃지 색상 | 설명 |
|------|-----------|------|
| 일반 (retail) | 회색 | 오프라인 매장 고객 |
| 온라인 (online) | 파란색 | 아임웹 쇼핑몰 고객 |
| 딜러 (dealer) | 보라색 | B2B 딜러 (납품) |
| 아카데미 (academy) | 에메랄드 | B2B 아카데미 (납품) |

### 유형별 영향
- **딜러** 선택 시 판매 등록에서 → 딜러가 자동 적용
- **아카데미** 선택 시 판매 등록에서 → 아카데미가 자동 적용
- **딜러/아카데미** → 시리얼 없이 보관창고에서 직접 출고

---

## 4. 고객 상세 패널

### 프로필 탭
- 이름, 유형, 연락처
- 메모 (인라인 편집 가능)
- 총 매출 금액 / 결제 상태

### 타임라인 탭
모든 거래 이력을 시간순으로 통합 표시:

| 아이콘 | 유형 | 표시 내용 |
|--------|------|-----------|
| 쇼핑백 (파란색) | 판매 | 판매번호, 결제상태, 금액 |
| 서명 | 계약서 | 계약서 번호 |
| 말풍선 | 상담 | 상담 유형 (매장방문/출장/톡상담) |
| 렌치 | 복원수리 | 수리 상태 (접수/수거/비용안내/작업중/출고/완료/취소) |

---

## 5. 미수금 추적

- 미결제/부분결제 판매 시 `outstanding_balance` 자동 증가
- 결제완료 처리 시 자동 감소
- 판매 취소 시 자동 감소
- 고객 상세에서 미수금 잔액 확인 가능
