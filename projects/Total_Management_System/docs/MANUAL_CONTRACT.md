## 0. 전자 계약서 한눈에 (먼저 읽기)

상담·판매 시 **제품 계약 + 고객 서명**을 화면에서 받아 계약서를 만드는 기능입니다 (종이 없이).

**기본 흐름**: 계약서 작성(제품 선택 + 고객 정보) → 화면에서 **서명**(손가락/마우스) → 저장(계약서 이미지 자동 생성) → 필요 시 **판매로 전환**(고객·제품 자동 입력). 사이드바 → **판매 → 계약서**.

- 계약서 번호는 `CT-YYYYMMDD-NNN`로 자동
- 판매로 전환한 계약서는 삭제 불가(먼저 판매 취소)

## 2026-05-18 — 계약서 영구 삭제 기능

### 어디서 삭제하나
- **사이드 패널**: 계약서 목록에서 선택 → 우측 상세 패널 하단 **"계약서 삭제"** 카드 → [삭제] 버튼
- **전체 화면**: 계약서 상세(`/contracts/[id]`) 페이지 하단 동일 위치

### 자동 가드 4겹
1. **판매 전환된 계약은 삭제 불가** — `offline_sale_id` 가 있으면 버튼 자체 회색 비활성 + "판매 전환된 계약은 삭제할 수 없습니다. 먼저 연결된 판매 건을 취소해주세요." 안내
2. **확인 모달** — 계약번호 + "복구할 수 없습니다" 빨간 경고 명시
3. **시리얼 연결 자동 해제** — `product_serials.contract_id` NULL로 풀어준 뒤 계약서 삭제 (시리얼 자체는 보존)
4. **계약 항목 자동 정리** — `contract_items` 는 ON DELETE CASCADE 로 자동 정리

### 상담 ↔ 계약서 단방향
계약서가 상담을 참조(`contracts.consultation_id`)하지만 반대 방향(상담 → 계약서)은 없음. 즉 계약서 삭제해도 **상담 데이터 영향 0**.

### 운영 권장 흐름
- **테스트 계약**: 바로 영구 삭제 OK
- **실제 고객 계약**: 가능하면 보존 (운영 데이터). 향후 운영 데이터 누적 시 soft delete(status='cancelled') 옵션 도입 검토 — 현재는 hard delete만

### 핵심 파일
- `app/api/contracts/[id]/route.ts` — DELETE endpoint
- `hooks/use-contracts.ts` — useDeleteContract()
- `components/contracts/contract-detail-panel.tsx` — 사이드 패널 삭제 UI
- `app/(dashboard)/contracts/[id]/page.tsx` — 전체화면 삭제 UI

## 1. 개요

전자 계약서는 오프라인 상담 후 **제품 계약 + 서명**을 디지털로 처리합니다.

**계약서 번호**: CT-YYYYMMDD-NNN (자동 채번)

---

## 2. 화면 구성

### 상단
- **검색**: 계약서 번호, 고객명, 전화번호
- **기간 필터**: 전체 / 오늘 / 이번주 / 이번달
- **+ 계약서 작성** 버튼

### 상태 탭 (4개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 전체 | - | 모든 계약서 |
| 신규계약 | draft/signed | 작성 중~서명 완료 |
| 전환완료 | completed | 판매로 전환 완료 |
| 취소 | cancelled | 취소 |

### PC 레이아웃
좌측 50% 목록 + 우측 50% 상세 패널

---

## 3. 계약서 작성

### 입력 항목
| 항목 | 필수 | 설명 |
|------|------|------|
| 고객명 | ✅ | 상담에서 연결 시 자동 입력 |
| 연락처 | ✅ | 상담에서 연결 시 자동 입력 |
| 주소 | 선택 | 배송지 |
| 제품 선택 | ✅ | 제품 모달에서 선택 + 수량 |
| 결제 방법 | ✅ | 카드/현금/이체 |
| 수령 방법 | ✅ | 매장수령/택배 |
| 선납/잔금 | 선택 | 선납 금액 입력 시 잔금 자동 계산 |

### 법적 고지
- 회사 소개 및 수리 정책
- 반품/교환 조건 (5일 이내, 각인 제품 불가)
- 자동 표시 (수정 불가)

### 서명
- **터치 + 마우스** 지원 서명 캔버스
- 고해상도 캔버스 (Retina 대응)
- 판매자 서명 + 구매자 서명 2개

---

## 4. 계약서 상세

### 표시 정보
- 계약서 번호 + 상태 뱃지
- 고객 정보 (이름, 연락처, 주소)
- 결제 방법 / 수령 방법
- 제품 목록 + 금액
- 서명 이미지 미리보기

### 상태 색상
| 상태 | 색상 |
|------|------|
| 작성중 (draft) | 회색 |
| 서명완료 (signed) | 파란색 |
| 발송완료 (sent) | 보라색 |
| 완료 (completed) | 녹색 |
| 취소 (cancelled) | 빨간색 |

### 가능한 액션
| 액션 | 설명 |
|------|------|
| 판매 전환 | 계약서 → 판매 등록으로 전환 (확인 모달) |

---

## 5. 상담 → 계약서 연결

상담 완료 시 **"계약서 작성하기"** CTA가 표시됩니다.
클릭 시 고객명/연락처가 자동으로 전달되어 계약서 작성 화면에 미리 입력됩니다.

```
상담 완료 → "계약서 작성하기" → /contracts/new?customer_name=...&customer_phone=...
```
