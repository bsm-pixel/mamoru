# 전자 계약서 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

전자 계약서는 오프라인 상담 후 **제품 계약 + 서명**을 디지털로 처리합니다.

**계약서 번호**: CT-YYYYMMDD-NNN (자동 채번)

---

## 2. 화면 구성

### 상단
- **검색**: 계약서 번호, 고객명, 전화번호
- **기간 필터**: 전체 / 오늘 / 이번주 / 이번달
- **+ 계약서 작성** 버튼

### 상태 탭 (4개)
| 탭 | 상태 | 설명 |
|----|------|------|
| 전체 | - | 모든 계약서 |
| 신규계약 | draft/signed | 작성 중~서명 완료 |
| 전환완료 | completed | 판매로 전환 완료 |
| 취소 | cancelled | 취소 |

### PC 레이아웃
좌측 50% 목록 + 우측 50% 상세 패널

---

## 3. 계약서 작성

### 입력 항목
| 항목 | 필수 | 설명 |
|------|------|------|
| 고객명 | ✅ | 상담에서 연결 시 자동 입력 |
| 연락처 | ✅ | 상담에서 연결 시 자동 입력 |
| 주소 | 선택 | 배송지 |
| 제품 선택 | ✅ | 제품 모달에서 선택 + 수량 |
| 결제 방법 | ✅ | 카드/현금/이체 |
| 수령 방법 | ✅ | 매장수령/택배 |
| 선납/잔금 | 선택 | 선납 금액 입력 시 잔금 자동 계산 |

### 법적 고지
- 회사 소개 및 수리 정책
- 반품/교환 조건 (5일 이내, 각인 제품 불가)
- 자동 표시 (수정 불가)

### 서명
- **터치 + 마우스** 지원 서명 캔버스
- 고해상도 캔버스 (Retina 대응)
- 판매자 서명 + 구매자 서명 2개

---

## 4. 계약서 상세

### 표시 정보
- 계약서 번호 + 상태 뱃지
- 고객 정보 (이름, 연락처, 주소)
- 결제 방법 / 수령 방법
- 제품 목록 + 금액
- 서명 이미지 미리보기

### 상태 색상
| 상태 | 색상 |
|------|------|
| 작성중 (draft) | 회색 |
| 서명완료 (signed) | 파란색 |
| 발송완료 (sent) | 보라색 |
| 완료 (completed) | 녹색 |
| 취소 (cancelled) | 빨간색 |

### 가능한 액션
| 액션 | 설명 |
|------|------|
| 판매 전환 | 계약서 → 판매 등록으로 전환 (확인 모달) |

---

## 5. 상담 → 계약서 연결

상담 완료 시 **"계약서 작성하기"** CTA가 표시됩니다.
클릭 시 고객명/연락처가 자동으로 전달되어 계약서 작성 화면에 미리 입력됩니다.

```
상담 완료 → "계약서 작성하기" → /contracts/new?customer_name=...&customer_phone=...
```
