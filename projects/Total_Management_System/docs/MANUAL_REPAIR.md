# 복원수리 매뉴얼

> 최종 업데이트: 2026-03-30

---

## 1. 개요

복원수리는 고객 가위의 복원·수리를 접수부터 출고까지 관리합니다.

**접수 경로**: 고객 접수 페이지(GitHub Pages) → Vercel API → Supabase → TMS

---

## 2. 화면 구성

### 상단 요약 카드 (클릭 → 필터)
| 카드 | 표시 | 클릭 시 |
|------|------|---------|
| 신규 | 신규 접수 건수 | intake 탭으로 필터 |
| 진행 | 진행 중 건수 | in_progress 탭으로 필터 |
| 미입금 | 미입금 건수 | 전체 탭에서 미입금만 필터 (주황 보더) |
| 3일경과 | 3일 이상 정체 건수 | 전체 탭에서 경과 건만 필터 |

### PC 레이아웃
좌측 40% 목록 + 우측 60% 상세 패널

---

## 3. 파이프라인 탭 (6단계)

| 탭 | 포함 상태 | 설명 |
|----|-----------|------|
| 신규접수 | intake | 접수 확인 대기 |
| 수거 | pickup_scheduled, picked_up | 수거 예약/수거 완료 |
| 입고·검수 | inspecting | 입고 후 검수 진행 |
| 진행중 | cost_notified, repairing | 비용안내 + 수리 작업 |
| 출고대기 | ready_to_ship | 송장 생성 + 출고 대기 |
| 출고완료 | shipped, delivered, completed | 발송~완료 |

---

## 4. 상세 패널

### 비용 섹션
- 수리비 / 수거비 / 합계 표시
- 수동 편집 가능 (비용안내 전)
- 무상 처리 (합계 0원) 지원

### 입금 상태
- 입금완료: 녹색 체크 + 일시 표시
- 미입금: **입금확인** 버튼 표시
  - 알림톡 발송 여부 체크박스 (해제 시 내부 처리만)

### 검수 (Inspection)
- 가위별 검수 항목 입력
- 검수 사진 업로드 (촬영/재촬영/삭제)
- 검수 완료 후 비용 자동 반영

---

## 5. 액션 버튼

### 비용안내 발송
- **대상 상태**: intake ~ cost_notified
- 클릭 → 확인 모달 → 고객에게 **비용안내 알림톡** 발송
- 자동으로 `cost_notified → repairing` 전환 (작업시작 별도 클릭 불필요)
- 0원(무상) → 자동 입금완료 처리

### 입금확인
- **대상 상태**: cost_notified ~ shipped (paid_at 없을 때)
- 확인 모달에서 알림톡 발송 여부 선택 가능
- 상태 변경 없이 `paid_at` 플래그만 설정

### 출고 섹션
- cost_notified 이상 상태에서 표시
- **송장 생성**: 롯데택배 ALPS API 연동
- **출고완료**: ready_to_ship + 송장 있을 때 → shipped
- **송장 취소**: 집하 전에만 가능

### 상태 전환 버튼
- 현재 상태에서 가능한 다음 상태만 표시
- 모든 전환에 확인 모달 적용

### 취소
- 모든 비터미널 상태에서 가능
- danger 모달로 확인

---

## 6. 상태 흐름도

```
intake (접수)
  → pickup_scheduled (수거예약)
    → picked_up (수거완료)
      → inspecting (입고·검수)
        → cost_notified (비용안내)
          → repairing (수리중) ← 비용안내 시 자동 전환
            → ready_to_ship (출고대기)
              → shipped (출고완료)
                → delivered (배송완료)
                  → completed (완료)

어디서든 → cancelled (취소) 가능
```

---

## 7. 알림톡 자동 발송

| 트리거 | 템플릿 | 내용 |
|--------|--------|------|
| 비용안내 발송 | as_cost_notice | 수리비/수거비/합계 안내 |
| 입금확인 | as_payment_confirmed | 입금 확인 알림 (선택적) |
| 출고완료 | as_shipped | 송장번호 + 택배사 안내 |
| 배송완료 | as_review_request | 리뷰 작성 요청 |
| 취소 | as_cancelled | 취소 안내 |
