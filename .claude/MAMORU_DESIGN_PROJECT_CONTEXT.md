## 2. 글꼴
- 제목·숫자·큰 영문 = **Outfit**(얇게 300 ↔ 굵게 800~900) / 본문 = **Plus Jakarta Sans**(영문) + **Pretendard**(한글) / 한글은 제목·본문·자막 모두 Pretendard(Noto Sans KR 안 씀). 이 밖의 새 글꼴 추가 금지.
- 크기: 모바일 본문 13~14px, PC 16px, 라벨 최소 11px. `clamp()`로 유동.
- 🚨 **브랜드명 "MAMORU"를 로고·제목·큰 글씨로 쓸 때는 글꼴로 타이핑하지 말고 AGRESSIVE 워드마크(SVG)를 쓴다** (`mamoru-wordmark.svg`, 가로:세로 ≈ 9.28:1로 길다 → 모바일은 폭 기준으로 크기). 문장 속 "MAMORU"·작은 라벨은 예외.
- 워드마크 SVG는 **글자가 아니라 외곽선 도형**이라 글꼴이 필요 없다 → 결과물(HTML·PNG·배너)에 SVG를 그대로 넣으면 어디서 내보내도 모양이 유지된다. 피그마는 필수가 아니다. 금지되는 건 "MAMORU"를 글자로 타이핑하는 것뿐.
- 거북이 심볼(mamorulogo.png 등)은 마무리 장·엔딩 프레임용으로 그대로 쓴다. 단 **글자 "MAMORU"가 들어가는 자리는 워드마크 SVG**.

## 3. 개성 레이어(B-09) — 사장님이 강하게 만족한 요소
1. **페이지마다 콘셉트 1개 + 시그니처 1개**를 먼저 정한다. 예: 장인 작업대 다큐 / 정밀 기술 도면 / 갤러리 도록 / 진단 리포트 / 접수 전표 / 인증서 용지. "보고 나서 기억에 남는 한 가지"가 있어야 한다.
2. **정밀 주석 레이어(마모루 시그니처)**: 흑백 확대 사진 위에 가는 선(hairline)·점·짧은 라벨(예: `01 EDGE 날 각도 복원`). 가위 = 정밀 공구라는 걸 장식 없이 말한다.
3. **거대 영문 단어가 사진 아래 끝을 살짝 덮는 겹침 1곳** (예: RESTORE, REAL, CHOSEN, REVIEW). 단어는 페이지 내용에서.
4. **극단적 크기 대비**: 거대 숫자·영문은 본문의 4~8배. 어중간한 2배 대비가 가장 밋밋하다.
5. **제목 굵기 대비**: 한 제목 안에서 얇게(300) ↔ 굵게(900). 예: "이달의 리뷰 / **주인공은?**"
6. **거대 번호 인덱스** 01·02·03 (Outfit 300, 흐린 색). 단계·항목·섹션 앞에.
7. **숫자 스펙 3개** (페이지에 있는 사실만, 예: 50년 / 2대 / 12년). 숫자는 자리 맞춤(tabular-nums).
8. **문제→답**: 문제는 흐리게·작게(취소선 가능), 답은 크고 굵게.
9. **가는 선(hairline)으로 묶기**: 흰 카드·회색 상자 대신 1px 선과 여백으로 그룹. 안내문은 회색 상자 대신 왼쪽 검은 세로선.

## 4. 사장님이 지적해서 확정된 규칙 (반드시 지킬 것)
- **흑백 필터는 히어로 시그니처 사진에만.** 일러스트·아이콘·작업/후기 사진은 원래 색 유지.
- **주석은 실제 부위를 정확히** (사장님 = 가위 전문가). 날·날끝·피봇·핸들을 정확히 짚을 것. 애매하면 넣지 말고 확인 요청.
- **용어는 사장님 용어로**: 예) "가위 테스트" ✕ → "인모 100% 가발 테스트" ○. 사실·수치는 지어내지 말 것.
- **탭은 글자 + 굵은 밑줄 2px.** 안내 라벨을 탭과 같은 모양·위치에 두면 버튼처럼 보이니 금지(작은 머리말 + 세로 구분선 + 가는 선).
- **왼쪽 정렬 시 외톨이 요소·빈 공간 금지**: 아이콘이 홀로 뜨면 [거대 번호 | 글 | 일러스트] 3칸 공정표로.
- **중복 버튼(CTA) 금지**: 하단 고정 바가 있으면 본문 안에 같은 버튼 또 넣지 않는다. 모바일 히어로 버튼 추가 금지(PC 전용은 가능).
- **모바일 줄바꿈 = 구절 단위**: 모바일(≤767px)에서 좁은 2단 금지 → 1단. 번호 칸 때문에 글이 좁으면 번호를 글 위로. "알 / 수 있기에"처럼 구절 중간에서 끊기면 묶는다. **360px 폭에서 꼭 확인.**
- **모바일 좌우 여백 20px**, PC 본문 폭 760px(넓은 영역 1100px).
- **입력폼·접수폼은 가볍게**: 입력칸·버튼 크기 그대로, 큰 히어로·주석 사진 넣지 않음. 제목 위계·가는 선·큰 항목 번호·모서리 2px 정도만.

## 5. "AI가 만든 흔한 화면" 금지
- 가운데 히어로 + 똑같은 카드 3장 + 아이콘 그리드 조합
- 모든 카드가 같은 크기·같은 간격 (→ 중요한 1개만 크게)
- 이모지·범용 아이콘으로 섹션 때우기 (→ 실사진 크롭이나 거대 숫자)
- 의미 없는 영문 장식 문구("Premium Quality") (→ 쓸 거면 사실 문장 `0.01mm 단위 연마`)
