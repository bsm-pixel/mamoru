# MAMORU Brand Color System
# Terracotta Editorial — 장인의 온도

> 모든 디자인 작업(웹/위젯/이미지/문서)에서 이 문서를 기준으로 색상을 적용한다.
> 이 문서에 없는 색상을 새로 도입할 경우 반드시 사용자 확인 후 진행.

---

## 1. Primary (메인 컬러) — 60/30/10 법칙

| 비중 | 역할 | 이름 | HEX | RGB | 사용처 |
|------|------|------|-----|-----|--------|
| **60%** | Base | Cream | `#F2F2EA` | 242,242,234 | 전체 배경, 여백, 호흡 공간 |
| **30%** | Dark | Indigo Black | `#181725` | 24,23,37 | 다크 섹션, 메인 텍스트, 푸터 |
| **10%** | Accent | Terracotta | `#D4613E` | 212,97,62 | CTA, 섹션바, 배지, 아이콘 |

### 브랜드 감성 키워드
- Cream = 와시(和紙), 자연, 과하지 않은 품격
- Indigo Black = 깊은 밤, 집중, 전문가의 깊이
- Terracotta = 흙, 도자기, 장인의 온도

## 6. Typography Scale (타이포그래피)

> 크림 배경(#F2F2EA) + 인디고 텍스트(#181725)는 순백+순흑 대비보다 약 15% 낮다.
> 따라서 본문 최소 15px, 웨이트는 900 대신 800 이하를 기본으로 한다.
> 에디토리얼 톤: 크기 차이로 위계를 잡고, 웨이트로 고함치지 않는다.

## 7. 금지 조합

| 조합 | 이유 |
|------|------|
| Terracotta 텍스트 on Cream 배경 | 대비 부족 (3.2:1, AA 미달) |
| Terracotta Soft 배경 + Terracotta 텍스트 | 구분 불가 |
| Indigo Mid 텍스트 on Indigo Black 배경 | 대비 부족 |
| Error `#C44040` + Terracotta `#D4613E` 나란히 | 혼동 위험 — 간격 두거나 아이콘으로 구분 |
| 순수 블랙 `#000000` 사용 | 팔레트와 불일치, 눈 피로 |
| 순수 화이트 `#FFFFFF` 배경 사용 | Cream `#F2F2EA` 또는 Card White `#FAFAF5` 사용 |

## 7. 사용 계층 다이어그램

```
배경 계층 (뒤에서 앞으로)
├─ #F2F2EA  전체 배경 (60%)
├─ #FAFAF5  카드/모달 (배경 위에 뜨는 요소)
├─ #E8E6DC  입력 필드/비활성 영역
└─ #181725  다크 섹션 (30%)
   ├─ #2A2940  다크 카드
   └─ #100F1C  다크 딥 (오버레이, 히어로)

텍스트 계층
├─ #181725  메인 (크림 위)
├─ #6B6980  서브 (크림 위)
├─ #F2F2EA  메인 (다크 위)
└─ rgba(242,242,234,0.6)  서브 (다크 위)

액센트 계층
├─ #D4613E  기본 (CTA, 배지, 강조)
├─ #B85232  호버/프레스
├─ #F0C4B3  소프트 (배경, 태그)
└─ rgba(212,97,62,0.14)  글로우/쉐도우
```
