A-01 — Mission & Principle

미션과 원칙

Mission · 미션

미용가위의 올바른 기준을 세워,
모든 미용사가 스스로 판단할 수 있게 한다.

MAMORU는 판매하지 않습니다. 안내할 뿐입니다.
할인 없음. 구매 권유 없음. 모든 고객에게 동일한 가격과 서비스.

Slogan · 슬로건 (확정)

CUT THE FAKE,
KEEP THE REAL

가짜를 잘라내고, 진짜를 지킨다.
미용가위의 Cut과 시장의 거짓을 걷어내는 Cut — 이중 의미.

A-02 — Core Values

핵심 가치

3 Core Values
① 고객이 이해해야 한다
왜 이 가위인지, 왜 이 형태인지, 왜 이 가격인지. 정보를 숨기지 않는다.
② 고객이 선택해야 한다
선택지를 안내할 뿐, 고르는 건 고객이다. "안 사셔도 됩니다"를 두려워하지 않는다.
③ 고객이 만족해야 한다
이해하고, 스스로 선택했기에 진짜 만족이 온다. "앞으로 오래 일해주세요"가 가장 듣고 싶은 말.

D-03 — Page Direction

페이지별 방향

Main Page · 메인
톤
"이 브랜드는 다르다"를 느끼게. 잡화점이 아닌 브랜드 쇼룸.
①
Hero — Void 배경. 슬로건 + 한 줄 카피 + CTA. 최소 70vh. 반응형 필수.
②
Trust Numbers — 경력 10+년, 리뷰 160+, 맞춤상담 100%, 할인 0. Outfit 900 큰 사이즈.
③
가위 프리뷰 — 대표 가위 3~6종. 아임웹 기본 위젯 또는 코드위젯. 3열/모바일 2열.
④
복원수리 CTA — Void 배경. 전/후 비교. "첫 날의 커트감을 되찾아 드립니다."
⑤
고객 후기 — 실제 네이버 리뷰 2~4개. 카드형 또는 캐러셀.
⑥
브랜드 한마디 — "판매하지 않는다. 안내할 뿐이다." Void 배경, Display 사이즈.
Product List · 상품 목록
구현
아임웹 기본 + 공통 CSS. 카드 radius 12px, 호버 translateY(-4px), 이미지 배경 Shell, 뱃지 제거.
카테고리
가위: 블런트·틴닝·스트록·세트 / 제품: 빗·브러시·클리퍼·기타 / 복원수리: 블런트·틴닝
Product Detail · 상품 상세
상단
아임웹 기본(이미지 6컷, 가격, 구매버튼) + CSS 커스텀.
하단 (코드위젯)
① 이 가위에 대하여 ② 스펙 테이블 ③ MAMORU's Note (이런 분에게 맞습니다 / 맞지 않을 수 있습니다) ④ 관련 상품
Brand Page · 브랜드(About)
코드위젯 전체 제작. 스크롤 스토리텔링.
① Hero(슬로건) → ② 문제 제기 → ③ MAMORU의 답(가치 3개) → ④ 복원수리 → ⑤ 대표 소개 → ⑥ 원칙 → ⑦ CTA
Restoration · 복원수리
코드위젯 전체 제작.
① Hero(전/후 비교) → ② 일반 vs MAMORU 비교 → ③ 프로세스 → ④ Before/After 갤러리 → ⑤ 가격 → ⑥ CTA
Consultation & AS · 상담·AS
코드위젯 폼 제작. 입력 필드: border --sand, radius 8px, focus --void. 여백 넉넉. Primary 버튼.

D-04 — Global Rules & Checklist

공통 규칙 & 체크리스트

디자인 원칙 5개
① 여백이 곧 고급감
섹션 간 최소 120px(PC), 80px(모바일).
② 사진이 말하게
사진 크게, 텍스트 보조. 배경 Shell 또는 White.
③ 장식 금지
뱃지, 리본, 그라데이션 배경, 포인트 컬러 — 전부 금지.
④ 모바일 우선
미용사는 모바일 접속. 터치 44px, 텍스트 14px+.
⑤ 일관성
모든 페이지에서 같은 컬러, 서체, 간격, radius.
Claude Code 체크리스트
작업 전
□ CSS 변수 복사 □ Google Fonts 3종 로드 □ viewport meta □ iframe 높이 자동 조절 스크립트
작업 중
□ ✏️ 마커 삽입 □ 파일 상단 안내문 □ 팔레트 9색+White 내 □ radius 스펙대로 □ 장식 없음 □ 아임웹 기능 침범 안 함
작업 후
□ PC(1200px+) 확인 □ 태블릿(768px) 확인 □ 모바일(375px) 확인 □ 터치 44px+ □ 텍스트 14px+ □ 이미지 안 잘림 □ "잡화점이 아니다" 최종 점검
