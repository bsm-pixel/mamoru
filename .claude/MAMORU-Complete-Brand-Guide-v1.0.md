## A-01 — 미션과 원칙

### Mission · 미션

> **미용가위의 올바른 기준을 세워, 모든 미용사가 스스로 판단할 수 있게 한다.**

MAMORU는 판매하지 않습니다. 안내할 뿐입니다.
할인 없음. 구매 권유 없음. 모든 고객에게 동일한 가격과 서비스.

### Slogan · 슬로건 (확정)

> # CUT THE FAKE, KEEP THE REAL

가짜를 잘라내고, 진짜를 지킨다.
미용가위의 Cut과 시장의 거짓을 걷어내는 Cut — 이중 의미.

---

## A-02 — 핵심 가치

### 3 Core Values

1. **고객이 이해해야 한다** — 왜 이 가위인지, 왜 이 형태인지, 왜 이 가격인지. 정보를 숨기지 않는다.
2. **고객이 선택해야 한다** — 선택지를 안내할 뿐, 고르는 건 고객이다. "안 사셔도 됩니다"를 두려워하지 않는다.
3. **고객이 만족해야 한다** — 이해하고, 스스로 선택했기에 진짜 만족이 온다. "앞으로 오래 일해주세요"가 가장 듣고 싶은 말.

## A-03 — 브랜드 성격

### Personality

- **한마디로:** 조용히 압도하는 전문가
- **형용사 5개:** `감각적인` `압도적인` `차분한` `전문적인` `신념이 느껴지는`
- **말투:** 먼저 묻고, 사실을 알려주고, 판단은 고객에게 맡긴다. 소리 지르지 않는데 가장 무서운 사람.
- **페르소나:** 사람의 모습을 한 외계인 — 업계 안에 있지만 관성에 물들지 않은 존재. 순하고 깔끔한데 남들이 모르는 걸 꿰뚫고 있다.
- **절대 피할 이미지:** ~~장사꾼 냄새~~ ~~촌스러움~~ ~~올드함~~ ~~장난기~~ ~~시끄러움~~

## A-05 — 불변 요소와 금기

### Absolutes · 절대 불변

`MAMORU 상호명` `거북이 심볼 로고` `맞춤 컨설팅 상담` `복원수리 기술력` `고객을 위한 진실된 철학`

### Golden Rules · 금기

- **할인 금지** — 모든 고객 동일 가격, 동일 서비스.
- **구매 권유 금지** — 볼트 조절이면 해결될 문제를 새 가위로 바꾸라 하지 않는다.
- **한마디로:** **판매하지 않는다. 안내할 뿐이다.**

### Supporting Copy · 보조 문구

> **돈이 안 아까운 곳, 시간이 아깝지 않은 곳**
> → 고객 언어에 가장 가까운 문구. 카피, 소개글, 후기 영역에 활용.

> **판매하지 않는다, 안내할 뿐이다.**
> → 내부 원칙문. About 페이지, 브랜드 소개 영역에 활용.

### 배경 운용 규칙 (중요)

- **기본은 라이트(Cream).** 일반 페이지(상품 목록·상세·상담·일반 안내 등)는 **Cream 배경 + Void 텍스트**가 기본.
- **다크(Void) 배경은 "특징·몰입 페이지"에만.** 복원수리 안내, 브랜드 철학(About) 같이 **감정·신뢰를 깊게 끌어올리는 페이지 한정.** 모든 페이지를 어둡게 깔지 않는다.
- **기법(모션·플루이드 타입·위계)은 라이트/다크 공통.** 색만 배경에 맞춰 반전 — **라이트: Void 텍스트 / 다크: Cream 텍스트**, 흐린 톤은 라이트=Warm Gray, 다크=Mist/Dim.

## B-02 — 타이포그래피

### 서체 역할

- **Display:** Outfit (PC 900 / 모바일 700) — 히어로, 대제목
- **Body:** Plus Jakarta Sans + Noto Sans KR (400) — 본문
- **Caption:** Plus Jakarta Sans + Noto Sans KR (400~500) — 주석, 라벨

### 타입 스케일 (기본)

| 역할 | 크기 | Weight |
|------|------|--------|
| Display | 56px | Outfit 900 (PC) / 700 (모바일) |
| H1 | 40px | Outfit 800 (PC) / 700 (모바일) |
| H2 | 28px | Outfit 800 (PC) / 700 (모바일) |
| H3 | 20px | Outfit 700 |
| Body | 16px | 400 |
| Caption | 12px | 400~500 |

### 반응형 타입 스케일 — PC vs Mobile

| 역할 | PC (1200px+) | 모바일 (≤480px) | Font / Weight |
|------|-------------|----------------|---------------|
| Display | 56px | 28~32px | Outfit 900 (PC) / 700 (모바일) |
| 페이지 제목 (H1) | 40px | 22px | Outfit 700~800 |
| 섹션 제목 (H2) | 28px | 18px | Jakarta/Noto 700 |
| 카드 제목 (H3) | 20px | 15px | Jakarta/Noto 600~700 |
| 서브 헤딩 | 16px | 14px | Jakarta/Noto 500~600 |
| 본문 | 16px | 13px (최소) | Jakarta/Noto 400 |
| 보조 설명 | 14px | 13px | Jakarta/Noto 400 |
| 주석 / 캡션 | 13px | 12px (최소) | Jakarta/Noto 400~500 |
| 라벨 / 배지 | 12px | 11px (하한선) | Jakarta/Noto 500~600 |

**핵심 규칙:**
- **모바일 절대 하한선: 11px** — 이보다 작으면 가독성 실패. 라벨/배지 외에는 사용 금지.
- **모바일 본문 기준: 13px** — "읽히긴 하는데 읽고 싶지 않은" 12px 대신, 13px을 모바일 본문 최소로 확정.
- **PC 본문 기준: 16px** — PC에서는 16px이 표준 본문 크기. 14px 이하는 보조 텍스트에만.

### 플루이드 타입 스케일 (clamp · 최신 · 권장)

미디어쿼리로 모바일/PC 두 값을 따로 잡는 대신, **`clamp(최소, 유동, 최대)` 한 줄로 화면 폭에 따라 매끄럽게 확대/축소.** 모바일에서 작고, PC에서 시원하게 — 코드 하나로. (검증: 복원수리 '원칙' 트렌디 리디자인)

| 역할 | `clamp()` 값 | 모바일(min) | PC(max) |
|------|-------------|------------|---------|
| Hero / 페이지 제목 | `clamp(30px, 9vw, 52px)` | 30 | 52 |
| 섹션 제목 (H2) | `clamp(22px, 6vw, 30px)` | 22 | 30 |
| 카드/소제목 (H3) | `clamp(18px, 4.5vw, 22px)` | 18 | 22 |
| 본문 | `clamp(14px, 3.8vw, 16px)` | 14 | 16 |
| 보조 설명 | `clamp(13px, 3.5vw, 15px)` | 13 | 15 |
| 라벨 / 인덱스 | `11~12px 고정` (clamp 불필요) | 11 | 12 |

- **하한선은 위 "핵심 규칙" 그대로** — clamp 최소값이 본문 13~14px, 라벨 11px 아래로 내려가지 않게.
- 제목엔 `letter-spacing:-.02~-.03em` + `text-wrap: balance`(줄바꿈 균형) 동반.
- 줄간격: 본문 1.8 / 제목 1.1~1.2 (트렌디 리디자인 기준, 기존 1.6~1.7도 허용).

## B-05 — 디자인 가이드라인

### Layout Rules

- **여백:** 요소 사이 충분한 공간. 여백 자체가 고급감.
- **그리드:** 정돈된 그리드 기반 배치. 이미지 크기·위치에 변화를 줘 단조롭지 않게.
- **사진:** 크고 임팩트 있게. 사진 하나가 압도하는 레이아웃.

### Forbidden · 디자인 금기

~~잡화점 느낌~~ ~~난잡한 레이아웃~~ ~~이미지와 텍스트 따로 노는 것~~ ~~포인트 컬러 남발~~ ~~과도한 장식~~

### Responsive Layout · 모바일/PC 배치 규칙

**모바일 전용 페이지 (알림톡 링크 등):** max-width 480px, 좌우 패딩 16px, 텍스트 center 정렬 기본, 카드 간격 12px.

**PC/모바일 겸용 페이지 (쇼핑몰 등):** max-width 1200px, 모바일 시 단일 컬럼 전환, 그리드 2~3열 → 1열.

| 속성 | PC (1200px+) | 모바일 (≤480px) |
|------|-------------|----------------|
| 섹션 간 여백 | 120px | 80px |
| 카드 내부 패딩 | 32~40px | 16~20px |
| 카드 border-radius | 16px | 12~14px |
| 버튼 높이 (CTA) | 52px | 48px (padding 16px) |
| 터치 타겟 최소 | — | 44×44px |
| 아이콘/썸네일 | 120px | 80~88px |
| 구분선 (divider) | 60px wide, 1px | 40px wide, 1px |

### Mobile Readability · 모바일 가독성 규칙

- **`<br>` 남용 금지:** `<br>`로 강제 줄바꿈하면 기기 너비(360~414px)에 따라 깨짐. max-width + 자연 줄바꿈 우선. 짧은 문구(2어절 이하)만 `<br>` 허용.
- **여백으로 공간 만들기:** 빈 `<br>`로 세로 간격을 만들지 않는다. margin-top/margin-bottom으로 처리.
- **위계 분리:** 동일 스타일(크기+굵기)의 텍스트가 연속 2회 이상 나오면 위계 실패. 제목 vs 결론은 반드시 크기·색상·굵기 중 하나 이상 차별화.
- **주석/부가 설명 분리:** 본문 속 * 기호로 주석을 섞지 않는다. step-note / caption 영역으로 시각적 분리 (배경 rgba + border-radius).
- **강조 (bold):** 핵심 키워드에만 `<b>` 적용. 한 단락에 2곳 이하. 과다 강조 = 강조 없음.
- **line-height:** 본문 1.6~1.7 / 리스트형 텍스트 2.0~2.2 / 제목 1.35~1.45

## B-06 — 모션 & 스크롤 인터랙션 (Scroll Reveal)

> "별똥별처럼 떠오르는" 느낌 — 스크롤로 콘텐츠가 **아래에서 살짝 떠오르며 페이드인**. 조용히, 한 번만, 우아하게. (검증: 복원수리 '원칙' 트렌디 리디자인)

### 시그니처 모션 = "Rise / Wipe"
- **효과:** 요소가 화면에 들어올 때 `translateY(20~26px) + opacity 0→1`로 떠오름. 제목은 0.8~0.9s, 본문 블록은 짧게.
- **구현(최신·초경량):** 순수 CSS **`animation-timeline: view()`** — **JS 0, 라이브러리 0, GPU 가벼움.** 진입 구간은 `animation-range: entry 2% cover 26%`로 제어.
- **폴백:** `@supports (animation-timeline: view())`로 감싸 **미지원 브라우저는 정적 표시**(깨짐 0). 모션은 "있으면 좋은" 진보적 향상 — 없어도 콘텐츠는 완전히 읽혀야 함.

```css
@keyframes rise{ from{opacity:0;transform:translateY(24px)} to{opacity:1;transform:none} }
@supports (animation-timeline: view()){
  .reveal{ animation:rise linear both; animation-timeline:view(); animation-range:entry 2% cover 26%; }
}
```

### 원칙
- **은은하게.** 이동 20~26px, 페이드 위주. 바운스·회전·과한 패럴럭스 금지.
- **한 번만.** 스크롤 왕복마다 반복 X(거슬림).
- **절제된 stagger.** 대량 리스트를 우르르 띄우지 않는다. 핵심 블록 위주.
- **자동재생 캐러셀은 과속 금지.** 손 스와이프 우선(브랜드 "조용히 압도").

### 적용처
히어로 제목/룰 · 섹션 진입 · "문제→답" 같은 대비 블록. 폼 입력·표·실시간 데이터엔 모션 최소.

## B-07 — 시각 위계 & 섹션 패턴 (인지가 쉬운 구조)

> 고객이 **1초 안에** "이게 문제, 이게 답"을 분류하도록. 색·크기·굵기를 동시에 차별.

### 대비로 인지시키기 ("문제 → 답" 패턴)
- **문제(과거·불편) = 흐리게:** 작은 크기 + 흐린 톤(라이트 Warm Gray / 다크 Dim·Mist) + 일반 굵기. 시각적으로 "배경/과거"로 물러남.
- **답(현재·마모루) = 선명하게:** 큰 제목(H2/H3) + 선명한 톤(Void/Cream) + Bold. "전경/현재"로 도드라짐.
- → 색·크기·굵기 **세 축 동시 차별** = 즉각 분류. (한 축만 다르면 약함)

### 구성 요소 (장식 아닌 "구조 신호")
- **거대 인덱스 넘버**(Outfit `01 / 03`): 섹션 스캔 리듬 + 진행감. 흐린 톤, 현재 번호만 선명.
- **Hairline 구분선**(다크 `rgba(255,255,255,.10)` / 라이트 `--sand`, 1px): 섹션 경계를 장식 없이 분리.
- **전환 큐**(가는 세로 그라데이션 라인): 문제 → 답으로 시선 유도.
- **히어로 룰**(짧은 막대 38×2px): 제목 하단 시그니처.
- **여백 리듬:** 섹션 진입 패딩 `clamp(48px,9vw,84px)` 류. 여백이 곧 위계 — 묶을 건 가깝게, 나눌 건 멀게.

### 1초 테스트 (제출 전)
화면을 1초 보고 눈 감았을 때 **핵심 메시지/답**이 잔상으로 남는가? 문제와 답이 섞여 보이면 대비 실패.

## B-08 — 콘텐츠 구조 패턴 (Layout Patterns) ★ 트렌디의 핵심

> ⚠️ **토큰(스킨)만으로는 "확 꽂히는" 느낌이 안 난다.** clamp·모션·색은 *기존 내용을 트렌디하게 보이게* 할 뿐.
> 진짜 임팩트는 **콘텐츠를 아래 패턴으로 '재구성'**할 때 나온다 (예: 신념 나열 → 문제→답). **구조를 바꾸는 게 핵심.**

### 패턴 카탈로그 (이름 붙여 재사용)
- **P1. 문제 → 답 (Problem → Answer)** — *나열형을 이걸로 바꿔라.*
  기존 방식의 **문제(흐림·작게)** → 마모루의 **답(선명·크게·Bold)**. "왜 우리인가" 신뢰·차별화 섹션. 경쟁사 비방 X, 업계 구조를 담담히. (적용: 복원수리 '왜, 마모루인가' — 구 '마모루의 원칙' 나열을 대체)
- **P2. 에디토리얼 인덱스 리스트** — `01 / 03` 거대 인덱스(Outfit) + hairline 구분 + 좌측 정렬. 원칙·단계·특징 나열에. 단순 카드 나열보다 잡지처럼 읽힘.
- **P3. 증거 우선 (Evidence-first)** — Before&After·후기 등 결과 증거를 **상단으로** 끌어올려 신뢰 선점. (적용: 복원수리 B&A를 선언 직후로)
- **P4. 과정 ↔ 결과 분리** — PREVIEW(과정 티저) / Before&After(결과 증거)를 역할로 나눔. 같은 부류를 한 섹션에 뭉치지 않기.
- **P5. 증명을 '보여주기'** — "투명합니다"(글) 대신 수리내역서 실물·후기·전후로 **보여줌**.

### 프로세스 규칙 (필수) — "트렌디 리디자인" 요청 시
1. **토큰 적용**(B-02 clamp / B-06 모션 / B-07 위계) — 기본기
2. **❗ 섹션별 구조 진단 → 패턴 제안** — *페인트만 칠하지 말 것.* 나열형·설명형 섹션을 발견하면 **"이건 P1 문제→답으로 바꿀까요?"** 식으로 **먼저 제안**한다. 구조 재구성이 트렌디의 본질.
3. 사장님 승인 후 토큰+패턴 함께 적용.

> 즉 **트렌디 = 스킨(토큰) + 뼈대(패턴)**. 뼈대 제안을 빼면 "왜 마모루인가" 급 임팩트는 안 나온다 — 이게 핵심 교훈(2026-06-20).

6. **브랜드 한마디** — "판매하지 않는다. 안내할 뿐이다." Void 배경, Display 사이즈.

## D-04 — 공통 규칙 & 체크리스트

### 디자인 원칙 5개

1. **여백이 곧 고급감** — 섹션 간 최소 120px(PC), 80px(모바일).
2. **사진이 말하게** — 사진 크게, 텍스트 보조. 배경 Shell 또는 White.
3. **장식 금지** — 뱃지, 리본, 그라데이션 배경, 포인트 컬러 — 전부 금지.
4. **모바일 우선** — 미용사는 모바일 접속. 터치 44px, 본문 13px+ (PC는 16px), 라벨 11px 하한선.
5. **일관성** — 모든 페이지에서 같은 컬러, 서체, 간격, radius.
