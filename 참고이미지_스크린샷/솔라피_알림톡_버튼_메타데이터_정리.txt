============================================================
 요약
============================================================

총 17개 템플릿
├─ WL 버튼 있음: 6개 (#1, #3, #7, #8, #10, #17)
├─ BC 버튼 있음: 12개 (#1~#3, #6~#10, #13, #15~#17)
├─ 퀵버튼 BC:    4개 (#4, #5, #11, #12) — 리마인드용
├─ 버튼 없음:    1개 (#14 변경요청접수)
└─ 메타데이터:   BC 있는 12개 전부 #{type}_#{template}_#{name}

메타데이터 통일 형식: #{type}_#{template}_#{name}
  → type: 서비스 종류 (매장 방문 / 출장 요청 / 톡상담)
  → template: 상태 (confirmed / cancelled / request / ...)
  → name: 고객명
  → 해피톡 상담사가 "누가, 어떤 서비스, 어떤 상태에서 문의했는지" 즉시 파악

※ #{name} 변수가 본문에 없는 템플릿(field_delayed 등)은
   변수 목록에 name을 추가 등록 필요 → 검수 시 확인
   거부 시 해당 템플릿만 #{type}_#{template} 으로 대체
