[개선 방향]
1. #23 출고완료 자동 발송
   → 현재: 관리자가 TMS에서 수동 발송
   → 개선: 롯데택배 수거 집하 처리 시 자동 트리거
   → 방법: 롯데택배 API 집하 상태 폴링 or 웹훅 연동

2. #22 입금완료 — 자동 감지 가능성
   → 우리은행 입금 알림 → Make 시나리오 → 금액 매칭 → 자동 발송
   → 동명이인/금액 불일치 리스크 있어 수동 확인이 안전 (현행 유지 권장)

3. #25 접수취소 — 취소 프로세스
   → 현행: 고객이 1:1 문의 → 관리자 수동 취소 (관리자 인지 보장)
   → 셀프 취소 UI는 오취소 리스크 대비 현재 단계에서 불필요

4. 수리내역서 기능 (TMS Phase 7)
   → 검수 시 상처부위 이미지 마킹 + 체크리스트 입력
   → 수리 전/후 사진 비교
   → page_as_report.html에서 고객에게 조회 제공

5. #23 출고완료 — 카카오 내장 배송조회 버튼 사용
   → 내장 배송조회 + WL(수리내역) + BC(1:1문의) 3버튼 구성으로 해결
   → WL 슬롯 1개만 사용하므로 BC 여유 확보
