# Cowork 프롬프트 모음

## 🔧 복원수리 블로그

### 프롬프트 1: 특정 1건 작성

```
01_톤가이드.md를 먼저 읽어줘.

blog_sources/복원수리/2026-02-25_시저스_날찍힘/ 폴더의
info.txt와 before/after 사진을 참고해서
톤가이드의 "복원수리 Before/After" 구조로 블로그 글 1편을 작성해줘.

규칙:
- 분량 400~800자
- 사진 삽입 위치를 [📷 before_전체.jpg] 형식으로 표시
- 제목은 30~50자, SEO 키워드 포함
- CTA는 부드러운 안내 형태

output/복원수리/ 폴더에 저장해줘.
```

---

### 프롬프트 2: 이번 주 수리 건 전부 일괄 작성

```
01_톤가이드.md를 먼저 읽어줘.

blog_sources/복원수리/ 하위 폴더를 모두 읽고,
각 건마다 톤가이드의 "복원수리 Before/After" 구조로 블로그 글을 작성해줘.

규칙:
- 건별로 info.txt + before/after 사진 참고
- 분량 400~800자
- 제목에 SEO 키워드 포함
- 제목이 서로 겹치지 않게
- 병렬로 처리

output/복원수리/ 폴더에 각각 저장해줘.
파일명: 날짜_가위종류_블로그.md
```

---

### 프롬프트 3: 기존 글 톤 검수

```
01_톤가이드.md를 읽고,
output/복원수리/ 폴더의 모든 .md 파일을 검수해줘.

체크 항목:
- 금지 표현 사용 여부
- 톤 일관성 (과장/압박 없는지)
- SEO 키워드 포함 여부
- 분량 적정 여부

문제 있는 부분은 수정해서 같은 파일에 덮어써줘.
수정 내역을 마지막에 요약해줘.
```

## 🎯 제품 소개 블로그

### 프롬프트 4: 제품 1종 소개

```
01_톤가이드.md를 먼저 읽어줘.

blog_sources/제품소개/ 폴더에서 제품 정보 파일을 읽고,
톤가이드의 "제품 소개" 구조로 블로그 글 1편을 작성해줘.

대상: 커트 비중 높은 중급 이상 디자이너
분량: 500~1000자

output/제품소개/ 폴더에 저장해줘.
```

## 💡 관리 팁 블로그

### 프롬프트 5: 관리 팁 시리즈

```
01_톤가이드.md를 먼저 읽어줘.

아래 주제로 가위 관리 팁 블로그 글을 작성해줘:

주제: [여기에 주제 입력]
(예: "장력이 약해졌을 때 셀프 점검법")
(예: "가위 세척, 이것만 피하면 됩니다")
(예: "연마 주기, 어떻게 판단하나요")

톤: 선생님이 아니라 같이 일하는 선배
구조: 문제 상황 → 원인 → 해결법 → 셀프 체크리스트
분량: 300~600자

output/관리팁/ 폴더에 저장해줘.
```

## 📋 월간 콘텐츠 계획 생성

### 프롬프트 6: 이번 달 블로그 캘린더

```

blog_sources/ 폴더 전체를 살펴보고,
아직 글로 작성되지 않은 소스가 있는지 확인해줘.

그리고 이번 달 블로그 발행 캘린더를 만들어줘:
- 주 2~3회 발행 기준
- 복원수리 B/A, 제품소개, 관리팁 골고루 배치
- 각 날짜에 제목 초안 + 소스 폴더 경로 매핑

output/월간계획_YYYY-MM.md 로 저장해줘.
```
