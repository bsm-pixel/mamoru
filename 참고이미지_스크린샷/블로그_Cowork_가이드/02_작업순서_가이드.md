# 블로그 작업 순서 가이드 (Cowork용)

---

## Step 1. 사진 준비

### 복원수리 Before/After — 사진 준비 규칙

| 구분 | 필수 사진 | 선택 사진 |
|------|-----------|-----------|
| Before (수리 전) | 전체샷 1장 + 증상 클로즈업 1장 | 다른 각도 증상 1장 |
| After (수리 후) | 전체샷 1장 + 동일 부위 클로즈업 1장 | 다른 각도 1장 |

**최소 4장, 권장 6장**

### 촬영 팁

```
✅ 해야 할 것
- Before/After 동일 배경 (흰색 or 크림색 단색 천)
- Before/After 동일 각도 (가능하면 같은 위치에서)
- Before/After 동일 조명 (자연광 추천)
- 증상 부위에 초점 맞추기 (날 끝, 스토퍼, 빗살 등)

❌ 하지 말 것
- 배경 지저분한 상태로 촬영
- Before는 어둡고 After는 밝게 (의도적 보정 느낌)
- 손가락으로 증상 부위 가리기
```

### 사진 파일명 규칙
```
before_전체.jpg
before_날끝.jpg
before_스토퍼.jpg  (선택)
after_전체.jpg
after_날끝.jpg
after_스토퍼.jpg   (선택)
```
→ Cowork가 파일명으로 before/after를 자동 구분합니다.

## Step 2. 폴더 만들기

### 폴더명 규칙: `날짜_가위종류_증상`
```
예시:
2026-02-25_시저스_날찍힘
2026-02-26_틴닝_장력저하
2026-02-27_블런트_스토퍼마모
2026-03-01_타사_시저스_무뎌짐    ← 타사 가위는 앞에 "타사" 표기
```

### 폴더 위치
```
blog_sources/
└── 복원수리/
    └── 2026-02-25_시저스_날찍힘/   ← 여기에 사진 넣기
        ├── before_전체.jpg
        ├── before_날끝.jpg
        ├── after_전체.jpg
        ├── after_날끝.jpg
        └── info.txt                ← Step 3에서 작성
```

## Step 3. info.txt 작성

### 각 수리 건 폴더에 info.txt 하나씩 만들기

아래 내용을 복사해서 채우면 됩니다:

```
고객: (비공개 or 이니셜, 예: K님)
가위종류: 시저스 / 틴닝 / 블런트
브랜드: 마모루 / 타사 (브랜드명 기입)
인치: 6.0
사용기간: 약 5년
증상: 날찍힘, 무뎌짐
수리내용: 날 재연마, 스토퍼 교체
수리전장력: 약함
수리후장력: 적정
특이사항: 첫 수리, 매일 사용
고객한마디: "다시 새 가위 같아요" (없으면 빈칸)
```

### 작성 팁
- **고객명은 이니셜만** (개인정보 보호)
- **증상은 쉼표로 구분** → Cowork가 자동으로 Before 섹션에 반영
- **수리내용은 간단히** → Cowork가 수리 과정 섹션으로 풀어씀
- **고객한마디** → 있으면 글의 시작이나 마무리에 인용으로 활용됨

## Step 4. Cowork 실행

### 4-1. Claude Desktop 열기
- Claude Desktop 앱 실행
- 상단 탭에서 **Chat → Cowork** 전환

### 4-2. 작업 폴더 지정
- `Work in a folder` 클릭
- 이 가이드가 들어있는 폴더 전체를 선택
  (또는 `blog_sources` 폴더를 선택)

### 4-3. 프롬프트 입력
- `03_Cowork_프롬프트_모음.md`에서 원하는 프롬프트 복사
- Cowork 입력창에 붙여넣기
- Enter

### 4-4. 계획 확인
- Cowork가 "이렇게 진행하겠습니다" 계획을 보여줌
- 확인 후 승인

### 4-5. 작업 진행 모니터링
- 사이드바에서 실시간 진행 상황 확인 가능
- 여러 건이면 Sub-Agent가 병렬로 동시 작성
- 중간에 방향 수정 지시 가능

### 4-6. 결과 확인
- `output/` 폴더에 완성된 .md 파일 저장됨
- 발행 전 체크리스트로 검수 (01_톤가이드.md §5 참조)

---

## Step 5. 발행

### 방법 A: 수동 발행
1. output/ 폴더의 .md 파일 열기
2. 블로그 플랫폼에 복사-붙여넣기
3. 사진 첨부
4. 미리보기 확인 → 발행

### 방법 B: WordPress 플러그인 연동 (추후)
1. Cowork WordPress 플러그인 설치
2. "output 폴더의 글을 WordPress에 임시저장으로 올려줘" 지시
3. WordPress에서 검토 → 발행

## 주간 루틴 제안

| 요일 | 작업 | 소요 시간 |
|------|------|-----------|
| 월 | 지난주 수리 건 사진 정리 + info.txt 작성 | 15~20분 |
| 화 | Cowork로 블로그 일괄 생성 | 5분 (지시) + 대기 |
| 수 | 생성된 글 검수 + 발행 | 15~20분 |

→ **주 1시간 미만**으로 복원수리 블로그 2~3편 발행 가능
