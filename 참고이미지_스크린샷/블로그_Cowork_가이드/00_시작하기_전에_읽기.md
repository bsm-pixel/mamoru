# 📂 MAMORU 블로그 Cowork 가이드

> 이 폴더 전체를 바탕화면에 복사해서 블로그 작업용으로 사용하세요.
> Claude Cowork에서 이 폴더를 작업 폴더로 지정하면 됩니다.

---

## 이 폴더 구성

```
블로그_Cowork_가이드/
│
├── 00_시작하기_전에_읽기.md    ← 지금 보고 있는 파일
├── 01_톤가이드.md              ← 브랜드 톤·문체 규칙 (Cowork 필수 참조)
├── 02_작업순서_가이드.md       ← 단계별 진행 방법
├── 03_Cowork_프롬프트_모음.md  ← 복사해서 바로 쓰는 프롬프트
│
├── blog_sources/               ← ⭐ 여기에 사진+정보 넣기
│   ├── 복원수리/
│   │   └── (날짜_가위종류_증상/) ← 건별 폴더
│   ├── 제품소개/
│   └── 관리팁/
│
└── output/                     ← Cowork가 완성 글을 여기에 저장
```

---

## 빠른 시작 (3분)

1. `blog_sources/복원수리/` 안에 폴더 하나 만들기
2. 수리 전후 사진 넣기 + `info.txt` 작성
3. Claude Desktop → Cowork 탭 → 이 폴더 지정
4. 프롬프트 복사 → 붙여넣기 → 실행

상세 방법은 `02_작업순서_가이드.md` 참조
