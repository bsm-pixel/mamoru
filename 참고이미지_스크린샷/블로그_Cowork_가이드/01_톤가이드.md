## 2. 톤 & 보이스

### 우리의 말투
- **전문가의 조용한 확신**: 과장 없이, 근거 있는 말만
- **동행하는 느낌**: "해드립니다"가 아니라 "함께 봅니다"
- **담백한 온기**: 감성적이되 눅눅하지 않음. 건조하되 차갑지 않음
- **존댓말 기본**: ~합니다/~입니다 체

### 문장 스타일

✅ **좋은 예**
- "오랜 시간 손에 익은 가위일수록, 복원의 가치가 큽니다."
- "날 끝 0.1mm의 차이가 커트라인을 바꿉니다."
- "수리 전후 사진으로 직접 확인하실 수 있습니다."

❌ **피할 표현**
- "업계 최고!" "놀라운 변화!" "지금 바로!" → 과장/압박
- "저희가 알아서 다 해드릴게요~" → 가벼움
- "단돈 ○○원에!" → 가격 강조
- "걱정 마세요" 반복 → 오히려 불안 유발

### 감성 키워드

| 사용 권장 | 사용 금지 |
|-----------|-----------|
| 복원, 되살리다, 본래의 | 완전 새것, 마법, 기적 |
| 장인, 숙련된, 정밀한 | 최고, 최강, 업계 1위 |
| 오래 함께한, 손에 익은 | 낡은, 버릴 뻔한 |
| 확인하다, 살펴보다 | 보장하다, 약속하다 |
| 안심, 신뢰, 꼼꼼한 | 걱정 마세요(반복적) |

## 3. 카테고리별 글 구조

### 🔧 복원수리 Before/After

```
[제목] ○○ 가위 복원수리 — [증상]에서 [결과]로

[도입부] 2~3문장
→ 가위의 사연, 어떤 증상으로 의뢰했는지

[Before] 📷 수리 전 사진
→ 증상 설명 (날찍힘/무뎌짐/스토퍼/빗살/장력 등)
→ 전문 용어는 괄호로 짧게 설명

[수리 과정] 1~3줄 (선택)
→ 어떤 작업을 했는지. 길게 쓰지 않음

[After] 📷 수리 후 사진
→ 개선된 점 구체적 서술
→ 가능하면 수치 포함 (장력 ○→○ 복원)

[마무리] 1~2문장
→ 안심 메시지 + 부드러운 CTA
```

분량: **400~800자** (사진이 주역, 텍스트는 보조)

제목 예시:
- `5년 된 시저스 복원수리 — 날찍힘에서 정밀 커트라인까지`
- `스토퍼 마모 + 장력 저하, 동시에 잡았습니다`
- `"버리려던 가위"가 다시 메인이 되기까지`

---

### 🎯 제품 소개

```
[한 줄 요약] → [대상: 어떤 스타일리스트에게] → [핵심 특징 2~3개] → [사진] → [마무리]
```
분량: 500~1000자
톤: 스펙 나열이 아니라 "이 가위가 어떤 손에 맞는가"

---

### 💡 가위 관리 팁

```
[문제 상황] → [원인] → [해결/관리법] → [셀프 점검 체크리스트]
```
분량: 300~600자
톤: 선생님이 아니라 "같이 일하는 선배"

---

### 💬 고객 후기

```
[고객 한마디 인용] → [상황 설명] → [우리가 한 일] → [결과]
```
분량: 300~500자
톤: 고객 목소리 중심, 우리는 배경

## 4. SEO 규칙

| 항목 | 규칙 |
|------|------|
| 제목 | 30~50자, 핵심 키워드 포함 |
| 키워드 | 미용가위, 복원수리, 가위수리, 가위연마, Before After |
| 메타설명 | 80~120자 |
| 이미지 alt | "마모루 가위 복원수리 before after [증상]" |
| 내부링크 | 관련 글/제품 페이지 최소 1개 연결 |
