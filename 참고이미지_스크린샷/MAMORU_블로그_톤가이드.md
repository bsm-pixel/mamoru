## 2. 톤 & 보이스

### 우리의 말투
- **전문가의 조용한 확신**: 과장 없이, 근거 있는 말만 한다
- **동행하는 느낌**: "해드립니다"가 아니라 "함께 봅니다"
- **담백한 온기**: 감성적이되 눅눅하지 않음. 건조하되 차갑지 않음
- **존댓말 기본**: ~합니다/~입니다 체. 친근하되 격식은 유지

### 문장 스타일
```
✅ 좋은 예
- "오랜 시간 손에 익은 가위일수록, 복원의 가치가 큽니다."
- "날 끝 0.1mm의 차이가 커트라인을 바꿉니다."
- "수리 전후 사진으로 직접 확인하실 수 있습니다."

❌ 피할 표현
- "업계 최고!" "놀라운 변화!" "지금 바로!" (과장/압박)
- "저희가 알아서 다 해드릴게요~" (가벼움)
- "이 정도면 새 가위 사는 게 낫지 않을까요?" (불안 자극)
- "단돈 ○○원에!" (가격 강조)
```

### 감성 키워드 (글에 자연스럽게 녹이기)
| 사용 권장 | 사용 금지 |
|-----------|-----------|
| 복원, 되살리다, 본래의 | 완전 새것, 마법, 기적 |
| 장인, 숙련된, 정밀한 | 최고, 최강, 업계 1위 |
| 오래 함께한, 손에 익은 | 낡은, 버릴 뻔한 |
| 확인하다, 살펴보다 | 보장하다, 약속하다 |
| 안심, 신뢰, 꼼꼼한 | 걱정 마세요(반복적) |

## 3. 블로그 카테고리별 가이드

### 📌 복원수리 Before/After (핵심 콘텐츠)

**구조 템플릿:**
```
[제목] ○○ 가위 복원수리 — [증상 키워드]에서 [결과 키워드]로

[도입부 2~3문장]
- 가위의 사연 or 고객 상황 간략 소개
- 어떤 증상으로 의뢰했는지

[Before 섹션]
- 📷 수리 전 사진 삽입
- 증상 설명 (날찍힘/무뎌짐/스토퍼/빗살/장력 등)
- 전문 용어는 짧은 괄호 설명 첨부

[수리 과정 섹션 (선택)]
- 어떤 작업을 했는지 1~3줄
- 너무 길게 쓰지 않음 — 결과로 말한다

[After 섹션]
- 📷 수리 후 사진 삽입
- 개선된 점 구체적 서술
- 가능하면 수치 포함 (예: 장력 ○→○ 복원)

[마무리 1~2문장]
- 다시 현장에서 쓸 수 있게 되었다는 안심 메시지
- CTA는 부드럽게: "복원수리가 궁금하시면 편하게 문의주세요."
```

**제목 패턴 예시:**
- `5년 된 시저스 복원수리 — 날찍힘에서 정밀 커트라인까지`
- `스토퍼 마모 + 장력 저하, 동시에 잡았습니다`
- `"버리려던 가위"가 다시 메인이 되기까지`

**분량:** 400~800자 (사진이 주역, 텍스트는 보조)

---

### 📌 제품 소개

**톤:** 스펙 나열이 아니라 "이 가위가 어떤 손에 맞는가"
```
구조: 한 줄 요약 → 대상 (어떤 스타일리스트에게) → 핵심 특징 2~3개 → 사진 → 마무리
분량: 500~1000자
```

**예시 도입부:**
> 커트 비중이 높은 디자이너를 위해 설계했습니다.
> 6인치 오프셋 핸들, 코발트 합금 — 하루 종일 잡아도 손목이 편한 무게 중심.

---

### 📌 가위 관리 팁 / 지식 콘텐츠

**톤:** 선생님이 아니라 "같이 일하는 선배"
```
구조: 문제 상황 → 원인 → 해결/관리법 → (선택) 자가 점검 체크리스트
분량: 300~600자
```

**예시:**
> "커트할 때 머리카락이 접히는 느낌" — 날이 무뎌진 게 아니라 장력 문제일 수 있습니다.
> 셀프 점검법 하나만 알면 불필요한 연마를 줄일 수 있어요.

---

### 📌 고객 후기 / 스토리

**톤:** 고객 목소리 중심, 우리는 배경
```
구조: 고객 한마디(인용) → 상황 설명 → 우리가 한 일 → 결과
분량: 300~500자
```

## 4. 사진 가이드라인

### 복원수리 Before/After 촬영

| 항목 | Before | After |
|------|--------|-------|
| 배경 | 통일 (흰색 or 크림 단색) | 동일 배경 |
| 각도 | 동일 각도 유지 | 동일 각도 유지 |
| 조명 | 자연광 or 일정한 조명 | 동일 조명 |
| 초점 | 증상 부위 클로즈업 | 개선 부위 클로즈업 |
| 촬영 컷 수 | 전체 1장 + 부위 1~2장 | 전체 1장 + 부위 1~2장 |

### 사진 파일 정리 규칙 (Cowork용)
```
blog_sources/
├── 복원수리/
│   ├── 2026-02-25_시저스_날찍힘/
│   │   ├── before_전체.jpg
│   │   ├── before_날끝.jpg
│   │   ├── after_전체.jpg
│   │   ├── after_날끝.jpg
│   │   └── info.txt          ← 아래 참조
│   └── 2026-02-26_블런트_장력저하/
│       └── ...
├── 제품소개/
└── 관리팁/
```

### info.txt 템플릿 (각 수리 건마다 작성)
```
고객명: (비공개 or 이니셜)
가위종류: 시저스 / 틴닝 / 블런트 등
브랜드: 마모루 / 타사 (브랜드명)
인치: 6.0
증상: 날찍힘, 무뎌짐
수리내용: 날 재연마 + 스토퍼 교체
수리전장력: 약함
수리후장력: 적정
특이사항: 5년 사용, 첫 수리
고객한마디: "다시 새 가위 같아요" (선택)
```

## 6. 발행 체크리스트

- [ ] 톤가이드의 금지 표현이 없는가?
- [ ] Before/After 사진 각도·배경이 통일되었는가?
- [ ] 제목에 핵심 키워드가 포함되었는가?
- [ ] 분량이 카테고리별 권장 범위 내인가?
- [ ] CTA가 부드러운 안내 형태인가? (압박 아닌 안심)
- [ ] 고객 개인정보(실명, 전화번호)가 노출되지 않았는가?
- [ ] 이미지 alt 텍스트가 입력되었는가?

## 7. Claude Cowork 사용 시 프롬프트 예시

### 복원수리 블로그 1편 작성
```
blog_sources/복원수리/2026-02-25_시저스_날찍힘/ 폴더를 읽어줘.
info.txt의 정보와 before/after 사진을 참고해서
MAMORU_블로그_톤가이드.md의 "복원수리 Before/After" 구조로
블로그 글 1편을 작성하고 output/ 폴더에 저장해줘.
```

### 복원수리 블로그 일괄 작성
```
blog_sources/복원수리/ 하위 폴더를 모두 읽고,
각 건마다 톤가이드 규칙에 맞는 블로그 글을 작성해줘.
병렬로 처리하고, output/복원수리/ 폴더에 각각 저장해줘.
```

### 제품 소개 블로그
```
blog_sources/제품소개/M7_스펙.xlsx를 읽고,
톤가이드의 "제품 소개" 구조로 블로그 글을 작성해줘.
대상 고객: 커트 비중 높은 중급 디자이너.
```
