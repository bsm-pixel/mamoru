# 간편진단 질문/선택지 구조

> 이 문서는 진단 결과 문구 시스템 개선을 위한 질문/선택지 정리 문서입니다.
> 사용자가 내용을 확정한 후 다음 단계(조합 로직 설계)로 진행합니다.

---

## 현재 질문 목록 (총 12개, 조건부 표시)

### Q1. 경력 (Q_STAGE) - 필수
| ID | 라벨 | 설명 |
|----|------|------|
| CE | 자격증 준비 | 아직 현장 경험이 없어요 |
| IN | 인턴/스탭 | 현장에서 배우는 중이에요 |
| DE | 디자이너 | 손님을 직접 담당해요 |

---

### Q2. 가위 종류 (Q_TYPE) - 필수, 복수선택
| ID | 라벨 | 설명 |
|----|------|------|
| BL | 블런트 (커트가위) | 기본 커트용 |
| TH | 틴닝 (숱가위) | 숱 조절용 |
| LO | 장가위 | 긴 날 커트용 |
| SL | 슬라이싱 | 슬라이드 컷 전용 |

---

### Q3. 커트 느낌 (Q_FEEL) - 조건부
**조건:** (인턴/스탭 OR 디자이너) AND (블런트 OR 장가위 선택)

| ID | 라벨 | 설명 |
|----|------|------|
| FEEL_SOFT | 부드러운 커트감 | 가볍고 매끄럽게 |
| FEEL_POWER | 힘있고 강한 느낌 | 단단하고 확실하게 |
| FEEL_NONE | 아직 잘 모르겠어요 | 경험이 더 필요해요 |

---

### Q4. 커트 스타일 (Q_STYLE) - 조건부
**조건:** 디자이너 AND 블런트 선택

| ID | 라벨 | 설명 |
|----|------|------|
| St_GO | 직진성 커트 | 직선으로 쭉쭉 |
| St_BACK | 스트로크 커트 | 뒤로 빼듯 조곤조곤 |
| St_NONE | 딱 기준이 없어요 | 상황에 따라 달라요 |

---

### Q5. 커트 습관 (Q_HABIT) - 조건부
**조건:** 디자이너 AND 블런트 선택

| ID | 라벨 | 설명 |
|----|------|------|
| HAB_WET | WET 커트 위주 | 항상 분무하고 커트해요 |
| HAB_DRY | DRY 커트 위주 | 마른 모발 커트가 많아요 |
| HAB_NONE | 반반이에요 | 그때그때 달라요 |

---

### Q6. 틴닝 감모량 (Q_TH_RATIO) - 조건부
**조건:** 틴닝 선택

| ID | 라벨 | 설명 |
|----|------|------|
| TH_25 | 25% (메인 틴닝) | 가장 범용적인 감모량 |
| TH_15 | 15% (적은 감모) | 섬세한 마무리용 |
| TH_35 | 35% (많은 감모) | 빠른 숱 조절용 |

---

### Q7. 틴닝 구매목적 (Q_TH_WHY) - 조건부

## 플랜에서 제안한 신규 데이터 구조

### 1. typeMessagesData (가위 종류별 메시지)

```
BL (블런트):
  - default: 블런트 가위 상태를 파악했습니다.
  - 조합별 메시지 (FEEL + STYLE + HABIT 조합)

TH (틴닝):
  - default: 틴닝 가위 상태를 파악했습니다.
  - 조합별 메시지 (감모량 + 구매목적 조합)

LO (장가위):
  - default: 장가위 상태를 파악했습니다.
  - 용도별 메시지 (블런트 겸용 / 싱글링 전용)
  - 특별 안내 (장가위 특성 설명)

SL (슬라이싱):
  - default: 슬라이싱 가위 상태를 파악했습니다.
  - 구매동기별 메시지 (첫 구매 / 불만족 교체)
  - 불만족 이유별 세부 메시지
```

### 2. mismatchRules (불일치 규칙)

| 조합 | 안내 메시지 (예시) |
|------|------------------|
| 직진성 + DRY | 직진성 + DRY 조합은 드문 편이에요. 상담에서 더 파악해드릴게요. |
| 스트로크 + 힘있는 느낌 | (추가 정의 필요) |
| DRY + 부드러운 느낌 | (추가 정의 필요) |

## 확인 필요 사항 (사용자 결정 필요)

### 1. 가위 종류별 메시지 문구
- [ ] BL (블런트): 조합별 메시지 문구 작성
- [ ] TH (틴닝): 조합별 메시지 문구 작성
- [ ] LO (장가위): 용도별 메시지 + 특별 안내 문구 작성
- [ ] SL (슬라이싱): 구매동기별/불만족 이유별 메시지 문구 작성

### 2. 불일치 조합 정의
어떤 조합을 "드문 조합"으로 안내할지 결정 필요:
- [ ] 직진성 + DRY → 드문 조합?
- [ ] 스트로크 + 힘있는 느낌 → 독특한 조합?
- [ ] 기타 불일치 조합 추가?

### 3. 메시지 톤 확정
- [ ] "~를 파악했습니다" / "~이시네요" / 기타
