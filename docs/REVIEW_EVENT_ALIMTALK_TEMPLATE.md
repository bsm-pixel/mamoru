# 리뷰 이벤트 알림톡 템플릿 (솔라피 콘솔 등록용)

> 2026-10-02 개정 — 당첨자 배송 기능(TMS 마이그 156)과 1:1로 맞춘 최종본. 이전 초안(BC 버튼·event_month 변수)은 폐기.
> 톤 = 기존 승인 템플릿(event_received·event_shipped 등)과 동일 — 절제·담백·존댓말, **마침표 생략**, 묶음 제목은 `✅ 상품` 형식, 항목 앞 `•`, 이모지는 **핵심 한 곳만**(①은 🎁).
> 부가정보(`고객센터 · 평일 09:00 ~ 17:00`)는 현재 운영 템플릿에 넣고 있다면 동일하게 추가.
> 알림톡 = **전부 이미지형** (배너 800×400 · Cream/Void · 장식 금지). 변수명 = 코드가 보내는 JSON 필드명과 100% 일치.
> 검수 1~3영업일. 승인 후 Make `06 EVENT` 시나리오에 분기 연결 (코드는 이미 `webhook_event`로 보냄).

## ① TMS-리뷰이벤트-당첨안내 · 코드값 `review_event_won`
- **카테고리**: 서비스이용 > 이용안내/공지 (004001)
- **배너**: `REVIEW EVENT` / `리뷰 이벤트 당첨` / `진심 어린 후기에 감사드립니다`
- **변수**: `#{name}` `#{rank}`(예: 1등·커스텀 상 이름) `#{prize}`(상품명) `#{token}`(배송지 링크 식별값)
- **내용**
```
#{name}님, 안녕하세요
MAMORU 리뷰 이벤트 #{rank}에 당첨되셨습니다
남겨주신 진심 어린 후기 감사합니다

🎁 당첨 상품
#{prize}

• 아래 버튼에서 받으실 주소를 확인해 주세요
• 확인되는 대로 순차 발송해 드립니다
```
- **버튼** (웹링크) **[배송지 입력하기]** → `https://page.mamoru.kr/projects/reviews/page_event_address.html?t=#{token}`
- **검수 요청 메모**
```
본 템플릿은 광고·홍보 목적이 아닌, 고객이 직접 참여한 이벤트의 "당첨 결과 안내 및 경품 배송지 확인"을 위한 정보성 메시지입니다.

[발송 대상]
마모루에서 제품 구매·상담·복원수리를 이용한 뒤 직접 이용 후기를 작성하여 리뷰 이벤트에 참여한 고객 중, 추첨을 통해 당첨된 고객에게만 1회 발송합니다. 미참여자나 미당첨자에게는 발송하지 않으며, 다수에게 일괄로 보내는 홍보 메시지가 아닙니다.

[발송 목적]
1) 고객 본인이 참여한 이벤트의 당첨 사실 안내
2) 당첨 경품을 발송하기 위한 배송지 확인(필수 절차)
버튼은 고객 본인의 배송지를 확인·입력하는 페이지로만 연결되며, 상품 구매 유도·할인·쿠폰 등 광고성 내용은 포함하지 않습니다.

[변수]
#{name} 당첨 고객명 / #{rank} 당첨 등수 / #{prize} 당첨 경품명 / #{token} 고객별 배송지 입력 링크 식별값
```

## ② TMS-리뷰이벤트-출고안내 · 코드값 `review_event_shipped`
- **카테고리**: 배송 > 상태안내 (006001)
- **배너**: `SHIPPED` / `당첨 상품 출고` / `곧 만나보실 수 있습니다`
- **변수**: `#{name}` `#{prize}` `#{courier}`(롯데택배) `#{tracking}`(송장번호)
- **내용**
```
#{name}님, 안녕하세요
리뷰 이벤트 당첨 상품이 발송되었습니다

✅ 상품
#{prize}

• 택배사 : #{courier}
• 송장번호 : #{tracking}

송장번호로 배송 조회가 가능합니다
```
- **버튼**: 배송조회
- **검수 요청 메모**
```
본 템플릿은 광고·홍보 목적이 아닌, 이벤트 당첨 고객에게 경품의 "발송 및 배송 조회 정보"를 안내하는 정보성(배송 안내) 메시지입니다.

[발송 대상]
리뷰 이벤트에 당첨되어 배송지를 직접 입력한 고객에게만, 택배사가 실제로 상품을 집하(수거)한 시점에 1회 자동 발송합니다.

[발송 목적]
당첨 경품의 발송 사실과 택배사·송장번호를 안내하여 고객이 배송 상황을 확인할 수 있도록 하기 위함입니다. 구매 권유·할인·쿠폰 등 광고성 내용은 포함하지 않으며, 버튼은 배송 조회 기능만 제공합니다.

[변수]
#{name} 고객명 / #{prize} 발송 경품명 / #{courier} 택배사 / #{tracking} 송장번호
```

- 시나리오 `06 EVENT` (webhook_event) 에 분기 2개: 필터 `{{1.template}}` = `review_event_won` / `review_event_shipped`

- 연결 후 Settings `Store incomplete executions` = Yes 재확인 ([reference_make_scenario_autostop])
